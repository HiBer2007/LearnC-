# 配置步骤 · 空模板 01（C 单文件）

目标：使本文件夹中按 **F5** 即可调试 `main.c`，两条路线各配置一套。

请按清单逐项确认；遇到问题时，请查看 `B-examples\01-c-single-file\.vscode\` 中的参考答案。

---

## 第 0 步 · 先确认工具链没有问题

在终端中执行以下命令，在不启动 VS Code 的情况下进行验证：

```powershell
gcc -g -O0 main.c -o main.exe
gdb --batch -ex "break square" -ex "run" -ex "print x" main.exe
```

只有当程序能够停在 `square` 断点并打印出 `x` 时，才说明工具链正常。**若此步骤未通过，后续配置均无意义。**

- [ ] 命令行能编译、能断点

---

## 第 1 步 · 创建 `.vscode` 文件夹与 `tasks.json`

`.vscode` 必须创建在**本文件夹根目录下**（与 `main.c` 同级）。

`tasks.json` 需要编写两个任务：

- [ ] 一个使用 `gcc` 编译（参数中 **`-g` 不可省略**，否则没有调试信息）
- [ ] 一个使用 MSVC 的 `cl.exe` 编译（需要先加载 vcvars 环境，见下文）

**关键点：**

| 要点 | 说明 |
|---|---|
| `"type": "process"` | 优于 `"type": "shell"`：不进行 shell 解析，参数不会因引号处理而出错 |
| **必须加字符集参数** | gcc 加 `-finput-charset=UTF-8 -fexec-charset=GBK`；MSVC 用 `/source-charset:utf-8 /execution-charset:gbk`（**不能用 `/utf-8`**）。缺少时中文输出会显示为 `涓枃` 一类的乱码，见《配置指南》第 9 章第 6 节 |
| 输出目录需要预先创建 | gcc 不会自动创建目录。用 PowerShell 的 `[System.IO.Directory]::CreateDirectory()`（幂等），不要用 `cmd /c "if not exist ... mkdir ..."`（参数转义会导致失败，见《配置指南》第 9 章第 4 节） |
| **`-o` 输出路径必须用反斜杠** | JSON 中写作 `\\`。路径含中文时若使用正斜杠，`ld.exe` 会报 `cannot open output file`（见《配置指南》第 9 章第 5 节） |
| 任务 `label` | 使用便于记忆的名称，第 2 步需要引用该名称 |

MSVC 路线较为复杂（需要先加载 `vcvars64.bat`，才能获得 `INCLUDE`/`LIB` 环境变量）。
**不要使用 `.cmd` 编写**：在中文路径下，cmd 会按 GBK 解析文件，将注释读作控制字符；
此外，`/Fo:"...\"` 结尾的反斜杠会被当作转义引号，导致源文件参数丢失（报 `D8003`）。
使用 PowerShell 实现，可直接参考 `B-examples\01-c-single-file\.vscode\tools\build-msvc.ps1`。

- [ ] `tasks.json` 编写完成，且在命令面板（`Ctrl+Shift+P`）中执行 `Tasks: Run Task` 能够手动运行成功
- [ ] 运行程序，确认中文输出显示正常（若为乱码，回到上表第 2 行检查字符集参数）

---

## 第 2 步 · 编写 `launch.json`

两个配置，至少需要以下字段：

- [ ] `type`：GDB 路线填写 `cppdbg`，VS2022 路线填写 `cppvsdbg`（**不可写反**）
- [ ] `request`：`launch`
- [ ] `program`：exe 的路径
- [ ] `MIMode` + `miDebuggerPath`：**仅 `cppdbg` 需要**，指向 `gdb.exe`
- [ ] `preLaunchTask`：**必须与第 1 步的任务 `label` 完全一致**
- [ ] `cwd`、`args`、`environment` 按需填写

说明：

| 需求 | 编写方式 |
|---|---|
| 对任何 `.c` 文件都成立 | `program` 使用 `${workspaceFolder}/build/${fileBasenameNoExtension}.exe` |
| 使 scanf 能够输入 | `cppdbg` 设置 `"externalConsole": false`；`cppvsdbg` 设置 `"console": "integratedTerminal"` |

- [ ] 两个配置均编写完成

---

## 第 3 步 · 验证

- [ ] 在 `square` 函数的 `int result = x * x;` 所在行设置断点
- [ ] 按 F5，选择 GDB 路线，应停在断点处，且 `x` 显示为 `7`
- [ ] 按 F5，选择 VS2022 路线，同样应停在断点处
- [ ] 故意将 `preLaunchTask` 改错一个字，观察报错信息的形式（以便识别该错误）
- [ ] 将 `preLaunchTask` 恢复为正确值

---

## 第 4 步（可选）· 添加 `settings.json` 与 `c_cpp_properties.json`

这两个文件**不影响调试**，只影响代码补全与波浪线提示。

- [ ] 在 `settings.json` 中设置 `C_Cpp.default.compilerPath` 指向 gcc
- [ ] 确认编辑器中 `printf` 能被识别（没有红色波浪线）
