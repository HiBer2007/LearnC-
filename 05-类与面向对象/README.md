# 类与面向对象

本板块收录 **C++ 独有的类与 OOP 特性**——从「类是什么」一直到「模板能做什么」。

**它不是一份特性清单。** 本板块建立在一条判断上：

> [!IMPORTANT]
> **类与 OOP 是手段，不是目标。**
> 它们要解决的问题是**封装**：把数据与操作捆在一起、把不该看见的东西藏起来、
> 让改一处不会牵动全身。**命名空间、成员函数、重载、继承、模板，全都服务于这一件事。**
> **因此读本板块时要一直问：这个特性替我挡住了什么麻烦。**

这条判断的完整论述见《05-类与面向对象/00-导读：类与 OOP 是手段.md》第 1 节与第 2 节。
**读任何一章之前先读它。**
