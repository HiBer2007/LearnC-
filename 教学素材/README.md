## 使用须知

### 1. 版权头不要删

每个文件开头的注释块是**授权依据**。
例如 `STM32F103XX_FLASH.ld` 的文件头里就是完整的 BSD-3-Clause 条款。
**删掉它，授权就无从证明。**

### 2. 两类文件要区别对待

| | 教材作者自有 | 第三方（ST / ARM） |
|---|---|---|
| 例子 | NeoServerUpdateModpack、CPP讲解用 | CubeMX 生成文件、CMSIS |
| 许可 | GPL-3.0 / LGPL / 自有 | BSD-3-Clause / Apache-2.0 |
| 复制进教材 | 可以 | **可以，但必须保留版权声明** |

### 3. 链接仓库与内部模块的许可不同

在 NeoServerUpdateModpack 中：

- **内部模块**（`NeoCore`、`NeoBuild`、`NeoWorkspace` 等 27 个）→ **GPL-3.0**
- **链接仓库**（`CommonLoggerCPP`、`CrashTracker` 等 7 个）→ **LGPL-2.1**
- **nbtcpp** → 声明 LGPL-3.0

判断方法：看目录里的 `.git` 是**文件**还是**目录**，
或查 `git submodule status`。详见《版权与许可说明.md》第 2.2 节。
