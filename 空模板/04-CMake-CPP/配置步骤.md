本模板的步骤与 [`../03-CMake-C/配置步骤.md`](../03-CMake-C/配置步骤.md) **基本相同**，
此处仅说明不同之处。建议先完成模板 03。

## 与模板 03 的区别

| | 03（C） | 04（C++） |
|---|---|---|
| `CMakeLists.txt` | `LANGUAGES C` | `LANGUAGES CXX` |
| 标准变量 | `CMAKE_C_STANDARD` | `CMAKE_CXX_STANDARD` |
| 预设中的编译器 | `CMAKE_C_COMPILER: gcc` | `CMAKE_CXX_COMPILER: g++` |
| `.vscode` 的智能感知 | `gcc.exe` | `g++.exe` |

**`launch.json` 完全相同**：调试器不区分所编写的是 C 还是 C++。

---

## 现象验证：使用 `gcc` 编译 C++ 源码

```powershell
# 使用 gcc 编译 C++ 源码会失败
gcc -g -O0 src\main.cpp src\util.cpp -o x.exe
```

将出现大量 `undefined reference to std::cout` 报错。

**原因**：`gcc` 会按 C++ 语法编译 `.cpp`，但**不会链接 `libstdc++`**。

```powershell
# 改用 g++ 可以成功
g++ -g -O0 src\main.cpp src\util.cpp -o test.exe
```

- [ ] 复现一次该报错

> **说明**：MSVC 不存在该问题，`cl.exe` 按扩展名自动判断语言。
