# 配置步骤 · 07-standard-library/01-c-stdlib-toolbox（C 标准库综合）

本模板是**分阶段的整体演练**：成品是一个用 C 标准库写成的文本统计工具，
读一份文本文件，分词、数词频、排序、计时，最后打印一份报表；
另有一个 Win32 界面版显示同一份报表。
每个阶段结束时程序都能编译、能运行。怎么复制模板、怎么打开、遇到问题查哪里，
见 [`../../README.md`](../../README.md)，本文件不重复。

---

## 成品形态

做完这 5 个阶段之后，`app_cli.exe` 具备下面这些能力：

| 能力 | 由哪一阶段提供 |
|---|---|
| 把一个文本文件整个读进内存，数出字节数与行数 | 阶段 1 |
| 按「连续字母算一个词」的规则分词，统计词频 | 阶段 2 |
| 用 `qsort` 排序：次数降序，次数相同按字典序 | 阶段 3 |
| 两种计时来源对照：`clock()` 的 CPU 时间与 `time()` 的墙上时间 | 阶段 4 |
| 打印对齐的报表，前 10 名带柱状条 | 阶段 5 |

界面版 `app_gui_win32.exe` 把同一个核心模块生成的报表显示在窗口里。

## 阶段 1 · 读文件与数行

**要做什么**（都在 `src/textstats.c`）

- 1-1 `ts_read_file`：`fopen(path, "rb")`，用 `fseek` 到文件尾、`ftell` 量长度，
  再回到开头，`malloc` 出「长度 + 1」字节，`fread` 一次读进来并补 `'\0'`；
  任何一步失败都把 `strerror(errno)` 拼进 `err` 后返回 `NULL`
- 1-2 `ts_count_lines`：数 `'\n'` 的个数；最后一个字节不是 `'\n'` 且文件非空时再加一

**验收标准**

`Text`

```text
=== Stage 1: read file ===
path    : data/sample.txt
bytes   : 913
lines   : 16
```

**怎么自查**

| 你看到的 | 说明 |
|---|---|
| `open failed : data/sample.txt: No such file or directory` | 不在模板目录下运行，或者阶段 1-1 还没写 |
| `bytes : 0` | `ftell` 之后没有 `fseek(f, 0, SEEK_SET)` 回到开头，`fread` 从文件尾读，读到 0 字节 |
| `bytes : 914` | 长度多算了 1：`malloc` 要多分配 1 字节放 `'\0'`，但长度本身只算文件自己的字节 |
| `lines : 15` | 漏了「最后一个字节不是 `'\n'` 也要算一行」这条；用 `data/sample.txt` 时两处都对才能得到 16 |
| 换成 `data\missing.txt` 运行时崩溃 | 失败路径没写：`fopen` 返回 `NULL` 之后仍然 `fseek` |

## 阶段 2 · 分词与词频

**要做什么**

- 2-1 `ts_collect_words`：写一个循环扫过全文，`isalpha((unsigned char)c)` 为真就攒词；
  遇到分隔符就把词收尾（转小写、截断到 63 字符），在表里查一遍，
  有就 `count += 1`，没有就新加一条，同时把 `words` 加一

**验收标准**

`Text`

```text
=== Stage 2: tokenize and count ===
words   : 169
unique  : 100
```

**怎么自查**

| 你看到的 | 说明 |
|---|---|
| `words : -1` | 占位实现还在：函数返回前没有把结果写回 `*out_words` |
| `unique : 169`，与 `words` 相等 | 每个词都被当成新词：查表那一步没有做，或者比较用了 `=` 而不是 `strcmp` |
| 数字与上面差几个 | `isalpha` 的实参没有转 `unsigned char`；另外数字与标点必须当分隔符，不能当词的一部分 |
| `unique : 100` 但前几名不对 | 计数没问题，排序有问题，去阶段 3 |
| 表里的词带大写字母 | 收尾时漏了 `tolower` |

## 阶段 3 · `qsort` 排序

**要做什么**

- 3-1 写比较函数 `int cmp(const void *a, const void *b)`：两个 `void *` 转回
  `const TsEntry *`，先比 `count`（降序），相等再 `strcmp` 比 `word`（升序）
- 3-2 `ts_sort_entries` 里调用 `qsort`，注意元素个数小于 2 时不必排

**验收标准**

`Text`

```text
=== Stage 3: sort with qsort ===
   1  the              16
   2  and               9
   3  a                 8
   4  is                6
   5  word              5
```

**怎么自查**

| 你看到的 | 说明 |
|---|---|
| 阶段 3 一行都没有 | 阶段 2 的 `unique` 还是 0，先回阶段 2 |
| 次序与上面不同，例如 `a` 排在 `the` 前面 | 比较函数里次数比反了方向 |
| 次数相同的那几个词次序每次都变 | 次数相等时没有用 `strcmp` 兜底，`qsort` 不保证稳定 |
| 次数大的词被排到后面且值很怪 | 比较函数写成 `return x->count - y->count;`，`long` 相减的结果被截成 `int`；改成两个分支分别返回 `1` 与 `-1` |

## 阶段 4 · 两种计时

**要做什么**

- 4-1 `ts_measure`：把「整份文本再分词一遍」重复 `repeat` 遍，
  用 `clock()` 量进程 CPU 时间（毫秒），用 `time()` 与 `difftime()` 量墙上时间（秒）

**验收标准**

`Text`

```text
=== Stage 4: timing ===
repeat       : 20000
cpu_ms       : 438.000
wall_s       : 0.000
note         : clock() 是 CPU 时间（毫秒级），time() 只有 1 秒分辨率
```

`cpu_ms` 随机器与构建类型变化，`wall_s` 打 0 是这一段工作的正常结果：
这段工作量还不到 1 秒，`time()` 读不出来。

`实测数据`
`Text`

```text
同一份源码、同一次 20000 遍的重复：
  MinGW gcc 15.2.0，Debug      cpu_ms = 438.000   wall_s = 0.000
  MSVC 19.44，Debug            cpu_ms = 857.000   wall_s = 1.000
```

**怎么自查**

| 你看到的 | 说明 |
|---|---|
| `cpu_ms : -1.000` | 占位实现还在 |
| `cpu_ms` 不随 `repeat` 变大 | 循环被写成了只跑一遍，或者 `repeat` 没有传进去 |
| 编译报 `implicit declaration of function 'timespec_get'` | 本机的 MinGW 链接的是 msvcrt，没有 C11 的 `timespec_get` 与 `TIME_UTC`。改用 `clock()` 与 `time()`，原因见《07-标准库/A-04-时间与日期：time.h.md》第 5.2 小节 |
| `wall_s` 一直是 0.000，怀疑写错了 | 这是 `time()` 的 1 秒分辨率造成的正常现象，把 `repeat` 调大十倍再看 |

## 阶段 5 · 报表

**要做什么**

- 5-1 `ts_write_report`：用 `snprintf` 一段段拼出报表，名次 `%2ld`、词 `%-14s`、
  次数 `%4ld`，后面跟两个空格与柱状条（`#` 重复 `min(count, 40)` 次），
  只打印前 10 名，返回写出的字符数

**验收标准**

`Text`

```text
=== Stage 5: report ===
file    : data/sample.txt
bytes   : 913
lines   : 16
words   : 169
unique  : 100
top 10  :
   1  the              16  ################
   2  and               9  #########
   3  a                 8  ########
   4  is                6  ######
   5  word              5  #####
   6  c                 4  ####
   7  be                3  ###
   8  data              3  ###
   9  its               3  ###
  10  library           3  ###
```

**怎么自查**

| 你看到的 | 说明 |
|---|---|
| 只有 `(TODO stage 5-1: ...)` 一行 | 占位实现还在 |
| 柱状条长短与次数不成比例 | 忘了取 `min(count, 40)`，或者柱状条字符串没写结尾的 `'\0'` |
| 名次列左对齐、词列左对齐但次数没有右对齐 | 格式串写成了 `%-2ld` 或 `%-4ld`，对照上面的输出逐列核对 |
| 报表末尾多出一个空行 | `snprintf` 的返回值没有累加，后一段覆盖了前一段，或者多打了一次 `'\n'` |
| 打印到一半被截断 | 每次 `snprintf` 之后要把已写长度累加，剩余空间传 `cap - written` |

## 常见错误与排查

| 现象 | 原因与做法 |
|---|---|
| `implicit declaration of function 'timespec_get'` 或 `'TIME_UTC' undeclared` | 本机 MinGW 的 msvcrt 运行库没有 C11 的 `timespec_get`；用 `clock()`、`time()`、`difftime()`，见《07-标准库/A-04-时间与日期：time.h.md》第 5.2 小节 |
| MSVC 下每个 `fopen`、`strerror` 都报 `C4996` | MSVC 的弃用检查，不是 C 标准的要求。工程的 `CMakeLists.txt` 里已经为 `core` 加了 `_CRT_SECURE_NO_WARNINGS`，自己新建目标时要照样加 |
| 编译出现 `warning: 'to_wide' defined but not used` | 骨架预留的辅助函数暂时没被用到。本模板的占位实现里用 `(void)to_wide;` 一类写法压住了警告，补完界面连接之后可以删掉那几行 |
| `open failed : data/sample.txt: No such file or directory` | 不在模板目录下运行。相对路径以**当前工作目录**为基准，换目录运行就等于换文件 |
| 报表里所有词都只出现 1 次 | 查表时比较的是指针而不是内容，或者表里的词没有转小写 |
| 程序结束时崩溃，报 `invalid pointer` 一类 | `ts_read_file` 里失败路径漏了 `fclose`，或者缓冲区不是 `malloc` 得来的 |
| `cmake --preset msvc` 报 `Compatibility with CMake < 3.5 has been removed` | 预设文件被改过。本模板的 `CMakePresets.json` 里 `cmakeMinimumRequired` 是 3.21 |
| 冒烟脚本报「没有编号为 10031004 的控件」 | `-ReadId` 传参方式的问题，见上面「界面部分怎么用」的提示 |
