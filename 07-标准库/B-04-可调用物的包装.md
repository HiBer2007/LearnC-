**一段代码要留到以后再调用，必须先有地方存它。**

《05-类与面向对象/10-lambda 与函数对象.md》第 5 节把「把可调用物传出去」
的三种接收方式作过对照：函数指针只认最朴素的一种，
模板参数把类型完整保留下来，`std::function` 把类型藏起来。
那一节还测出 1 亿次调用的差距——模板参数 26 毫秒，`std::function` 95 毫秒。

那一节的重点在 lambda 本身：它是什么、捕获怎么工作、为什么类型唯一。
到了真要「把一段逻辑存起来、过一会儿再调」的时候，问题换了：
存到哪里去，类型怎么写，存进去之后还剩多少信息，
一次调用要多花多少——这些都属于标准库的用法，而不是 lambda 的语法。

本章节接着讲的就是这些。`std::function` 是唯一能把类型藏起来的那个，
因此它的接口、它装不下的东西、它那 32 字节里装的是什么，占了大半篇幅。
把实参提前固定下来曾经靠 `std::bind`，今天多数场合 lambda 更清楚，
两者的对照与取舍在中间一节。成员函数指针、`std::invoke` 与
`std::reference_wrapper` 是同一件事的另外三个侧面：怎么调用、
怎么统一地调用、怎么把一个引用放进容器。最后是函数视图——
一个不持有可调用物的包装，`std::function` 的轻量替代品。

C 里只有函数指针一种可调用物，也没有类型擦除。C 段的对照在
《07-标准库/A-05-工具与其它：stdlib 与杂项.md》第 2 节：那里讲 `qsort`
怎样靠一个函数指针把比较逻辑交给调用方，它的局限正是本章节要处理的问题。

# 第 1 节 `std::function`：把可调用物装进一个类型

**普通函数、lambda、仿函数、成员函数绑定结果，这四样东西的类型各不相同**，
因此不能放进同一个变量、同一个容器、同一个类成员。
`std::function` 用一个统一的类型把它们收下来，
代价是擦掉类型信息、要多一次间接调用。

## 1.1 它能装什么

只要满足「能像函数一样调用」，并且**可以拷贝**，就能装进 `std::function`。
签名的写法就是把返回类型和参数表写在模板参数里：
`std::function<int(int)>` 表示「收一个 `int`，返回一个 `int`」。

`C++`

```cpp
/* b04_fn_basic.cpp    编译：g++ -std=c++17 b04_fn_basic.cpp -o b04_fn_basic */
#include <cstdio>
#include <functional>

/* 普通函数 */
static int add_one(int x) { return x + 1; }

/* 仿函数：带状态，能记住被调了几次 */
struct Counter {
    int calls = 0;
    int operator()(int x) {
        ++calls;
        return x * calls;
    }
};

class Machine {
public:
    explicit Machine(int base) : base_(base) {}
    int apply(int x) const { return base_ + x; }

private:
    int base_;
};

int main() {
    std::printf("1. 同一个 std::function<int(int)> 变量，可以先后装四类可调用物\n");
    std::function<int(int)> f;

    f = add_one;
    std::printf("  装函数指针：f(10) = %d\n", f(10));

    f = [](int x) { return x * 100; };
    std::printf("  装无捕获 lambda：f(10) = %d\n", f(10));

    int factor = 7;
    f = [factor](int x) { return x * factor; };
    std::printf("  装有捕获 lambda：f(10) = %d\n", f(10));

    Counter c;
    f = c;                                          /* 仿函数被拷进 f 里 */
    std::printf("  装仿函数：f(10) = %d，f(10) = %d\n", f(10), f(10));
    std::printf("  外面那个 c.calls 仍然是 %d（f 里存的是副本）\n\n", c.calls);

    std::printf("2. 空状态：默认构造的 function 不能调用\n");
    std::function<int(int)> empty;
    std::printf("  empty 非空 = %d，empty ? 1 : 0 = %d\n", empty ? 1 : 0, empty ? 1 : 0);
    std::function<int(int)> from_null = nullptr;     /* 从 nullptr 构造也是空 */
    std::printf("  从 nullptr 构造：非空 = %d\n", from_null ? 1 : 0);
    try {
        std::printf("  调用空 function：");
        std::fflush(stdout);
        int r = empty(1);                            /* 抛 std::bad_function_call */
        std::printf("%d\n", r);
    } catch (const std::bad_function_call &e) {
        std::printf("抛出 std::bad_function_call：%s\n", e.what());
    }

    std::printf("3. 成员函数怎么装进去\n");
    Machine m(100);
    f = [&m](int x) { return m.apply(x); };          /* 用 lambda 包一层 */
    std::printf("  lambda 包成员函数：f(5) = %d\n", f(5));

    std::printf("4. 换成别的签名\n");
    std::function<double(double)> g = [](double x) { return x / 2.0; };
    std::printf("  std::function<double(double)>：g(9) = %.1f，sizeof = %zu\n",
                g(9.0), sizeof(g));
    std::function<void(const char *)> h = [](const char *s) { std::printf("  %s\n", s); };
    h("返回类型是 void 也可以");
    return 0;
}
```

`实测数据`
`Text`

```text

  装函数指针：f(10) = 11
  装无捕获 lambda：f(10) = 1000
  装有捕获 lambda：f(10) = 70
  装仿函数：f(10) = 20，f(10) = 10
  外面那个 c.calls 仍然是 0（f 里存的是副本）

2. 空状态：默认构造的 function 不能调用
  empty 非空 = 0，empty ? 1 : 0 = 0
  从 nullptr 构造：非空 = 0
  调用空 function：抛出 std::bad_function_call：bad_function_call
3. 成员函数怎么装进去
  lambda 包成员函数：f(5) = 105

  std::function<double(double)>：g(9) = 4.5，sizeof = 32

```

三处要点：

| 观察 | 说明 |
|---|---|
| `外面那个 c.calls 仍然是 0` | `f = c;` 存进去的是**副本**，此后 `f` 与 `c` 各有一份状态 |
| 「装仿函数」那行打印 `20` 再打印 `10` | 副本里的 `calls` 累加了，因此第二次是 `10 × 2` |
| 空 `function` 上调用 | 抛 `std::bad_function_call`，不是崩溃 |

> [!IMPORTANT]
> **`std::function` 是「可拷贝」的包装器，它复制被包装的对象。**
> 想让它改到外面那份状态，须装一个持有指针或引用的可调用物
> （第 4 节讲 `std::reference_wrapper`）；想共享状态，
> 装一个捕获了 `std::shared_ptr` 的 lambda。

## 1.2 空状态与 `bad_function_call`

默认构造的 `std::function` 是空的，`if (f)` 为假。
**在空的上调用不会返回一个默认值，而是抛异常**，这一点与函数指针不同
（空函数指针调用是未定义行为）。

`C++`

```cpp
/* b04_fn_empty.cpp    编译：g++ -std=c++17 b04_fn_empty.cpp -o b04_fn_empty */
#include <cstdio>
#include <functional>

int main() {
    std::function<int(int)> f;                       /* 默认构造：空的 */
    std::setvbuf(stdout, nullptr, _IONBF, 0);
    std::printf("f 非空 = %d\n", f ? 1 : 0);
    std::printf("直接调用空 function，异常没人接：\n");
    int r = f(1);                                    /* 抛 std::bad_function_call */
    std::printf("这一行不会执行，r = %d\n", r);
    return 0;
}
```

`实测数据`
`Text`

```text
f 非空 = 0
直接调用空 function，异常没人接：
terminate called after throwing an instance of 'std::bad_function_call'
  what():  bad_function_call
退出码 3
```

**异常没有人捕获，程序直接终止**（《04-语法/13-异常.md》第 5.3 小节）。
所以调用一个可能为空的 `std::function` 之前应当先判空，
或者在外面套一层 `try`；回调注册表这类场合，
「没注册」与「注册了一个空的」应当区分开。

## 1.3 32 字节里装的是什么，什么时候向堆要内存

`std::function` 要同时装下两件事：**被擦除的那个对象**，
以及**怎么调用它**——后者是一个编译期生成的转发函数。
libstdc++ 的做法是 32 字节里放三样东西：

`Text`

```text
std::function<int(int)>（32 字节）
├─ 小对象缓冲（16 字节）
│    └─ 装得下就把可调用物放在这里，装不下就改成放一个堆上的指针
├─ 调用转发函数的指针（8 字节）
└─ 管理这块存储的指针（8 字节）
```

`C++`

```cpp
/* b04_fn_size.cpp    编译：g++ -std=c++17 b04_fn_size.cpp -o b04_fn_size */
#include <array>
#include <cstdio>
#include <cstdlib>
#include <functional>
#include <new>

static long g_allocs = 0;                            /* 累计分配次数 */

void *operator new(std::size_t n) {
    ++g_allocs;
    void *p = std::malloc(n ? n : 1);
    if (!p) throw std::bad_alloc();
    return p;
}
void operator delete(void *p) noexcept { std::free(p); }
void operator delete(void *p, std::size_t) noexcept { std::free(p); }
void *operator new[](std::size_t n) { return operator new(n); }
void operator delete[](void *p) noexcept { operator delete(p); }
void operator delete[](void *p, std::size_t) noexcept { operator delete(p); }

static int free_fn(int x) { return x + 1; }

struct Functor {
    int operator()(int x) const { return x + 2; }
};

/* 捕获 N 个字节的 lambda，装进 std::function 时看会不会向堆要内存 */
template <std::size_t N>
static void probe(const char *what) {
    std::array<char, N> buf{};
    buf[0] = 1;
    auto lam = [buf](int x) { return x + (int)buf[0]; };

    long before = g_allocs;
    std::function<int(int)> f = lam;
    long used = g_allocs - before;

    std::printf("  %-26s sizeof(lambda) = %2zu   构造时分配 %ld 次   调用结果 %d\n",
                what, sizeof(lam), used, f(10));
}

int main() {
    std::printf("sizeof(std::function<int(int)>) = %zu\n", sizeof(std::function<int(int)>));
    std::printf("sizeof(函数指针)                 = %zu\n", sizeof(int (*)(int)));
    std::printf("sizeof(Functor)                  = %zu\n", sizeof(Functor));
    std::printf("sizeof(std::function<int(int)>) 与 void* 一样大吗：%d\n\n",
                sizeof(std::function<int(int)>) == sizeof(void *));

    std::printf("装不同大小的可调用物，看有没有堆分配：\n");
    {
        long before = g_allocs;
        std::function<int(int)> f = free_fn;
        std::printf("  %-26s sizeof(函数指针) = %2zu   构造时分配 %ld 次   调用结果 %d\n",
                    "普通函数", sizeof(&free_fn), g_allocs - before, f(10));
    }
    {
        long before = g_allocs;
        std::function<int(int)> f = Functor{};
        std::printf("  %-26s sizeof(仿函数)   = %2zu   构造时分配 %ld 次   调用结果 %d\n",
                    "无状态仿函数", sizeof(Functor), g_allocs - before, f(10));
    }
    probe<1>("捕获 1 字节");
    probe<4>("捕获 4 字节");
    probe<8>("捕获 8 字节");
    probe<16>("捕获 16 字节");
    probe<24>("捕获 24 字节");
    probe<32>("捕获 32 字节");
    probe<64>("捕获 64 字节");

    std::printf("\n拷贝一个已经装好的 std::function：\n");
    {
        std::array<char, 64> big{};
        auto lam = [big](int x) { return x + (int)big[0]; };
        std::function<int(int)> f = lam;
        long before = g_allocs;
        std::function<int(int)> g = f;               /* 拷贝：大的要再分配一次 */
        std::printf("  拷贝 64 字节的那个：分配 %ld 次\n", g_allocs - before);

        std::function<int(int)> h = free_fn;
        before = g_allocs;
        std::function<int(int)> k = h;               /* 小的不用分配 */
        std::printf("  拷贝普通函数那个：分配 %ld 次\n", g_allocs - before);
        std::printf("  调用结果 %d %d\n", g(1), k(1));
    }
    std::printf("累计分配次数 = %ld\n", g_allocs);
    return 0;
}
```

`实测数据`

| 可调用物的大小 | 构造 `std::function` 时的分配次数 |
|---|---|
| 0 ~ 16 字节 | **0 次**，直接放进内部缓冲 |
| 24 字节及以上 | **1 次**，改为在堆上存 |

**分界线落在 16 字节**：这正是那个小对象缓冲的大小。
被包装的对象不超过 16 字节时，`std::function` 一个字节也不额外要；
超过了就要向堆要一次，而且**每次拷贝它都要再要一次**——
实测里拷贝那个 64 字节的 lambda 又分配了 1 次。

> [!TIP]
> **想让 `std::function` 不分配内存，就让被捕获的东西不超过 16 字节。**
> 一个指针、一个 `int`、两个 `int` 都在这个范围内；
> 捕获一个大结构体就会掉到堆上，此时改成捕获它的指针或
> `std::shared_ptr` 更合适——但须自行管好生命周期。

## 1.4 代价：一次间接调用

《05-类与面向对象/10-lambda 与函数对象.md》第 5.3 小节测过 1 亿次调用：
模板参数 26 毫秒，`std::function` 95 毫秒。同一件事再加上函数指针，一起测量：

`C++`

```cpp
/* b04_fn_cost.cpp    编译：g++ -std=c++17 -O2 b04_fn_cost.cpp -o b04_fn_cost */
#include <chrono>
#include <cstdio>
#include <functional>

/* 接收方三种写法，函数体做同一件事 */
template <class F>
long long sum_template(F f, int n) {
    long long s = 0;
    for (int i = 0; i < n; ++i) s += f(i);
    return s;
}

long long sum_function_pointer(int (*f)(int), int n) {
    long long s = 0;
    for (int i = 0; i < n; ++i) s += f(i);
    return s;
}

long long sum_std_function(const std::function<int(int)> &f, int n) {
    long long s = 0;
    for (int i = 0; i < n; ++i) s += f(i);
    return s;
}

static int and_seven(int x) { return x & 7; }

static double ms_since(std::chrono::steady_clock::time_point t0) {
    return std::chrono::duration<double, std::milli>(
               std::chrono::steady_clock::now() - t0).count();
}

int main() {
    const int n = 100000000;                         /* 1 亿次 */
    auto f = [](int x) { return x & 7; };

    auto t0 = std::chrono::steady_clock::now();
    long long a = sum_template(f, n);
    double t_tmpl = ms_since(t0);

    auto t1 = std::chrono::steady_clock::now();
    long long b = sum_template(and_seven, n);        /* 模板参数收函数指针 */
    double t_tmpl_fp = ms_since(t1);

    auto t2 = std::chrono::steady_clock::now();
    long long c = sum_function_pointer(and_seven, n);
    double t_fp = ms_since(t2);

    std::function<int(int)> sf = f;
    auto t3 = std::chrono::steady_clock::now();
    long long d = sum_std_function(sf, n);
    double t_std = ms_since(t3);

    std::printf("%d 次调用，结果一致 = %d\n", n, (a == b && b == c && c == d));
    std::printf("  模板参数收 lambda      %7.1f 毫秒\n", t_tmpl);
    std::printf("  模板参数收函数指针      %7.1f 毫秒\n", t_tmpl_fp);
    std::printf("  函数指针形参            %7.1f 毫秒\n", t_fp);
    std::printf("  std::function 形参      %7.1f 毫秒\n", t_std);
    std::printf("  std::function ÷ 模板参数 = %.1f 倍\n", t_std / t_tmpl);
    std::printf("  std::function ÷ 函数指针 = %.1f 倍\n", t_std / t_fp);
    return 0;
}
```

```text
  模板参数收函数指针         26.1 毫秒
```

| 接收方式 | 1 亿次调用 | 相对模板参数 |
|---|---|---|
| 模板参数收 lambda | 26.1 毫秒 | 1.0 |
| 模板参数收函数指针 | 26.1 毫秒 | 1.0 |
| 函数指针形参 | 26.2 毫秒 | 1.0 |
| `std::function` 形参 | **95.4 毫秒** | **3.7** |

**三条「看得见函数体」的路一样快，`std::function` 慢到 3.6 倍。**
原因不是它有额外的语法，而是它可以接收任何可调用物**这件事本身**：
编译器在调用点只看到一个签名，看不到函数体，因此内联与向量化都做不了
（《05-类与面向对象/11-模板.md》第 8.4 小节）。

函数指针同样是间接调用，为什么和模板一样快：
因为那个函数体在同一个编译单元里可见，编译器把它内联掉了，
循环于是和模板版一样被向量化。

> [!IMPORTANT]
> **`std::function` 的代价是「编译器看不见函数体」，不是「多一层函数调用」。**
> 因此它该用在哪很清楚：**需要把类型统一起来的时候**——
> 放进容器、写成类成员、跨接口传递。只是随手传给一个模板函数时不必用它。
> 反过来，一次回调花 1 微秒，`std::function` 的十纳秒开销根本不算什么。

## 1.5 它装不下的东西

`std::function` 要求被包装的对象**可拷贝**。

`文档`

> "Requires: F shall be CopyConstructible."
>
> —— N4659 §23.14.13.2.1/7

因此捕获了 `std::unique_ptr` 这类只能移动的对象的 lambda 存不进去
（《05-类与面向对象/05-拷贝与移动.md》第 4 节）。

`C++`

```cpp
/* b04_fn_moveonly_err.cpp    编译：g++ -std=c++17 b04_fn_moveonly_err.cpp -o b04_fn_moveonly_err （失败） */
#include <functional>
#include <memory>

int main() {
    auto p = std::make_unique<int>(7);
    std::function<int()> f = [q = std::move(p)] { return *q; };   /* 闭包只能移动 */
    return f();
}
```

`实测数据`
`Text`

```text
H:/mingw64/lib/gcc/x86_64-w64-mingw32/15.2.0/include/c++/bits/std_function.h:441:69:
  error: static assertion failed: std::function target must be copy-constructible
  441 |           static_assert(is_copy_constructible<__decay_t<_Functor>>::value,
      |                                                                     ^~~~~
  note: 'std::integral_constant<bool, false>::value' evaluates to false
```

报错落在标准库的 `static_assert` 上，措辞很直白：
**`std::function` 的目标必须可拷贝构造**。

需要装只能移动的可调用物时有两条路：

| 做法 | 版本 | 说明 |
|---|---|---|
| 捕获 `std::shared_ptr` 而不是 `unique_ptr` | C++11 起 | 共享所有权，闭包可拷贝，改动最小的绕法 |
| `std::move_only_function` | **C++23** | 官方给只移动的可调用物准备的包装器 |

`std::move_only_function` 是一个类型，住在 `<functional>` 里，不是单独的头文件，
C++23 起才有。本机加 `-std=c++23` 能编译过，加 `-std=c++17` 或 `-std=c++20` 编译时
都报 `error: 'move_only_function' is not a member of 'std'`。
本教材基准是 C++17，能用的绕法是第一条。

# 第 2 节 `std::bind`：把实参固定下来

调用一个函数之前要把一部分实参先定下来，这种需求叫**部分应用**。
`std::bind` 是 C++11 给出的通用做法：**没给的实参用占位符 `_1`、`_2` 标出来**，
给了的就固定住。它今天仍然能用，但多数场合 lambda 写出来更短也更清楚。

## 2.1 占位符与固定实参

占位符 `_1`、`_2`、`_3` 在 `std::placeholders` 里，
它们的编号指的是**调用时实参的位置**，与它们在参数表里排第几无关。

`C++`

```cpp
/* b04_bind_basic.cpp    编译：g++ -std=c++17 b04_bind_basic.cpp -o b04_bind_basic */
#include <cstdio>
#include <functional>

static int add(int a, int b) { return a + b; }
static int sub(int a, int b) { return a - b; }
static void print3(int a, int b, int c) { std::printf("  %d %d %d\n", a, b, c); }

using namespace std::placeholders;                   /* 让 _1、_2 直接可用 */

int main() {
    std::printf("1. 固定一个实参，剩下的留给调用方\n");
    auto add10  = std::bind(add, _1, 10);            /* 第一个实参待定，第二个固定为 10 */
    auto from10 = std::bind(add, 10, _1);            /* 反过来 */
    std::printf("  std::bind(add, _1, 10)(5) = %d（等于 add(5, 10)）\n", add10(5));
    std::printf("  std::bind(add, 10, _1)(5) = %d（等于 add(10, 5)）\n\n", from10(5));

    std::printf("2. 交换实参顺序\n");
    auto swap_args = std::bind(sub, _2, _1);
    std::printf("  std::bind(sub, _2, _1)(3, 10) = %d（等于 sub(10, 3)）\n\n", swap_args(3, 10));

    std::printf("3. 同一个占位符用两次\n");
    auto twice = std::bind(add, _1, _1);
    std::printf("  std::bind(add, _1, _1)(7) = %d\n\n", twice(7));

    std::printf("4. 一次打乱三个实参\n");
    auto p = std::bind(print3, _3, _1, _2);
    p(1, 2, 3);                                      /* 按参数表打印 3 1 2 */
    std::printf("\n");

    std::printf("5. 同一件事写成 lambda\n");
    auto add10_l = [](int x) { return add(x, 10); };
    auto swap_l  = [](int a, int b) { return sub(b, a); };
    auto p_l     = [](int a, int b, int c) { print3(c, a, b); };
    std::printf("  lambda add10(5)    = %d\n", add10_l(5));
    std::printf("  lambda swap(3, 10) = %d\n", swap_l(3, 10));
    p_l(1, 2, 3);
    return 0;
}
```

`实测数据`
`Text`

```text
1. 固定一个实参，剩下的留给调用方
  std::bind(add, _1, 10)(5) = 15（等于 add(5, 10)）
  std::bind(add, 10, _1)(5) = 15（等于 add(10, 5)）

2. 交换实参顺序
  std::bind(sub, _2, _1)(3, 10) = 7（等于 sub(10, 3)）

3. 同一个占位符用两次
  std::bind(add, _1, _1)(7) = 14

4. 一次打乱三个实参
  3 1 2

5. 同一件事写成 lambda
  lambda add10(5)    = 15
  lambda swap(3, 10) = 7
  3 1 2
```

**`_1` 与 `_2` 是「调用时的第几个实参」，不是「参数表里的第几个位置」。**
第 3 段把 `_1` 用了两次，于是同一个实参被传了两遍。

## 2.2 绑定成员函数

成员函数比普通函数多一个隐含参数：对象。`std::bind` 把对象写在第一个实参的位置，
`std::placeholders::_1` 往后才对应真正的参数。**对象按值传时 `bind` 存的是副本**，
这一点与 `std::function` 的行为一致，也是 `bind` 最容易出错的地方。

`C++`

```cpp
/* b04_bind_member.cpp    编译：g++ -std=c++17 b04_bind_member.cpp -o b04_bind_member */
#include <cstdio>
#include <functional>
#include <string>
#include <vector>

class Account {
public:
    explicit Account(std::string owner) : owner_(std::move(owner)) {}

    void deposit(int amount) {
        balance_ += amount;
        std::printf("  %s：存入 %d，余额 %d\n", owner_.c_str(), amount, balance_);
    }
    int balance() const { return balance_; }

private:
    std::string owner_;
    int         balance_ = 0;
};

using namespace std::placeholders;

int main() {
    Account acc("甲");
    acc.deposit(1000);

    std::printf("\n1. 绑定成员函数：被绑的对象写在第一个实参的位置\n");
    auto bal = std::bind(&Account::balance, &acc);            /* 对象用指针：指向原对象 */
    auto dep = std::bind(&Account::deposit, &acc, _1);
    dep(500);
    std::printf("  bind(&Account::balance, &acc)() = %d\n\n", bal());

    std::printf("2. 对象用指针与用 std::ref，效果相同\n");
    auto dep_ptr = std::bind(&Account::deposit, &acc, _1);
    auto dep_ref = std::bind(&Account::deposit, std::ref(acc), _1);
    dep_ptr(100);
    dep_ref(100);
    std::printf("  acc.balance() = %d\n\n", acc.balance());

    std::printf("3. 对象按值传：bind 存下来的是一份副本\n");
    Account victim("乙");
    victim.deposit(1000);
    auto dep_val = std::bind(&Account::deposit, victim, _1);  /* 少写了 & 或 std::ref */
    dep_val(777);
    std::printf("  调用之后，外面那个 victim.balance() = %d\n", victim.balance());
    std::printf("  777 加在了 bind 内部那份副本上，外面的对象一个字节也没动\n\n");

    std::printf("4. 同一件事写成 lambda\n");
    auto dep_l = [&acc](int amount) { acc.deposit(amount); };
    auto bal_l = [&acc] { return acc.balance(); };
    dep_l(50);
    std::printf("  lambda 版本：acc.balance() = %d\n\n", bal_l());

    std::printf("5. 成员函数指针可以像普通值一样传递\n");
    std::vector<Account> accounts;
    accounts.emplace_back("丙");
    accounts.emplace_back("丁");
    accounts[0].deposit(10);
    accounts[1].deposit(20);

    auto deposit_all = [](std::vector<Account> &v, int amount) {
        for (Account &a : v) a.deposit(amount);
    };
    std::printf("  批量存 5：\n");
    deposit_all(accounts, 5);

    int (Account::*getter)() const = &Account::balance;       /* 成员函数指针本身是一个值 */
    std::printf("  用成员函数指针取余额：%d，%d\n",
                (accounts[0].*getter)(), (accounts[1].*getter)());
    return 0;
}
```

`实测数据`
`Text`

```text
  甲：存入 1000，余额 1000

  甲：存入 500，余额 1500
  bind(&Account::balance, &acc)() = 1500

2. 对象用指针与用 std::ref，效果相同
  甲：存入 100，余额 1600
  甲：存入 100，余额 1700
  acc.balance() = 1700

3. 对象按值传：bind 存下来的是一份副本
  乙：存入 1000，余额 1000
  乙：存入 777，余额 1777
  调用之后，外面那个 victim.balance() = 1000
  777 加在了 bind 内部那份副本上，外面的对象一个字节也没动

4. 同一件事写成 lambda
  甲：存入 50，余额 1750
  lambda 版本：acc.balance() = 1750

5. 成员函数指针可以像普通值一样传递
  丙：存入 10，余额 10
  丁：存入 20，余额 20
```

第 3 段是最典型的错误：**`dep_val(777)` 打印出「余额 1777」，
看起来一切正常，外面那个对象的余额却还是 1000。**
写成 `std::ref(victim)` 或 `&victim` 才会改到原对象。

> [!WARNING]
> **`std::bind` 默认按值保存每一个绑定的实参**，对象也不例外。
> 想改到外面那份对象，必须显式写 `&对象`、`std::ref(对象)`
> 或 `std::cref`。这个错误的后果是静默的：程序不报错，结果不对。

## 2.3 与 lambda 的取舍

同一件事的两种写法如下：

`C++`

```cpp
/* b04_bind_vs_lambda.cpp    编译：g++ -std=c++17 b04_bind_vs_lambda.cpp -o b04_bind_vs_lambda */
#include <cstdio>
#include <functional>
#include <string>
#include <vector>

struct Order {
    int         id;
    int         amount;
    std::string user;
};

static int add(int a, int b) { return a + b; }
static int scale(int a, int k) { return a * k; }
static void note(const char *who, const char *what) {
    std::printf("  [%s] %s\n", who, what);
}

int main() {
    std::vector<Order> orders = {{1, 30, "甲"}, {2, 70, "乙"}, {3, 50, "甲"}};

    std::printf("1. 取一个字段\n");
    auto amount_bind   = std::bind(&Order::amount, std::placeholders::_1);
    auto amount_lambda = [](const Order &o) { return o.amount; };
    std::printf("  bind   ：%d\n", amount_bind(orders[0]));
    std::printf("  lambda ：%d\n", amount_lambda(orders[0]));

    std::printf("2. 固定一个实参\n");
    auto add10_bind   = std::bind(add, std::placeholders::_1, 10);
    auto add10_lambda = [](int x) { return add(x, 10); };
    std::printf("  bind   ：%d\n", add10_bind(5));
    std::printf("  lambda ：%d\n", add10_lambda(5));

    std::printf("3. 在一次调用里套两层\n");
    auto f_bind   = std::bind(scale, std::bind(add, std::placeholders::_1, 10), 2);
    auto f_lambda = [](int x) { return scale(add(x, 10), 2); };
    std::printf("  bind   ：%d\n", f_bind(5));
    std::printf("  lambda ：%d\n", f_lambda(5));

    std::printf("4. 多传的实参\n");
    note("甲", "存了 10");
    auto note_bind = std::bind(note, "乙", std::placeholders::_1);
    std::printf("  bind 把第一个实参固定成 \"乙\"：\n");
    note_bind("存了 20");
    note_bind("存了 30", "这是多余的第四个实参");   /* 多余的实参被静默忽略 */

    std::printf("5. 大小与拷贝\n");
    auto with_capture = [k = 10](int x) { return add(x, k); };
    std::printf("  sizeof(bind 表达式)       = %2zu\n", sizeof(add10_bind));
    std::printf("  sizeof(无捕获的 lambda)   = %2zu\n", sizeof(amount_lambda));
    std::printf("  sizeof(捕获一个 int 的)   = %2zu\n", sizeof(with_capture));
    std::printf("  sizeof(std::function<int(int)>)  = %zu\n", sizeof(std::function<int(int)>));
    return 0;
}
```

`实测数据`
`Text`

```text
1. 取一个字段
  bind   ：30
  lambda ：30
2. 固定一个实参
  bind   ：15
  lambda ：15
3. 在一次调用里套两层
  bind   ：30
  lambda ：30
4. 多传的实参
  [甲] 存了 10
  bind 把第一个实参固定成 "乙"：
  [乙] 存了 20
  [乙] 存了 30
5. 大小与拷贝
  sizeof(bind 表达式)       = 16
  sizeof(无捕获的 lambda)   =  1
  sizeof(捕获一个 int 的)   =  4
  sizeof(std::function<int(int)>)  = 32
```

同一件事的两种写法对照：

| 要做的事 | `std::bind` | lambda |
|---|---|---|
| 固定一个实参 | `std::bind(add, _1, 10)` | `[](int x) { return add(x, 10); }` |
| 交换两个实参 | `std::bind(sub, _2, _1)` | `[](int a, int b) { return sub(b, a); }` |
| 取一个成员 | `std::bind(&Order::amount, _1)` | `[](const Order &o) { return o.amount; }` |
| 套两层 | `std::bind(scale, std::bind(add, _1, 10), 2)` | `[](int x) { return scale(add(x, 10), 2); }` |

四行里 lambda 都多写几个字符，但**参数从哪来、返回什么，一眼看得出来**。
`bind` 那一列要读到第二层才知道 `_1` 去了哪里，实参一多就更难看懂。

三条具体的取舍理由：

| 理由 | 说明 |
|---|---|
| 报错难读 | `bind` 的返回类型是一长串内部类型，写错时的错误信息里全是它 |
| 大小 | 空的 `bind` 表达式也是 16 字节，而捕获一个 `int` 的 lambda 只有 4 字节（第 2.3 小节） |
| 多余的实参被吞掉 | 第 4 段里 `note_bind("存了 30", "多余的")` 照常执行，多出来的实参无声消失 |

> [!IMPORTANT]
> **今天写新代码，需要「固定实参」时优先写 lambda。**
> `std::bind` 仍然该认识——它在老代码里到处都是，
> 而且绑定成员函数时 `std::bind(&T::f, &obj, _1)` 这种写法仍然常见。
> **但不要主动用它去写新东西**，除非要绑定的实参个数在写代码时还不知道
> （那属于模板元编程的范畴，见《05-类与面向对象/12-模板的高阶使用.md》第 4 节）。

C++20 起标准库给了两个更清楚的替代品：`std::bind_front`（C++20）
与 `std::bind_back`（C++23），它们只做「把前几个（或后几个）实参钉住」这一件事，
不涉及占位符重排，因此返回类型的报错也短得多。

# 第 3 节 成员函数指针与统一调用

`std::bind` 能绑成员函数，但它的语法重。**标准库另外给了两个更轻的件**：
`std::mem_fn` 只管把成员函数变成一个可调用对象，
`std::invoke` 只管把「调用」这件事在各种可调用物上统一起来。

## 3.1 `std::mem_fn`

`std::mem_fn(&T::f)` 返回一个可调用对象，它既能接对象，也能接对象指针，
还能接智能指针。**只做这一件事，没有占位符，没有绑定。**

`C++`

```cpp
/* b04_memfn.cpp    编译：g++ -std=c++17 b04_memfn.cpp -o b04_memfn */
#include <cstdio>
#include <functional>
#include <string>
#include <vector>

class Item {
public:
    Item(std::string name, int price) : name_(std::move(name)), price_(price) {}
    const std::string &name() const { return name_; }
    int price() const { return price_; }
    bool cheap() const { return price_ < 50; }
    void discount(int percent) { price_ = price_ * (100 - percent) / 100; }

private:
    std::string name_;
    int         price_;
};

int main() {
    std::vector<Item> items;
    items.emplace_back("书", 80);
    items.emplace_back("笔", 12);
    items.emplace_back("本", 30);
    items.emplace_back("包", 200);

    std::printf("1. mem_fn 把成员函数变成一个可调用对象\n");
    auto price_of = std::mem_fn(&Item::price);
    std::printf("  price_of(items[0]) = %d\n", price_of(items[0]));
    std::printf("  price_of(&items[1]) = %d（指针也行）\n\n", price_of(&items[1]));

    std::printf("2. 判断有没有便宜货\n");
    auto is_cheap = std::mem_fn(&Item::cheap);
    std::printf("  items[1] 便宜吗：%d，items[3] 便宜吗：%d\n\n",
                is_cheap(items[1]) ? 1 : 0, is_cheap(items[3]) ? 1 : 0);

    std::printf("3. 数一数有几个便宜货（手写循环，容器的算法部分归 08 板块）\n");
    int n = 0;
    for (const Item &it : items) {
        if (is_cheap(it)) ++n;
    }
    std::printf("  便宜的有 %d 个\n\n", n);

    std::printf("4. 统一打折\n");
    auto apply_discount = std::mem_fn(&Item::discount);
    for (Item &it : items) apply_discount(it, 10);
    for (const Item &it : items) {
        std::printf("  %s：%d\n", it.name().c_str(), it.price());
    }
    std::printf("\n");

    std::printf("5. 与 bind、lambda 写同一件事\n");
    auto via_bind   = std::bind(&Item::price, std::placeholders::_1);
    auto via_lambda = [](const Item &it) { return it.price(); };
    std::printf("  bind   = %d\n", via_bind(items[0]));
    std::printf("  lambda = %d\n", via_lambda(items[0]));
    std::printf("  mem_fn = %d\n", price_of(items[0]));
    std::printf("  三者结果一致：%d\n",
                via_bind(items[0]) == via_lambda(items[0]) &&
                via_lambda(items[0]) == price_of(items[0]));
    return 0;
}
```

`实测数据`
`Text`

```text

  price_of(items[0]) = 80
  price_of(&items[1]) = 12（指针也行）

2. 判断有没有便宜货
  items[1] 便宜吗：1，items[3] 便宜吗：0

3. 数一数有几个便宜货（手写循环，容器的算法部分归 08 板块）
  便宜的有 2 个

4. 统一打折
  书：72
  笔：10
  本：27
  包：180

5. 与 bind、lambda 写同一件事
  bind   = 72
  lambda = 72
  mem_fn = 72
  三者结果一致：1
```

`std::mem_fn` 的价值在「**不用写 `_1`**」：同一个可调用对象
既能接左值对象、右值对象、对象指针，也能接 `shared_ptr` / `unique_ptr`，
而调用处只是 `f(x)`。这比 `std::bind(&Item::price, _1)` 短，
也比手写 lambda 更通用。

`std::mem_fn` 是 C++11 起的；更早的 `std::mem_fun` 与 `std::mem_fun_ref`
在 C++17 被弃用、C++20 移除，看到它们就知道代码有多旧。

## 3.2 `std::invoke`：四种调用写法合成一种

调用的写法在 C++ 里有四种：普通调用 `f(x)`、成员函数调用 `(o.*pmf)(x)`、
通过指针的成员调用 `(p->*pmf)(x)`、取数据成员 `o.*pmd`。
`std::invoke` 把四种统一成 `std::invoke(f, args...)`。

`C++`

```cpp
/* b04_invoke.cpp    编译：g++ -std=c++17 b04_invoke.cpp -o b04_invoke */
#include <cstdio>
#include <functional>
#include <string>

static int free_fn(int x) { return x + 1; }

struct Functor {
    int operator()(int x) const { return x + 2; }
};

struct Widget {
    std::string name;
    int         size = 0;

    int grow(int by) {
        size += by;
        return size;
    }
    int area() const { return size * size; }
};

/* 一个不关心可调用物到底是什么的转发函数 */
template <class F, class... Args>
auto call_it(F &&f, Args &&...args) -> decltype(std::invoke(std::forward<F>(f),
                                                            std::forward<Args>(args)...)) {
    return std::invoke(std::forward<F>(f), std::forward<Args>(args)...);
}

int main() {
    std::printf("1. std::invoke 把四种调用写法合成一种\n");
    std::printf("  普通函数          %d\n", std::invoke(free_fn, 1));
    std::printf("  仿函数            %d\n", std::invoke(Functor{}, 1));
    std::printf("  lambda            %d\n", std::invoke([](int x) { return x + 3; }, 1));

    Widget w{"甲", 4};
    std::printf("  成员函数（对象）  %d\n", std::invoke(&Widget::grow, w, 1));
    std::printf("  成员函数（指针）  %d\n", std::invoke(&Widget::area, &w));
    std::printf("  数据成员（对象）  %s\n", std::invoke(&Widget::name, w).c_str());
    std::printf("  数据成员（指针）  %d\n", std::invoke(&Widget::size, &w));
    std::printf("\n");

    std::printf("2. 上面这些写法，不用 invoke 时各写各的\n");
    std::printf("  free_fn(1)              = %d\n", free_fn(1));
    std::printf("  Functor{}(1)            = %d\n", Functor{}(1));
    std::printf("  (w.*&Widget::grow)(1)   = %d\n", (w.*&Widget::grow)(1));
    std::printf("  ((&w)->*&Widget::area)() = %d\n", ((&w)->*&Widget::area)());
    std::printf("  w.*&Widget::name        = %s\n", (w.*&Widget::name).c_str());
    std::printf("  分别是指针就用 .*，是对象指针就用 ->*\n\n");

    std::printf("3. 转发函数：一份代码收下所有可调用物\n");
    std::printf("  call_it(free_fn, 10)          = %d\n", call_it(free_fn, 10));
    std::printf("  call_it(Functor{}, 10)        = %d\n", call_it(Functor{}, 10));
    std::printf("  call_it(&Widget::area, w)     = %d\n", call_it(&Widget::area, w));
    std::printf("  call_it(&Widget::name, w)     = %s\n", call_it(&Widget::name, w).c_str());
    std::printf("  最后一个取的是数据成员，invoke 也照调不误\n\n");

    std::printf("4. 与 std::function 的关系\n");
    std::function<int(int)> f = free_fn;
    std::printf("  std::function 也是用 invoke 实现的：f(1) = %d\n", f(1));
    std::printf("  std::invoke(f, 1) = %d\n", std::invoke(f, 1));
    return 0;
}
```

`实测数据`
`Text`

```text

  普通函数          2
  仿函数            3
  lambda            4

  成员函数（指针）  25
  数据成员（对象）  甲
  数据成员（指针）  5

2. 上面这些写法，不用 invoke 时各写各的
  free_fn(1)              = 2

  w.*&Widget::name        = 甲
```

**`std::invoke` 是「写库的人用的件」。** 自己写一个接收可调用物的模板函数时，
函数体里写 `std::invoke(f, args...)` 而不是 `f(args...)`，
就能同时支持成员函数指针和数据成员指针，而调用方完全不用改。
`std::function`、`std::mem_fn`、`std::bind` 内部走的都是它。

`std::invoke` 是 **C++17** 起才有的。在那之前，
标准库内部用的是自己的一份 `INVOKE` 实现，用户写不出来。
本机基准就是 C++17，可以直接用。

# 第 4 节 `std::reference_wrapper`：能放进容器的引用

引用不能放进容器——`std::vector<T &>` 编译不过。
`std::reference_wrapper<T>` 就是一个**可以拷贝、可以赋值的引用**，
大小与指针相同，用起来与引用几乎一样。

## 4.1 一个能放进容器的引用

`C++`

```cpp
/* b04_refwrap.cpp    编译：g++ -std=c++17 b04_refwrap.cpp -o b04_refwrap */
#include <cstdio>
#include <functional>
#include <vector>

struct Player {
    const char *name;
    int         score = 0;
};

/* 按值收：拿到的是副本，改不到外面 */
static void add_by_value(Player p, int n) { p.score += n; }

/* 按引用收：改得到外面 */
static void add_by_ref(Player &p, int n) { p.score += n; }

int main() {
    Player a{"甲", 10};
    Player b{"乙", 20};

    std::printf("1. reference_wrapper 就是「一个可以放进容器的引用」\n");
    std::printf("  sizeof(std::reference_wrapper<Player>) = %zu，sizeof(Player *) = %zu\n",
                sizeof(std::reference_wrapper<Player>), sizeof(Player *));

    std::vector<std::reference_wrapper<Player>> board;   /* 容器里存的是引用，不是副本 */
    board.push_back(a);
    board.push_back(b);
    board.push_back(std::ref(a));                        /* 显式写法，与上一行等价 */

    std::printf("  容器里 %zu 项，改一项看会不会同步：\n", board.size());
    board[0].get().score += 5;
    std::printf("  board[0].get().score = %d，a.score = %d\n\n", board[0].get().score, a.score);

    std::printf("2. 对照：容器存值就改不到外面\n");
    std::vector<Player> copies;
    copies.push_back(a);
    copies[0].score += 100;
    std::printf("  copies[0].score = %d，a.score 仍然是 %d\n\n", copies[0].score, a.score);

    std::printf("3. cref 是只读版本\n");
    std::vector<std::reference_wrapper<const Player>> roster;
    roster.push_back(std::cref(a));
    roster.push_back(std::cref(b));
    for (const auto &r : roster) {
        std::printf("  %s：%d\n", r.get().name, r.get().score);
    }
    std::printf("  通过 cref 拿到的引用不能改：类型是 const Player &\n\n");

    std::printf("4. 解决 bind 按值拷贝的问题\n");
    Player c{"丙", 30};
    auto by_value = std::bind(add_by_value, c, std::placeholders::_1);
    auto by_ref   = std::bind(add_by_ref, std::ref(c), std::placeholders::_1);
    by_value(1000);
    by_ref(1000);
    std::printf("  by_value(1000) 之后 c.score = %d（bind 存的是副本）\n", c.score);
    std::printf("  by_ref(1000)   之后 c.score = %d（ref 让它去改原对象）\n\n", c.score);

    std::printf("5. std::function 也可以收 reference_wrapper\n");
    std::function<void(int)> f = std::bind(add_by_ref, std::ref(c), std::placeholders::_1);
    f(1);
    std::printf("  f(1) 之后 c.score = %d\n", c.score);
    return 0;
}
```

`实测数据`
`Text`

```text
1. reference_wrapper 就是「一个可以放进容器的引用」
  sizeof(std::reference_wrapper<Player>) = 8，sizeof(Player *) = 8
  容器里 3 项，改一项看会不会同步：
  board[0].get().score = 15，a.score = 15

2. 对照：容器存值就改不到外面
  copies[0].score = 115，a.score 仍然是 15

3. cref 是只读版本
  甲：15
  乙：20
  通过 cref 拿到的引用不能改：类型是 const Player &

4. 解决 bind 按值拷贝的问题
  by_value(1000) 之后 c.score = 1030（bind 存的是副本）
  by_ref(1000)   之后 c.score = 1030（ref 让它去改原对象）

5. std::function 也可以收 reference_wrapper
  f(1) 之后 c.score = 1031
```

第 4 段的两次打印看起来一样，是因为它们读的是同一个 `c.score`：
`by_value(1000)` 改的是 `bind` 内部的副本，`c` 没有被碰到；
`by_ref(1000)` 改的才是 `c` 本身。**要看出差别，须打印两份数据**
（第 2.2 小节那个程序里是这么做的）。

三个动作需要分清：

| 写法 | 得到什么 | 什么时候用 |
|---|---|---|
| `std::ref(x)` | `reference_wrapper<T>`，可改 | 容器存引用、`bind` 传引用 |
| `std::cref(x)` | `reference_wrapper<const T>`，只读 | 只需要看，不需要改 |
| `x` | 一份副本 | 确实想要副本时 |

`reference_wrapper` 有隐式转换到 `T &`，因此 `board[0].get()` 之外，
直接把它当引用传给函数也可以：`add_by_ref(board[0], 5)` 是合法的。

> [!CAUTION]
> **`reference_wrapper` 不管理生命周期。**
> 它只是一个指针，指向的对象析构之后它就成了悬垂引用，
> 用它得到的后果与用悬垂指针完全相同。
> 需要「可能已经没了」的语义时用 `std::weak_ptr`
> （《07-标准库/B-03-智能指针的用法.md》第 3.2 小节）。

# 第 5 节 函数视图：不持有可调用物的包装

`std::function` 存的是副本，因此拷贝它、构造它都可能分配内存。
**如果那个可调用物本来就在外面长期存活，只是想借来用一下**，
复制一份是浪费。函数视图（function view）解决的就是这件事。

## 5.1 C++17 里没有 `std::function_ref`

标准里的函数视图叫 `std::function_ref`，**它是 C++26 才进标准的**。

```cpp
    return v(1);
```

## 5.2 照 `string_view` 的思路自己写一个

`std::string_view` 是「不持有字符串的字符串」，16 字节；
函数视图就是「不持有可调用物的可调用物」，也是两个指针：

`Text`

```text
IntFnView（16 字节）
├─ 指向可调用物本身的指针（8 字节）—— 不复制，只借地址
└─ 指向一个编译期生成的转发函数的指针（8 字节）——「怎么调」写在这里
```

`C++`

```cpp
/* b04_funcview.cpp    编译：g++ -std=c++17 b04_funcview.cpp -o b04_funcview */
#include <cstdio>
#include <functional>
#include <type_traits>
#include <utility>

/* 一个不持有可调用物的视图：两个指针，16 字节。
   构造只接受左值，因为存下来的只是一个地址，右值活不过那句表达式。 */
class IntFnView {
public:
    template <class F,
              class = std::enable_if_t<
                  std::is_lvalue_reference_v<F> &&
                  !std::is_same_v<std::remove_cv_t<std::remove_reference_t<F>>, IntFnView>>>
    IntFnView(F &&f) noexcept {                      /* 只借地址，不复制对象 */
        if constexpr (std::is_function_v<std::remove_reference_t<F>>) {
            entity_.fn = &f;                         /* 普通函数：退化成一个函数指针 */
            call_      = [](const Entity &e, int x) -> int { return e.fn(x); };
        } else {
            entity_.obj = const_cast<void *>(static_cast<const void *>(std::addressof(f)));
            call_       = [](const Entity &e, int x) -> int {
                return (*static_cast<std::remove_reference_t<F> *>(e.obj))(x);
            };
        }
    }

    int operator()(int x) const { return call_(entity_, x); }

private:
    union Entity {                                   /* 两种被绑对象共用一块 8 字节 */
        void *obj;
        int (*fn)(int);
        Entity() : obj(nullptr) {}
    };

    Entity entity_;
    int (*call_)(const Entity &, int);
};

/* 接收方：按值收一个视图，开销与传两个指针相同 */
static int apply_twice(IntFnView f, int x) { return f(f(x)); }

static int triple(int x) { return x * 3; }

int main() {
    std::printf("sizeof(IntFnView)                  = %zu\n", sizeof(IntFnView));
    std::printf("sizeof(std::function<int(int)>)    = %zu\n", sizeof(std::function<int(int)>));
    std::printf("sizeof(函数指针) + sizeof(void *)  = %zu\n\n",
                sizeof(int (*)(int)) + sizeof(void *));

    std::printf("1. 视图能收下三种可调用物\n");
    int  captured = 10;
    auto lam      = [captured](int x) { return x + captured; };
    auto negate   = std::negate<int>{};
    std::printf("  lambda：  apply_twice(lam, 1)    = %d\n", apply_twice(lam, 1));
    std::printf("  函数：    apply_twice(triple, 1) = %d\n", apply_twice(triple, 1));
    std::printf("  仿函数：  apply_twice(negate, 1) = %d\n", apply_twice(negate, 1));
    std::printf("  三者在调用处的写法完全相同\n\n");

    std::printf("2. 与 std::function 的分工\n");
    std::function<int(int)> owned = lam;             /* 拥有：可拷贝、可存起来 */
    IntFnView               view  = lam;             /* 不拥有：只借，调用期必须活着 */
    std::printf("  owned(1) = %d，view(1) = %d\n", owned(1), view(1));
    std::printf("  owned 存的是副本，view 存的是地址\n\n");

    std::printf("3. 视图的大小不随可调用物变化\n");
    char big[256] = {};
    auto big_lam  = [big](int x) { return x + big[0]; };
    std::printf("  sizeof(捕获 256 字节的 lambda) = %zu\n", sizeof(big_lam));
    std::printf("  std::function 装它之后 = %zu\n", sizeof(std::function<int(int)>));
    std::printf("  IntFnView 装它之后     = %zu\n", sizeof(IntFnView));
    IntFnView big_view = big_lam;
    std::printf("  调用结果 = %d\n", big_view(1));
    return 0;
}
```

| `std::function<int(int)>` | 32 字节 | 仍是 32 字节 | **会**（超过 16 字节就分配） | 是 |
| 自己写的函数视图 | **16 字节** | 仍是 16 字节 | **不会** | 否 |

**视图只借地址，因此构造与拷贝都不分配内存，一次调用也只有一次间接调用。**
代价是**生命周期须由调用者保证**：视图指向的可调用物必须先于视图析构。

为了让这一点在编译期就挡掉，上面那个构造函数只接受左值：
指向一个马上就没了的临时对象，是这类包装最典型的错误。

`C++`

```cpp
/* b04_funcview_tmp_err.cpp    编译：g++ -std=c++17 b04_funcview_tmp_err.cpp -o b04_funcview_tmp_err （失败） */

#include <type_traits>
#include <utility>

class IntFnView {
public:
    template <class F,
              class = std::enable_if_t<std::is_lvalue_reference_v<F>>>
    IntFnView(F &&f) noexcept
        : obj_((void *)std::addressof(f)),
          call_([](void *o, int x) -> int { return (*static_cast<std::remove_reference_t<F> *>(o))(x); }) {}

    int operator()(int x) const { return call_(obj_, x); }

private:
    void *obj_;
    int (*call_)(void *, int);
};

int main() {
    IntFnView v = std::negate<int>{};                /* 想绑一个临时对象 */
    return v(1);
}
```

> [!CAUTION]
> **函数视图不持有它包装的东西。**
> 被包装的可调用物一旦析构，视图就成了悬垂引用，调用它是未定义行为。
> 拿不准生命周期时就退回 `std::function`——它慢一点，但存的是副本。
> 这与 `std::string_view` 的取舍是同一条
> （`07-标准库` 板块的 `B-02-std-string 与 string_view.md`）。

## 5.3 版本与替代品

可调用物包装这一族东西的版本分布很散，用到哪个都要先看版本：

| 名字 | 版本 | 说明 |
|---|---|---|
| `std::function` | C++11 | 可拷贝的通用包装器，本教材基准里有 |
| `std::bind`、`std::placeholders` | C++11 | 部分应用；新代码优先写 lambda |
| `std::mem_fn` | C++11 | 成员函数变成可调用对象 |
| `std::reference_wrapper`、`std::ref`、`std::cref` | C++11 | 能放进容器的引用 |
| `std::invoke` | **C++17** | 四种调用写法统一；本教材基准里有 |
| `std::not_fn` | C++17 | 把谓词取反，替代已弃用的 `std::not1` |
| `std::bind_front` | C++20 | 只钉住前几个实参，比 `bind` 清楚 |
| `std::bind_back` | C++23 | 只钉住后几个实参 |
| `std::move_only_function` | **C++23** | 装只能移动的可调用物（第 1.5 小节） |
| `std::function_ref` | **C++26** | 官方的函数视图（第 5.1 小节） |
| `std::copyable_function` | C++26 | 带 `const` / `noexcept` 限定的新包装器 |
| `std::mem_fun` 一族、`std::bind1st`、`std::bind2nd` | 已移除 | C++17 弃用，C++20 起不再提供 |

本机基准是 C++17，因此能用的是 `std::function`、`std::bind`、`std::mem_fn`、
`std::reference_wrapper`、`std::invoke`、`std::not_fn` 这几样。
遇到 C++20 及以后的写法，本教材会明确标出版本，不会让它们混进 C++17 的例子里。

这一族里 C++17 能用的几个放进同一个程序：

`C++`

```cpp
/* b04_cxx17_set.cpp    编译：g++ -std=c++17 b04_cxx17_set.cpp -o b04_cxx17_set */
#include <cstdio>
#include <functional>
#include <vector>

/* C++17 下这一族件里能用的几个，一次全用上 */
static bool is_even(int x) { return x % 2 == 0; }

struct InRange {
    int lo;
    int hi;
    bool operator()(int x) const { return x >= lo && x <= hi; }
};

static int add(int a, int b) { return a + b; }

int main() {
    std::vector<int> v = {1, 2, 3, 4, 5, 6};

    std::printf("1. std::not_fn：把谓词取反（C++17）\n");
    auto is_odd = std::not_fn(is_even);
    std::printf("  is_even(4) = %d，is_odd(4) = %d\n", is_even(4) ? 1 : 0, is_odd(4) ? 1 : 0);
    auto outside = std::not_fn(InRange{2, 5});
    std::printf("  在 2..5 之外：%d %d\n\n", outside(1) ? 1 : 0, outside(3) ? 1 : 0);

    std::printf("2. std::bind 与 lambda 写同一件事\n");
    auto add10_bind   = std::bind(add, std::placeholders::_1, 10);
    auto add10_lambda = [](int x) { return add(x, 10); };
    std::printf("  bind = %d，lambda = %d\n\n", add10_bind(5), add10_lambda(5));

    std::printf("3. std::mem_fn 与 std::invoke\n");
    auto size_of = std::mem_fn(&std::vector<int>::size);
    std::printf("  mem_fn(&vector::size)(v) = %zu\n", size_of(v));
    std::printf("  std::invoke(add, 20, 3) = %d\n\n", std::invoke(add, 20, 3));

    std::printf("4. std::ref 让 std::function 改得到外面\n");
    int total = 0;
    std::function<void(int)> acc = [&total](int x) { total += x; };   /* 捕获引用 */
    acc(7);
    std::function<void()> bump = std::bind([](int &t) { t += 100; }, std::ref(total));
    bump();
    std::printf("  total = %d\n\n", total);

    std::printf("5. 这一族件的大小\n");
    std::printf("  sizeof(std::function<void(int)>)      = %zu\n", sizeof(std::function<void(int)>));
    std::printf("  sizeof(not_fn 表达式)                 = %zu\n", sizeof(is_odd));
    std::printf("  sizeof(reference_wrapper<int>)        = %zu\n", sizeof(std::reference_wrapper<int>));
    std::printf("  sizeof(mem_fn 表达式)                 = %zu\n", sizeof(size_of));
    return 0;
}
```

`实测数据`
`Text`

```text
1. std::not_fn：把谓词取反（C++17）
  is_even(4) = 1，is_odd(4) = 0
  在 2..5 之外：1 0

2. std::bind 与 lambda 写同一件事
  bind = 15，lambda = 15

3. std::mem_fn 与 std::invoke
  mem_fn(&vector::size)(v) = 6
  std::invoke(add, 20, 3) = 23

4. std::ref 让 std::function 改得到外面
  total = 107

5. 这一族件的大小
  sizeof(std::function<void(int)>)      = 32
  sizeof(not_fn 表达式)                 = 8
  sizeof(reference_wrapper<int>)        = 8
  sizeof(mem_fn 表达式)                 = 16
```

# 第 6 节 检查清单与速查表

## 6.1 速查表

| 名字 | 一句话用途 | 典型坑 |
|---|---|---|
| `std::function<R(Args...)>` | 把类型各异的可调用物统一成一种类型 | 忘了判空就调用；以为它改得到外面那份状态 |
| `if (f)` / `f ? a : b` | 判空 | 空的时候调用会抛 `std::bad_function_call` |
| 构造与拷贝 `std::function` | 被包装对象超过 16 字节时向堆要内存 | 每次拷贝都再分配一次 |
| `std::bind(f, ...)` | 固定部分实参 | 绑定的实参按值存副本；占位符编号与位置无关 |
| `std::placeholders::_1` | 标出「调用时的第几个实参」 | 与它在参数表里排第几无关 |
| `std::mem_fn(&T::f)` | 成员函数变成可调用对象 | 需要 C++11 起 |
| `std::invoke(f, args...)` | 统一四种调用写法 | C++17 起才有 |
| `std::ref(x)` / `std::cref(x)` | 把引用包起来放进容器或 `bind` | 不管生命周期，指向的对象没了就是悬垂 |
| `std::reference_wrapper<T>` | 可拷贝、可赋值的引用，大小等于指针 | 同上 |
| 自己写的函数视图 | 只借地址，构造与调用都不分配 | 被包装的东西必须先于视图析构 |
| `std::bind_front` | C++20 起，钉住前几个实参 | 基准是 C++17，用不了 |
| `std::move_only_function` | C++23 起，装只能移动的可调用物 | 同上 |
| `std::function_ref` | C++26 起，官方函数视图 | 同上 |

## 6.2 检查清单

| 检查 | 为什么 |
|---|---|
| 接收方是模板吗 | 是模板就直接传 lambda，省掉 3.6 倍的调用开销（第 1.4 小节） |
| `std::function` 调用前判空了吗 | 空的时候抛异常，没人接就终止（第 1.2 小节） |
| 被包装的可调用物超过 16 字节吗 | 超过了每次构造与拷贝都要分配（第 1.3 小节） |
| 想改到外面那份状态吗 | `std::function` 与 `std::bind` 都存副本，要写 `std::ref`（第 2.2 小节） |
| 用 `bind` 只是固定实参吗 | 是的话改写成 lambda，报错更好读（第 2.3 小节） |
| 在模板函数里调用可调用物吗 | 写 `std::invoke(f, args...)`，同时支持成员函数指针（第 3.2 小节） |
| 函数视图包装的东西还活着吗 | 视图不持有它，析构之后调用是未定义行为（第 5.2 小节） |
| 用到的件在 C++17 里有吗 | `bind_front`、`move_only_function`、`function_ref` 都要更高版本（第 5.3 小节） |

# 术语表

| 术语 | 英文 | 含义 |
|---|---|---|
| 可调用物 | Callable | 能用 `f(args...)` 形式调用的东西：函数、lambda、仿函数、成员函数指针 |
| 仿函数 | Functor / function object | 重载了 `operator()` 的类对象 |
| 类型擦除 | Type erasure | 把不同的具体类型统一成一种类型，`std::function` 的做法 |
| 部分应用 | Partial application | 先把一部分实参固定下来，得到一个新的可调用物 |
| 占位符 | Placeholder | `_1`、`_2`，标出「调用时的第几个实参」 |
| 成员函数指针 | Pointer to member function | `&T::f` 的类型，必须与对象一起才能调用 |
| 函数视图 | Function view / `function_ref` | 不持有可调用物、只记地址的包装器；C++26 才进标准 |
| `std::reference_wrapper` | — | 可拷贝、可赋值的引用包装，`std::ref` 的返回类型 |
| 小对象缓冲 | Small buffer optimization | 在包装器内部留一块空间放小的被包装对象，避免堆分配 |

# 附录 A 复现本章节实测

## A.1 环境

各程序用 `g++` 15.2.0（MinGW-w64）、`-std=c++17` 编译，平台为 Windows 11 x86-64；
计时那一组额外加了 `-O2`，其余用默认。

`sizeof`、分配次数与耗时都随平台和标准库实现变化。
小对象缓冲的大小（这里测出来是 16 字节）由实现决定，
换一个标准库实现时这个数字会变，但「超过它就分配」这条规律不变。

## A.2 编译期失败那一组

三个程序都在编译期就被挡住，不产生可执行文件。

`Bash`

```bash
g++ -std=c++17 b04_fn_moveonly_err.cpp -o b04_fn_moveonly_err
g++ -std=c++17 b04_funcview_err.cpp    -o b04_funcview_err
g++ -std=c++17 b04_funcview_tmp_err.cpp -o b04_funcview_tmp_err
```

`Text`

```text
第一条挡住的是「std::function 的目标必须可拷贝」，
第二条挡住的是「C++17 里没有 std::function_ref」，
第三条挡住的是「视图不能绑右值」。
```

另有一个人为的运行时失败：`b04_fn_empty.cpp` 会以退出码 3 终止，
因为空 `std::function` 抛出的异常没有人捕获。
