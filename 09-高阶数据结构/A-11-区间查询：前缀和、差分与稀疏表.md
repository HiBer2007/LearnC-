# 区间查询：前缀和、差分与稀疏表

> 文中引用的代码不受此限，各自保留原有许可证，详见[版权与许可说明.md](../版权与许可说明.md)。

前面几章的问题都是「找某个东西」：找一个键、找一段前缀、找一个点的邻居。
这一章问的是另一种问题：**同一个区间要反复问很多次**。
一段数据摆在那里，程序反复问「第 3 万到第 4 万个元素的和是多少」，
而每次从头加一遍要一千次加法——问一万次就是一千万次。

省下这些加法的办法是**先把一部分结果算好**。算好的那部分结果是什么形状，
取决于两个问题：**问的是求和还是最值**，以及**数据会不会变**。
这两问一共分出四条路：数据不变时用前缀和（求和）或稀疏表（最值）；
数据会变时用差分（改一段、最后统一读）或者干脆每次现算。
四条路放在同一份数据上，要比的是四项：
建表时间、单次查询耗时、一次修改的代价、每元素内存。

实测的结果里有两个数字最值得记住：**前缀和把一次区间求和从 201.93 ns 降到 11.67 ns，
代价是建表 1.577 ms 与「改一个元素就要重建整张表」的 0.494 ms**；
而**建表成本的回本点在查询 1000 到 10000 次之间**——
问得比这少，从头加反而更省。

线段树与树状数组不在本章：两者都是「数据会变 + 区间查询」
的通用解法，代价是每元素的内存与常数都比本章这几种大，
需要它们时见 `【待补：09-高阶数据结构/B-01-手写：线段树与树状数组.md】`。

# 第 1 节 需求：同一个区间反复问

## 1.1 四种组合

| | 数据不变 | 数据会变 |
|---|---|---|
| 求和 | **前缀和** | 差分（区间加、最后统一读）／线段树、树状数组 |
| 最值 | **稀疏表** | 线段树、树状数组 |

**「会不会变」是第一个问题**，它比「问的是和还是最值」更早决定选哪条路：
前缀和与稀疏表都是**建好之后只读**的结构，改一个元素就要重建。

## 1.2 一次查询值多少钱

| 做法 | 一次区间求和 | 一次区间最值 | 一次区间加 |
|---|---|---|---|
| 从头算 | `O(长度)` | `O(长度)` | `O(长度)` |
| 前缀和 | **`O(1)`** | 不适用 | 重建 `O(n)` |
| 差分 | 还原后 `O(1)` | 不适用 | **`O(1)`** |
| 稀疏表 | 不适用 | **`O(1)`** | 重建 `O(n log n)` |

**表里的两处「不适用」不是实现问题，是原理问题**：
差分算不出区间最值，稀疏表算不出区间和——原因在第 3、4 节各说一次。

# 第 2 节 前缀和

## 2.1 模型

把「前 `i` 个元素的和」全部先算出来，存进一张表：

`Text`

```text
   a     ： 3   1   4   1   5   9   2   6
   pre   ： 0   3   4   8   9  14  23  25  31
            ↑   ↑
            pre[0] = 0（空区间的和）
                pre[i] = a[0] + … + a[i-1]

   问 a[2] 到 a[5] 的和（下标左闭右开 [2, 6)）：
        pre[6] - pre[2] = 23 - 4 = 19
        验算：4 + 1 + 5 + 9 = 19 ✓
```

**为什么一次减法就够**：`pre[6]` 是前 6 个的和，`pre[2]` 是前 2 个的和，
两者相减，前面那一段抵消掉，剩下的正好是 `[2, 6)`。
这就是「先算好一部分结果」的全部内容——`pre` 比 `a` 多一个元素，
`pre[0]` 是空区间的和，有了它就不必为「从 0 开始」写特例。

## 2.2 接口

`C++`

（下面是节选：前缀和的建表与查询，完整程序见第 5 节的 `range_queries.cpp`。）

```cpp
pre.assign(n + 1, 0);
for (int i = 0; i < n; ++i) pre[i + 1] = pre[i] + a[i];   // 建表 O(n)
long long sum = pre[r] - pre[l];                            // 查询 O(1)，区间 [l, r)
```

## 2.3 代价

| 操作 | 复杂度 | 实测（n = 100 万） |
|---|---|---|
| 建表 | `O(n)` | 1.577 ms |
| 一次查询 | `O(1)` | 11.67 ns |
| 改一个元素 | **`O(n)` 重建** | 0.494 ms |
| 内存 | `n + 1` 个累加值 | 8.00 字节/元素 |

**存的是 `long long` 而不是 `int`**：`n` 个不超过 1000 的数加起来可以到 10 亿，
再往上加就溢出 `int`。前缀和是一处**容易溢出**的地方，
因为累加值比原数组大得多——这也是它每元素要 8 字节的原因。

> [!WARNING]
> **改一个元素就要重建整张表。**
> 前缀和的所有位置都依赖它前面的一切，中间改一个数，
> 从它往后每个 `pre` 都错。**「会变的数据不要用前缀和」**——
> 除非改动是成批的、而且只在最后查一次（那就是下一节的差分）。

# 第 3 节 差分

## 3.1 模型

差分数组 `d` 记的是**相邻两个元素的差**：

`Text`

```text
   a     ： 3   1   4   1   5   9   2   6
   d     ： 3  -2   3  -3   4   4  -7   4
            ↑
            d[i] = a[i] - a[i-1]（d[0] = a[0]）

   把 a[2] 到 a[4]（左闭右开 [2, 5)）每个都加 10：
        只有两处变化：d[2] += 10，d[5] -= 10
        因为区间内部相邻的差没变，只有「进区间」和「出区间」两个位置变了
```

**一次区间加只要改两个位置**，与区间长度无关——这就是差分的全部价值。

## 3.2 接口

`C++`

（下面是节选：差分的区间加与还原，完整程序见第 5 节的 `range_queries.cpp`。）

```cpp
d[l] += x;      // 进区间
d[r] -= x;      // 出区间（区间是 [l, r)）
// 要把差分还原成每个位置的值：一次前缀和
long long cur = 0;
for (int i = 0; i < n; ++i) { cur += d[i]; a[i] = cur; }
```

## 3.3 代价

| 操作 | 复杂度 | 实测（n = 100 万） |
|---|---|---|
| 建表 | `O(n)`（或全 0，看用途） | 0.000 ms（全 0 初始化） |
| 一次区间加 | **`O(1)`** | 10.59 ns |
| 一次单点查询 | 要么 `O(1)`（维护当前值）要么还原 `O(n)` | 还原一次 0.650 ms |
| 内存 | `n + 1` 个差值 | 8.00 字节/元素 |

**差分把「区间加」和「查值」的代价换了个位置**：
前缀和是「查便宜、改贵」，差分是「改便宜、查贵」。
它最合适的用法是**先把一批区间加做完，最后统一还原一次**——
那一次还原是 `O(n)`，摊到几十万次区间加上可以忽略。

`实测数据`
`Text`

```text
  差分：一次区间加                         10.59 ns（200000 次共 1.197 ms）
  差分：把差分还原成每个位置的值           0.650 ms（一次前缀和，1000000 个位置）
```

**20 万次区间加一共 1.197 ms，最后一次还原 0.650 ms。**
如果每加一次都还原一遍再查，20 万次就是 20 万 × 0.650 ms——五十七秒。

# 第 4 节 稀疏表

## 4.1 模型：把「可重复贡献」的运算做到 `O(1)`

区间最值有一条性质，是第 2、3 节都没有的：**重叠不会算错**。
`min(a, b)` 里 `a` 被算两次还是 `min(a, b)`；
而 `a + b` 里 `a` 被算两次就变成了两倍。

于是可以对每个长度是 2 的幂的区间先算好答案，查询时**用两块盖住整个区间**：

`Text`

```text
   问 a[2] 到 a[9]（长度 7）的最小值：7 不是 2 的幂，但可以拿两块盖住它

   a  ： … │ 4   1   5   9   2   6   5 │ …
           └─────┬─────┘   └─────┬─────┘
              长度 4 的一块    长度 4 的一块
              （从 2 开始）    （从 6 开始，即 9-4+1）

   两块合起来盖住了 [2, 10)，中间有重叠——最值允许重叠，
   答案就是这两块的最小值再取最小
```

`Text`

```text
   sparse[k][i] = 从 i 开始、长度为 2^k 的区间的最值

   sparse[0][i] = a[i]
   sparse[k][i] = min(sparse[k-1][i], sparse[k-1][i + 2^(k-1)])
                  └──── 前半块 ────┘  └──── 后半块 ────┘

   查询 [l, r)：令 k = ⌊log2(r - l)⌋
       答案 = min(sparse[k][l], sparse[k][r - 2^k])
```

**这就是稀疏表的全部内容**：一张 `n × log n` 的表，换一次查询两次访存。

## 4.2 代价

| 操作 | 复杂度 | 实测（n = 100 万） |
|---|---|---|
| 建表 | `O(n log n)` | 27.517 ms |
| 一次区间最值 | `O(1)` | 13.03 ns |
| 改一个元素 | **只能整表重建** | 27.517 ms |
| 内存 | `n log n` 个值 | **80.00 字节/元素** |

**80 字节/元素是本章最贵的一项**（`log₂ 100 万 ≈ 20` 层，每层 4 字节）。
它是「只读数据 + 大量最值查询」的专用工具：
建表 20 毫秒，之后每次查询 13 纳秒。

> [!CAUTION]
> **稀疏表对「可重复贡献」的运算才成立，`+` 不行。**
> 区间求和用两块重叠去盖，重叠部分会被算两次；
> 这不是实现技巧问题，是这个结构的前提。
> **求和要 `O(1)` 就用前缀和（数据不变）或线段树（数据会变）。**

# 第 5 节 四项实测与回本点

`C++`

```cpp
/* range_queries.cpp    编译：g++ -std=c++17 -O2 range_queries.cpp -o range_queries
 * 同一个数组被反复追问区间：朴素累加、前缀和、差分、稀疏表四条路，
 * 比四件事——建表时间、单次查询耗时、一次修改的代价、每元素占多少字节。
 * 另外给一张「查询多少次之后建表成本才回本」的实测表。 */
#include <algorithm>
#include <chrono>
#include <cstdio>
#include <cstdlib>
#include <new>
#include <random>
#include <vector>

static long long g_bytes = 0;

void* operator new(std::size_t n) {
    g_bytes += static_cast<long long>(n);
    void* p = std::malloc(n ? n : 1);
    if (!p) throw std::bad_alloc();
    return p;
}
void operator delete(void* p) noexcept { std::free(p); }
void operator delete(void* p, std::size_t) noexcept { std::free(p); }

template <class F>
static double ms(F&& f) {
    const auto t0 = std::chrono::steady_clock::now();
    f();
    const auto t1 = std::chrono::steady_clock::now();
    return std::chrono::duration<double, std::milli>(t1 - t0).count();
}

int main() {
    constexpr int N = 1000000;        // 数组长度
    constexpr int L = 1000;           // 每次查询的区间长度
    constexpr int QRUNS = 200000;     // 单次查询耗时的采样次数
    std::mt19937 rng(2024);
    std::vector<int> a(N);
    for (int& x : a) x = static_cast<int>(rng() % 1000);

    std::vector<int> lo(QRUNS), hi(QRUNS);
    for (int i = 0; i < QRUNS; ++i) {
        lo[static_cast<std::size_t>(i)] = static_cast<int>(rng() % (N - L));
        hi[static_cast<std::size_t>(i)] = lo[static_cast<std::size_t>(i)] + L;
    }

    volatile long long sink = 0;
    std::printf("数组长度 %d，每次查询区间长度 %d，单次查询采样 %d 次\n\n", N, L, QRUNS);

    // ---------------- 一、朴素：每次查询都从头累加 ----------------
    long long naive_sum = 0;
    const double naive_ms = ms([&] {
        long long acc = 0;
        for (int i = 0; i < QRUNS; ++i) {
            long long s = 0;
            for (int j = lo[static_cast<std::size_t>(i)]; j < hi[static_cast<std::size_t>(i)]; ++j) {
                s += a[static_cast<std::size_t>(j)];
            }
            acc += s;
        }
        naive_sum = acc;
    });
    sink += naive_sum;

    // ---------------- 二、前缀和 ----------------
    g_bytes = 0;
    std::vector<long long> pre;
    const double pre_build = ms([&] {
        pre.assign(static_cast<std::size_t>(N) + 1, 0);
        for (int i = 0; i < N; ++i) pre[static_cast<std::size_t>(i) + 1] = pre[static_cast<std::size_t>(i)] + a[static_cast<std::size_t>(i)];
    });
    const long long pre_bytes = g_bytes;
    long long pre_sum = 0;
    const double pre_query = ms([&] {
        long long acc = 0;
        for (int i = 0; i < QRUNS; ++i) {
            acc += pre[static_cast<std::size_t>(hi[static_cast<std::size_t>(i)])]
                 - pre[static_cast<std::size_t>(lo[static_cast<std::size_t>(i)])];
        }
        pre_sum = acc;
    });
    sink += pre_sum;
    // 一次修改：改一个元素，然后重建整张表
    const double pre_update = ms([&] {
        a[N / 2] += 1;
        for (int i = 0; i < N; ++i) pre[static_cast<std::size_t>(i) + 1] = pre[static_cast<std::size_t>(i)] + a[static_cast<std::size_t>(i)];
    });

    // ---------------- 三、差分：区间加便宜，查询要前缀和 ----------------
    g_bytes = 0;
    std::vector<long long> diff(static_cast<std::size_t>(N) + 1, 0);
    const long long diff_bytes = g_bytes;
    const double diff_add = ms([&] {
        for (int i = 0; i < QRUNS; ++i) {
            const int l = lo[static_cast<std::size_t>(i)];
            const int r = hi[static_cast<std::size_t>(i)];
            diff[static_cast<std::size_t>(l)] += 1;
            diff[static_cast<std::size_t>(r)] -= 1;
        }
    });
    long long diff_sum = 0;
    const double diff_flush = ms([&] {          // 把差分还原成每个位置的值：一次前缀和
        long long cur = 0;
        long long acc = 0;
        for (int i = 0; i < N; ++i) {
            cur += diff[static_cast<std::size_t>(i)];
            acc += cur;
        }
        diff_sum = acc;
    });
    sink += diff_sum;

    // ---------------- 四、稀疏表：只支持「可重复贡献」的运算 ----------------
    g_bytes = 0;
    int levels = 1;
    while ((1 << levels) <= N) ++levels;
    std::vector<std::vector<int>> sparse;
    const double sparse_build = ms([&] {
        sparse.assign(static_cast<std::size_t>(levels), std::vector<int>(static_cast<std::size_t>(N), 0));
        sparse[0] = a;
        for (int k = 1; k < levels; ++k) {
            const int half = 1 << (k - 1);
            for (int i = 0; i + (1 << k) <= N; ++i) {
                sparse[static_cast<std::size_t>(k)][static_cast<std::size_t>(i)] =
                    std::min(sparse[static_cast<std::size_t>(k - 1)][static_cast<std::size_t>(i)],
                             sparse[static_cast<std::size_t>(k - 1)][static_cast<std::size_t>(i + half)]);
            }
        }
    });
    long long sparse_ints = 0;
    for (const auto& lv : sparse) sparse_ints += static_cast<long long>(lv.size());
    long long sparse_sum = 0;
    const double sparse_query = ms([&] {
        long long acc = 0;
        for (int i = 0; i < QRUNS; ++i) {
            const int l = lo[static_cast<std::size_t>(i)];
            const int r = hi[static_cast<std::size_t>(i)];
            int k = 0;
            while ((1 << (k + 1)) <= r - l) ++k;
            acc += std::min(sparse[static_cast<std::size_t>(k)][static_cast<std::size_t>(l)],
                            sparse[static_cast<std::size_t>(k)][static_cast<std::size_t>(r - (1 << k))]);
        }
        sparse_sum = acc;
    });
    sink += sparse_sum;

    std::printf("%-34s %12s %14s %14s %14s\n", "做法", "建表 ms", "总字节", "每元素字节", "单次查询 ns");
    const long long pre_bytes_cap = static_cast<long long>(pre.capacity()) * 8;
    const long long diff_bytes_cap = static_cast<long long>(diff.capacity()) * 8;
    const long long sparse_bytes_cap = sparse_ints * 4;
    std::printf("%-34s %12s %14s %14s %14.2f ns\n", "朴素（每次从头累加）", "无", "无", "无",
                naive_ms * 1e6 / QRUNS);
    std::printf("%-34s %12.3f %14lld %14.2f %14.2f ns\n", "前缀和", pre_build, pre_bytes_cap,
                double(pre_bytes_cap) / N, pre_query * 1e6 / QRUNS);
    std::printf("%-34s %12.3f %14lld %14.2f %14.2f ns\n", "差分（区间加；查值要还原）", 0.0,
                diff_bytes_cap, double(diff_bytes_cap) / N, diff_add * 1e6 / QRUNS);
    std::printf("%-34s %12.3f %14lld %14.2f %14.2f ns\n", "稀疏表（区间最值）", sparse_build,
                sparse_bytes_cap, double(sparse_bytes_cap) / N, sparse_query * 1e6 / QRUNS);
    std::printf("（每元素字节按容量算：前缀和与差分各用 long long 存 N+1 个；\n");
    std::printf("  稀疏表有 %d 层，共 %lld 个 int）\n", levels, sparse_ints);
    std::printf("（建表过程中向堆申请的字节数：前缀和 %lld，差分 %lld，稀疏表 %lld）\n",
                pre_bytes, diff_bytes, sparse_bytes_cap);

    std::printf("\n一次修改的代价：\n");
    std::printf("  前缀和：改一个元素之后重建整张表    %10.3f ms\n", pre_update);
    std::printf("  差分：一次区间加                   %10.2f ns（%d 次共 %.3f ms）\n",
                diff_add * 1e6 / QRUNS, QRUNS, diff_add);
    std::printf("  差分：把差分还原成每个位置的值      %10.3f ms（一次前缀和，%d 个位置）\n",
                diff_flush, N);
    std::printf("  稀疏表：改一个元素只能整表重建      %10.3f ms\n", sparse_build);

    std::printf("\n查询多少次之后，前缀和的建表成本才回本（查同样的 %d 个区间）：\n", L);
    for (int m : {1, 10, 100, 1000, 10000, 100000, 1000000}) {
        const double naive_total = ms([&] {
            long long acc = 0;
            for (int i = 0; i < m; ++i) {
                const std::size_t idx = static_cast<std::size_t>(i) % lo.size();
                long long s = 0;
                for (int j = lo[idx]; j < hi[idx]; ++j) {
                    s += a[static_cast<std::size_t>(j)];
                }
                acc += s;
            }
            sink += acc;
        });
        const double pre_total = ms([&] {
            long long acc = 0;
            for (int i = 0; i < m; ++i) {
                const std::size_t idx = static_cast<std::size_t>(i) % lo.size();
                acc += pre[static_cast<std::size_t>(hi[idx])] - pre[static_cast<std::size_t>(lo[idx])];
            }
            sink += acc;
        });
        std::printf("  查询 %8d 次：朴素 %10.3f ms，前缀和 %10.3f ms  %s\n",
                    m, naive_total, pre_build + pre_total,
                    pre_build + pre_total < naive_total ? "前缀和更省" : "朴素更省");
    }
    std::printf("\n（sink=%lld）\n", static_cast<long long>(sink));
    return 0;
}
```

## 5.3 二维前缀和

一维前缀和那套做法在二维上照样成立，只是「相减」变成了「容斥」：
两个方向各减一次，多减的交集再加回来。

`Text`

```text
   pre[r][c] = 从左上角到 (r, c) 这个矩形的和

   问 (r1, c1) 到 (r2, c2) 的矩形和：
        pre[r2][c2] - pre[r1][c2] - pre[r2][c1] + pre[r1][c1]
        └── 整个大块 ──┘ └ 上面一条 ┘ └ 左边一条 ┘ └ 多减的交集加回来 ┘

   建表也是同一个式子反过来：pre[r][c] = pre[r-1][c] + pre[r][c-1] - pre[r-1][c-1] + a[r][c]
```

`C++`

```cpp
/* prefix2d.cpp    编译：g++ -std=c++17 -O2 prefix2d.cpp -o prefix2d
 * 二维前缀和：建表、一次矩形求和、每元素内存，以及「查多少次才回本」。
 * 对照是逐格累加（每次矩形求和把 rect 个格子加一遍）。 */
#include <algorithm>
#include <chrono>
#include <cstdio>
#include <random>
#include <vector>

template <class F>
static double ms(F&& f) {
    const auto t0 = std::chrono::steady_clock::now();
    f();
    const auto t1 = std::chrono::steady_clock::now();
    return std::chrono::duration<double, std::milli>(t1 - t0).count();
}

int main() {
    constexpr int R = 2000;          // 行
    constexpr int C = 2000;          // 列
    constexpr int SIDE = 100;        // 每次查询的矩形边长
    constexpr int Q = 200000;        // 单次查询耗时的采样次数
    std::mt19937 rng(2024);

    std::vector<int> g(static_cast<std::size_t>(R) * C);
    for (int& x : g) x = static_cast<int>(rng() % 1000);

    // 查询矩形的位置提前生成，不计进计时区间
    std::vector<int> r0(Q), c0(Q);
    for (int i = 0; i < Q; ++i) {
        r0[static_cast<std::size_t>(i)] = static_cast<int>(rng() % (R - SIDE));
        c0[static_cast<std::size_t>(i)] = static_cast<int>(rng() % (C - SIDE));
    }

    volatile long long sink = 0;
    std::printf("网格 %d × %d（%d 个格子），每次查询 %d × %d 的矩形，单次查询采样 %d 次\n\n",
                R, C, R * C, SIDE, SIDE, Q);

    // ---- 逐格累加 ----
    long long naive_acc = 0;
    const double naive_ms = ms([&] {
        long long acc = 0;
        for (int i = 0; i < Q; ++i) {
            long long s = 0;
            for (int r = r0[static_cast<std::size_t>(i)]; r < r0[static_cast<std::size_t>(i)] + SIDE; ++r) {
                for (int c = c0[static_cast<std::size_t>(i)]; c < c0[static_cast<std::size_t>(i)] + SIDE; ++c) {
                    s += g[static_cast<std::size_t>(r) * C + c];
                }
            }
            acc += s;
        }
        naive_acc = acc;
    });
    sink += naive_acc;

    // ---- 二维前缀和 ----
    std::vector<long long> pre;
    const double build_ms = ms([&] {
        pre.assign(static_cast<std::size_t>(R + 1) * (C + 1), 0);
        for (int r = 0; r < R; ++r) {
            for (int c = 0; c < C; ++c) {
                pre[static_cast<std::size_t>(r + 1) * (C + 1) + (c + 1)] =
                    pre[static_cast<std::size_t>(r) * (C + 1) + (c + 1)]
                  + pre[static_cast<std::size_t>(r + 1) * (C + 1) + c]
                  - pre[static_cast<std::size_t>(r) * (C + 1) + c]
                  + g[static_cast<std::size_t>(r) * C + c];
            }
        }
    });
    long long pre_acc = 0;
    const double query_ms = ms([&] {
        long long acc = 0;
        for (int i = 0; i < Q; ++i) {
            const int r = r0[static_cast<std::size_t>(i)];
            const int c = c0[static_cast<std::size_t>(i)];
            const int r2 = r + SIDE;
            const int c2 = c + SIDE;
            acc += pre[static_cast<std::size_t>(r2) * (C + 1) + c2]
                 - pre[static_cast<std::size_t>(r) * (C + 1) + c2]
                 - pre[static_cast<std::size_t>(r2) * (C + 1) + c]
                 + pre[static_cast<std::size_t>(r) * (C + 1) + c];
        }
        pre_acc = acc;
    });
    sink += pre_acc;

    const long long cells = static_cast<long long>(R) * C;
    const long long pre_bytes = static_cast<long long>(pre.capacity()) * 8;
    std::printf("%-24s %12s %14s %14s %14s\n", "做法", "建表 ms", "总字节", "每格字节", "单次查询 ns");
    std::printf("%-24s %12s %14s %14s %14.2f ns\n", "逐格累加", "无", "无", "无", naive_ms * 1e6 / Q);
    std::printf("%-24s %12.3f %14lld %14.2f %14.2f ns\n", "二维前缀和", build_ms, pre_bytes,
                static_cast<double>(pre_bytes) / static_cast<double>(cells), query_ms * 1e6 / Q);
    std::printf("\n（每次查询的矩形有 %d 个格子；二维前缀和每格 8 字节，是因为存的是 long long 累加值）\n",
                SIDE * SIDE);

    std::printf("\n查多少次之后建表成本才回本（每次查 %d × %d 的矩形）：\n", SIDE, SIDE);
    for (int m : {1, 10, 100, 1000, 10000, 100000}) {
        const double naive_total = ms([&] {
            long long acc = 0;
            for (int i = 0; i < m; ++i) {
                const std::size_t idx = static_cast<std::size_t>(i) % Q;
                long long s = 0;
                for (int r = r0[idx]; r < r0[idx] + SIDE; ++r) {
                    for (int c = c0[idx]; c < c0[idx] + SIDE; ++c) {
                        s += g[static_cast<std::size_t>(r) * C + c];
                    }
                }
                acc += s;
            }
            sink += acc;
        });
        const double pre_total = ms([&] {
            long long acc = 0;
            for (int i = 0; i < m; ++i) {
                const std::size_t idx = static_cast<std::size_t>(i) % Q;
                const int r = r0[idx];
                const int c = c0[idx];
                acc += pre[static_cast<std::size_t>(r + SIDE) * (C + 1) + (c + SIDE)]
                     - pre[static_cast<std::size_t>(r) * (C + 1) + (c + SIDE)]
                     - pre[static_cast<std::size_t>(r + SIDE) * (C + 1) + c]
                     + pre[static_cast<std::size_t>(r) * (C + 1) + c];
            }
            sink += acc;
        });
        std::printf("  查询 %8d 次：逐格累加 %10.3f ms，前缀和（含建表 %.3f）%10.3f ms  %s\n",
                    m, naive_total, build_ms, build_ms + pre_total,
                    build_ms + pre_total < naive_total ? "前缀和更省" : "逐格累加更省");
    }
    std::printf("\n（sink=%lld）\n", static_cast<long long>(sink));
    return 0;
}
```

> 区间越长、查询越多，建表越划算；区间很短或者只问几次，从头算更快。
> **这条判断应该在动手写代码之前做完**——它只用到两个数：数据规模与查询次数。

# 第 6 节 怎么选

| 你的情况 | 选择 | 理由 |
|---|---|---|
| 数据不变，反复求区间和 | **前缀和** | 建表 `O(n)`，查询 `O(1)`，每元素 8 字节 |
| 数据不变，反复求区间最值 | **稀疏表** | 查询 `O(1)`；代价是每元素 80 字节 |
| 成批的区间加，最后统一读一次 | **差分** | 每次区间加 `O(1)` |
| 数据会变，还要随时查 | 线段树／树状数组 | 见 `B` 段（本章不展开） |
| 只问几次、区间又短 | **从头算** | 建表的成本回不来 |
| 二维表格的矩形求和 | 二维前缀和 | 同一套思路再加一维，容斥两次 |

> [!NOTE]
> 这一章收成三句话：
> **区间查询的本质是「用空间换时间」——先把一部分结果算好，查询时只做几次访存；
> 换多少、怎么换，由「会不会变」和「问的是和还是最值」两个问题决定；
> 这笔交易有明确的回本点，本机实测在 1000 到 10000 次查询之间，
> 少于它就老老实实从头算。**

# 术语表

| 术语 | 含义 |
|---|---|
| **前缀和** | `pre[i]` 表示前 `i` 个元素的和；区间和由两次相减得到 |
| **差分** | `d[i] = a[i] - a[i-1]`；区间加变成两个位置的修改 |
| **稀疏表** | 对每个长度是 2 的幂的区间预先算好答案的表 |
| **可重复贡献** | 重叠计算不影响结果的运算，例如 `min`、`max`、`gcd`；加法不是 |
| **回本点** | 查询省下的时间补回建表开销所需的查询次数 |
| **线段树／树状数组** | 支持「随时改 + 随时查」的结构，不在本章 |

- 数组长度 100 万、每次查询的区间长度 1000、单次查询采样 20 万次，
  数据与查询区间都由固定种子生成，重跑一致；
- 每元素字节按**容量**算（`capacity()` × `sizeof`），是结构量，重跑逐位相同；
- 「建表过程中向堆申请的字节数」那一行里差分是 0：
  **记 0 不等于没分配**——那一次分配没有走到程序替换的那个 `operator new`，
  计数器因此没有记上。这也是本章的每元素字节**一律按容量算**的原因：
  容量是结构量，重跑逐位相同；计数器依赖替换是否被走到，不能当证据；
- 朴素那一列的 201.93 ns 包含 1000 次加法与循环开销，
  它是「区间长度 1000」这个前提下的数字，区间变长会线性增长；
- 建表、查询、修改都是计时量，每次重跑会浮动；
  倍数的方向（前缀和比朴素快一个数量级、稀疏表内存是 10 倍）稳定。
