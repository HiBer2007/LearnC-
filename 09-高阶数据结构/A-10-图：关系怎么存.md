前面九章存的东西都有一个共同点：**元素之间是排好序的**。
树按键的大小组织，数组按下标组织，哈希表按算出来的位置组织。
图不是这样——它存的是**关系**：谁和谁相连、连了多重。
关系本身没有「第一个」「第二个」之分，一个点可以和任意多个点相连，
因此前面那些结构的组织方式一个都用不上。

需求只有一句话：**给定一些点和一些边，要能回答「谁和谁相连」与「连了多重」。**
但这句话落到实现上会分岔：有时候要问「这两个点之间有没有边」，
有时候要问「这个点连出去的所有点是哪些」，
而这两种问法在同一个存法上的代价可以差几千倍。
本章把三种存法在三种密度下各测四项：建图时间、每边占多少字节、
遍历一个点的全部邻居、判断一条边是否存在。
结论在实测里：稀疏图上邻接表遍历邻居比邻接矩阵快 **1197 倍**，
而邻接矩阵查边只要 9 到 11 ns 且不随密度变化。

**图上怎么走（广度优先、深度优先、拓扑排序、最短路）归 `08` 板块**，
本章只讲「存」，以及**存法本身决定的代价**。

# 第 1 节 需求：点与边

## 1.1 三种存法的形状

`Text`

```text
   同一个图：4 个点，边是 (0,1) (0,2) (1,3)

   邻接矩阵（V×V 个位置，一位一条边）      邻接表（每个点一个数组）
        ┌───┬───┬───┬───┐                   0 → [1, 2]
        │ 0 │ 1 │ 2 │ 3 │                   1 → [0, 3]
     ┌──┼───┼───┼───┼───┤                   2 → [0]
     0  │ 0 │ 1 │ 1 │ 0 │                   3 → [1]
     1  │ 1 │ 0 │ 0 │ 1 │
     2  │ 1 │ 0 │ 0 │ 0 │                边表（就是一串对）
     3  │ 0 │ 1 │ 0 │ 0 │                   (0,1) (0,2) (1,3)
        └───┴───┴───┴───┘
```

**三种存法存的是同一份信息，代价分布完全不同**：矩阵把「有没有边」摊成一张表，
查得快、占得多；邻接表只存真正存在的边，遍历邻居快、查边要扫一个数组；
边表把边摊成一串，加边最快、别的都慢。

## 1.2 有向、无向、带权

| 需求 | 邻接矩阵 | 邻接表 | 边表 |
|---|---|---|---|
| 无向图 | 对称的两个位置都置位 | 两边各加一次 | 存一条，查的时候两个方向都试 |
| 有向图 | 只置一个位置 | 只加出边那一侧 | 存一条，方向就是 `(u, v)` 的顺序 |
| 带权图 | 位置存权值（不再是「一位」） | 每个邻居带一个权值 | 每条边带一个权值 |

**带权这一条把矩阵的成本放大了 8 倍**：位图可以用 1 位表示一条边，
带权就得每格存一个 `int` 或 `double`。
一万个点的矩阵从 12.5 MB 涨到 400 MB，这正是矩阵在带权图上少被采用的原因之一。

## 1.3 本章的测量口径

四项指标：

| 指标 | 怎么测 |
|---|---|
| 建图时间 | 把同一批边灌进每种结构所花的时间 |
| 每边字节 | 结构占的总字节数 ÷ 边数 |
| 遍历邻居 | 取一个点，把它的邻居全部读一遍，折算成每次的纳秒数 |
| 查边 | 判断一对点之间有没有边，折算成每次的纳秒数 |

**遍历邻居必须把邻居真的读出来**（本章的程序把邻居编号累加），
否则编译器会把整个循环优化掉——这一点在《09-高阶数据结构/A-00-导读：数据结构是问题的形状.md》第 3.3 小节已经作为纪律讲过。

# 第 2 节 邻接矩阵

一位表示一条边，因此 `V` 个点的图固定占 `V²/8` 字节，与边数无关。

`C++`

```cpp
/* 邻接矩阵的核心：位图 + 一次乘加定位 */
class Matrix {
public:
    explicit Matrix(int v) : v_(v), bits_(static_cast<std::size_t>(v) * v / 64 + 1, 0) {}
    void add(int a, int b) { set(a, b); set(b, a); }
    bool has(int a, int b) const {
        const std::size_t i = static_cast<std::size_t>(a) * v_ + b;
        return (bits_[i >> 6] >> (i & 63)) & 1ULL;      // 一次移位与一次按位与
    }
private:
    void set(int a, int b) {
        const std::size_t i = static_cast<std::size_t>(a) * v_ + b;
        bits_[i >> 6] |= 1ULL << (i & 63);
    }
    int v_;
    std::vector<std::uint64_t> bits_;
};
```

（上面是节选：完整程序在附录 A。）

| 优点 | 代价 |
|---|---|
| 查边是 `O(1)`，一次乘加加一次位测试 | 内存是 `V²/8` 字节，与边数无关 |
| 加边、删边都是 `O(1)` | **遍历一个点的邻居要把整行扫一遍**，`O(V)`，与这个点实际有几个邻居无关 |
| 判断「两个点是不是都有边」这类操作可以按位与一次算一批 | 带权就要每格存一个权值，内存再涨 8 倍 |

**「遍历邻居 `O(V)`」是矩阵最要命的一条**：一个点只有 4 个邻居时，
它也要看 `V` 个位置。实测里这一条差出一千多倍。

# 第 3 节 邻接表

每个点一个数组，里面只放它真正的邻居。加一条边就在两边的数组里各 `push_back` 一次。

`C++`

```cpp
/* 邻接表的核心：外层一个数组，每个元素自己一个数组 */
class AdjList {
public:
    explicit AdjList(int v) : adj_(static_cast<std::size_t>(v)) {}
    void add(int a, int b) { adj_[a].push_back(b); adj_[b].push_back(a); }
    bool has(int a, int b) const {
        const auto& row = adj_[a];
        return std::find(row.begin(), row.end(), b) != row.end();   // 扫这个点的邻居
    }
    long long neighbors(int a) const {
        long long sum = 0;
        for (int b : adj_[a]) sum += b;          // 每个邻居都被真的读一次
        return sum;
    }
private:
    std::vector<std::vector<int>> adj_;
};
```

（上面是节选：完整程序在附录 A。）

| 优点 | 代价 |
|---|---|
| 内存与边数成正比，稀疏图上很省 | 查边要扫这个点的邻居数组，`O(度数)` |
| 遍历邻居就是读一个数组，`O(度数)` 且连续 | 每个点一个 `std::vector`，头部的 24 字节 × `V` 是固定开销 |
| 天然支持「只遍历出边」（有向图只填一侧） | 删边要先把那条边找出来 |

**邻接表是绝大多数场合的默认选择**，因为现实里的图几乎都是稀疏的：
社交网络、网页链接、道路网、依赖关系，平均度数都远小于点数。

# 第 4 节 边表

只有一串 `(u, v)`，别的什么都没有。

`C++`

```cpp
/* 边表的核心：一串对，别的什么都没有 */
class EdgeList {
public:
    void add(int a, int b) { edges_.emplace_back(a, b); }        // 加边最快：一次追加
    bool has(int a, int b) const {
        for (const auto& e : edges_) {
            if ((e.first == a && e.second == b) || (e.first == b && e.second == a)) return true;
        }
        return false;                                            // 查边要扫全表
    }
private:
    std::vector<std::pair<int, int>> edges_;
};
```

（上面是节选：完整程序在附录 A。）

边表在两个场合反而最合适：

- **只需要遍历所有边**（比如「把每条边处理一遍」这种一次性任务）：
  边表的顺序访问是最紧凑的，没有额外结构；
- **边的集合要反复重建**（比如每次迭代都重新生成一批边）：
  加边的代价最低，只有一次追加。

| 场合 | 用边表 | 用邻接表 |
|---|---|---|
| 把每条边处理一遍 | 好，顺序访问 | 也可以，但要按点跳 |
| 反复查两个点是否相连 | **很慢**，`O(E)` | `O(度数)` |
| 反复取一个点的全部邻居 | **很慢**，`O(E)` | `O(度数)` |

# 第 5 节 三种密度下的四项实测

`C++`

```cpp
/* graph_storage.cpp    编译：g++ -std=c++17 -O2 graph_storage.cpp -o graph_storage
 * 图的三种存法在三种密度下的代价：建图时间、占多少字节、遍历一个点的全部邻居、判断一条边是否存在。
 * 图是随机规则图：每个点连 D 个互不相同的随机邻居，因此边数约为 V*D/2。
 * 三处方法上的交代：
 *   1. 采样用的点号与点对都提前生成好，不计进计时区间；
 *   2. 「遍历邻居」把邻居的编号累加起来，保证每个邻居都被真的读过（否则编译器会把循环优化掉）；
 *   3. 边表每次操作都要扫全表，因此按总工作量反推采样次数，并把次数打印出来。 */
#include <algorithm>
#include <chrono>
#include <cstdint>
#include <cstdio>
#include <cstdlib>
#include <new>
#include <random>
#include <utility>
#include <vector>

static long long g_bytes = 0;

void* operator new(std::size_t n) {
    g_bytes += static_cast<long long>(n);
    void* p = std::malloc(n ? n : 1);
    if (!p) throw std::bad_alloc();
    return p;
}
void operator delete(void* p) noexcept { std::free(p); }
void operator delete(void* p, std::size_t) noexcept { std::free(p); }

template <class F>
static double ms(F&& f) {
    const auto t0 = std::chrono::steady_clock::now();
    f();
    const auto t1 = std::chrono::steady_clock::now();
    return std::chrono::duration<double, std::milli>(t1 - t0).count();
}

// ---------------- 一、邻接矩阵：每一位表示一条边 ----------------
class Matrix {
public:
    explicit Matrix(int v) : v_(v), bits_(static_cast<std::size_t>(v) * v / 64 + 1, 0) {}
    void add(int a, int b) { set(a, b); set(b, a); }
    bool has(int a, int b) const {
        const std::size_t i = static_cast<std::size_t>(a) * v_ + b;
        return (bits_[i >> 6] >> (i & 63)) & 1ULL;
    }
    // 遍历 a 的全部邻居：矩阵只能把整行扫一遍，把命中位置的编号加起来
    long long neighbors(int a) const {
        long long sum = 0;
        for (int b = 0; b < v_; ++b) {
            if (has(a, b)) sum += b;
        }
        return sum;
    }
    std::size_t bytes() const { return bits_.size() * sizeof(std::uint64_t); }

private:
    void set(int a, int b) {
        const std::size_t i = static_cast<std::size_t>(a) * v_ + b;
        bits_[i >> 6] |= 1ULL << (i & 63);
    }
    int v_;
    std::vector<std::uint64_t> bits_;
};

// ---------------- 二、邻接表：每个点一个数组 ----------------
class AdjList {
public:
    explicit AdjList(int v) : adj_(static_cast<std::size_t>(v)) {}
    void add(int a, int b) { adj_[a].push_back(b); adj_[b].push_back(a); }
    bool has(int a, int b) const {
        const auto& row = adj_[a];
        return std::find(row.begin(), row.end(), b) != row.end();
    }
    long long neighbors(int a) const {
        long long sum = 0;
        for (int b : adj_[a]) sum += b;          // 每个邻居都被真的读一次
        return sum;
    }
    std::size_t bytes() const {
        std::size_t n = adj_.size() * sizeof(std::vector<int>);
        for (const auto& r : adj_) n += r.capacity() * sizeof(int);
        return n;
    }

private:
    std::vector<std::vector<int>> adj_;
};

// ---------------- 三、边表：只有一串 (u, v) ----------------
class EdgeList {
public:
    void add(int a, int b) { edges_.emplace_back(a, b); }
    bool has(int a, int b) const {
        for (const auto& e : edges_) {
            if ((e.first == a && e.second == b) || (e.first == b && e.second == a)) return true;
        }
        return false;
    }
    long long neighbors(int a) const {
        long long sum = 0;
        for (const auto& e : edges_) {
            if (e.first == a) sum += e.second;
            else if (e.second == a) sum += e.first;
        }
        return sum;
    }
    std::size_t bytes() const { return edges_.capacity() * sizeof(std::pair<int, int>); }

private:
    std::vector<std::pair<int, int>> edges_;
};

int main() {
    constexpr int V = 20000;
    constexpr int kNeighborSamples = 20000;      // 三种存法用同样的「遍历邻居」调用次数
    constexpr int kEdgeSamples = 200000;         // 「查边」的调用次数
    volatile long long sink = 0;

    struct Density {
        const char* name;
        int degree;
    };
    const Density densities[] = {
        {"稀疏", 4},
        {"中等", 64},
        {"稠密", 1000},
    };

    std::printf("点数 V = %d，邻接矩阵固定占 %zu 字节（V*V 位）\n", V,
                (static_cast<std::size_t>(V) * V / 64 + 1) * 8);
    std::printf("遍历邻居采样 %d 次，查边采样 %d 次\n\n", kNeighborSamples, kEdgeSamples);

    for (const Density& d : densities) {
        std::mt19937 rng(2024);
        std::vector<std::pair<int, int>> edges;
        edges.reserve(static_cast<std::size_t>(V) * d.degree / 2);
        for (int i = 0; i < V; ++i) {
            std::vector<int> pick(static_cast<std::size_t>(d.degree));
            for (int& x : pick) x = static_cast<int>(rng() % static_cast<unsigned>(V - 1));
            for (int& x : pick) if (x >= i) ++x;                 // 避开自己
            std::sort(pick.begin(), pick.end());
            pick.erase(std::unique(pick.begin(), pick.end()), pick.end());
            for (int b : pick) {
                if (i < b) edges.emplace_back(i, b);
            }
        }
        const std::size_t E = edges.size();

        // 采样点号与点对提前生成，不计进计时区间
        std::vector<int> vsel(kNeighborSamples);
        for (int& x : vsel) x = static_cast<int>(rng() % V);
        std::vector<std::pair<int, int>> esel(kEdgeSamples);
        for (auto& e : esel) {
            e.first = static_cast<int>(rng() % V);
            e.second = static_cast<int>(rng() % V);
        }

        std::printf("=== %s：%zu 条边（平均度 %.1f）===\n", d.name, E,
                    2.0 * static_cast<double>(E) / V);
        std::printf("%-10s %10s %14s %12s %18s %14s\n", "存法", "建图 ms", "总字节", "每边字节",
                    "遍历邻居 ns/次", "查边 ns/次");

        struct Row {
            const char* name;
            double build;
            long long bytes;
            double per_edge;
            double neighbor_ns;
            double has_ns;
            int neighbor_samples;
        };
        std::vector<Row> rows;

        {   // 邻接矩阵
            g_bytes = 0;
            Matrix m(V);
            const double t = ms([&] { for (const auto& e : edges) m.add(e.first, e.second); });
            const long long b = g_bytes;
            long long acc = 0;
            const double tn = ms([&] { for (int a : vsel) acc += m.neighbors(a); });
            sink += acc;
            long long hits = 0;
            const double th = ms([&] {
                long long h = 0;
                for (const auto& e : esel) h += m.has(e.first, e.second) ? 1 : 0;
                hits += h;
            });
            sink += hits;
            rows.push_back(Row{"邻接矩阵", t, b, double(b) / double(E), tn * 1e6 / kNeighborSamples,
                               th * 1e6 / kEdgeSamples, kNeighborSamples});
        }

        {   // 邻接表
            g_bytes = 0;
            AdjList g(V);
            const double t = ms([&] { for (const auto& e : edges) g.add(e.first, e.second); });
            const long long b = g_bytes;
            long long acc = 0;
            const double tn = ms([&] { for (int a : vsel) acc += g.neighbors(a); });
            sink += acc;
            long long hits = 0;
            const double th = ms([&] {
                long long h = 0;
                for (const auto& e : esel) h += g.has(e.first, e.second) ? 1 : 0;
                hits += h;
            });
            sink += hits;
            rows.push_back(Row{"邻接表", t, b, double(b) / double(E), tn * 1e6 / kNeighborSamples,
                               th * 1e6 / kEdgeSamples, kNeighborSamples});
        }

        {   // 边表：每次操作都要扫全表，按总工作量反推采样次数
            g_bytes = 0;
            EdgeList g;
            const double t = ms([&] { for (const auto& e : edges) g.add(e.first, e.second); });
            const long long b = g_bytes;
            const int ns = static_cast<int>(std::max<long long>(
                1, 200000000LL / static_cast<long long>(E)));
            const int hs = ns;
            long long acc = 0;
            const double tn = ms([&] {
                for (int s = 0; s < ns; ++s) acc += g.neighbors(vsel[static_cast<std::size_t>(s) % vsel.size()]);
            });
            sink += acc;
            long long hits = 0;
            const double th = ms([&] {
                long long h = 0;
                for (int s = 0; s < hs; ++s) {
                    const auto& e = esel[static_cast<std::size_t>(s) % esel.size()];
                    h += g.has(e.first, e.second) ? 1 : 0;
                }
                hits += h;
            });
            sink += hits;
            rows.push_back(Row{"边表", t, b, double(b) / double(E), tn * 1e6 / ns, th * 1e6 / hs, ns});
        }

        for (const Row& r : rows) {
            std::printf("%-10s %10.3f %14lld %12.2f %18.1f %14.1f\n", r.name, r.build, r.bytes,
                        r.per_edge, r.neighbor_ns, r.has_ns);
        }
        std::printf("（边表的每次操作要扫全表，因此它的两列按 %d 次采样折算；\n",
                    rows.back().neighbor_samples);
        std::printf("  矩阵与邻接表按 %d 次与 %d 次采样折算）\n\n", kNeighborSamples, kEdgeSamples);
    }

    std::printf("（sink=%lld）\n", static_cast<long long>(sink));
    return 0;
}
```

## 5.1 内存：一个与边数无关，一个与边数成正比

| 图的密度 | 边数 | 邻接矩阵总字节 | 矩阵每边字节 | 邻接表每边字节 |
|---|---|---|---|---|
| 稀疏 | 40067 | 50000008 | 1247.91 | 30.03 |
| 中等 | 637973 | 50000008 | 78.37 | 23.74 |
| 稠密 | 9754721 | 50000008 | **5.13** | 17.37 |

**矩阵的总字节数三行完全一样**（`V` 没变，`V²/8` 就没变），
所以「每边字节」这一列从 1247.91 掉到 5.13——
矩阵不是变便宜了，是**边变多了，同一笔钱被更多边摊掉**。

反过来，邻接表的每边字节从 30.03 降到 17.37，原因在另一头：
每个点那个 `std::vector` 的头部（24 字节 × 20000 = 480 KB）是固定开销，
边越多摊得越薄；稠密时它的 17.37 字节里，
真正的边只占 8 字节（两个方向各一个 `int`），其余是容量增长留下的余量。

> [!IMPORTANT]
> **矩阵的内存是 `V²` 的函数，邻接表是 `E` 的函数。**
> 稀疏图（`E` 与 `V` 同阶）用矩阵，等于拿 `V²` 的空间去装 `V` 条信息；
> 稠密图（`E` 接近 `V²`）两者才在一个量级上。
> **判断标准是「平均度数」**：几十以下用邻接表，几千以上才轮到矩阵。

## 5.2 遍历邻居：矩阵的 `O(V)` 与邻接表的 `O(度数)`

| 图的密度 | 平均度数 | 邻接矩阵 ns/次 | 邻接表 ns/次 | 倍数 |
|---|---|---|---|---|
| 稀疏 | 4.0 | 12684.5 | **10.6** | **1197** |
| 中等 | 63.8 | 12648.4 | 49.6 | 255 |
| 稠密 | 975.5 | 12669.0 | 443.8 | 29 |

**矩阵那一列三次几乎不变**（一万二千多纳秒）——它每次都把 20000 个位置
看一遍，与这个点有几个邻居无关。邻接表那一列跟着度数走：
10.6 → 49.6 → 443.8，折算成「每读一个邻居」大约是 2.7、0.78、0.45 纳秒，
**度数越大越便宜**，因为连续读一大段数组比读一小段更划算。

**稀疏图上差 1197 倍**，这就是「矩阵的邻居遍历是 `O(V)`」的实测含义。

## 5.3 查边：矩阵的常数时间

| 图的密度 | 邻接矩阵 ns/次 | 邻接表 ns/次 | 边表 ns/次 |
|---|---|---|---|
| 稀疏 | 9.1 | **12.1** | 11995.6 |
| 中等 | **8.9** | 39.5 | 192143.8 |
| 稠密 | 11.1 | 543.4 | 5129150.0 |

矩阵那一列在 9 到 11 纳秒之间，**不随密度变化**——一次乘加加一次位测试，
与图里有多少边无关。邻接表那一列跟着度数涨（12.1 → 39.5 → 543.4），
因为它在扫一个数组。边表那一列在稠密图上是 **5.1 毫秒一次**。

**稀疏图上两者几乎一样快**（邻接表 12.1 对矩阵 9.1 纳秒）：
扫 4 个 `int` 与「算下标、移位、掩码、访存」这一套代价相当，
而邻接表那个数组就在缓存里。度数一变大，这一列立刻被拉开。

## 5.4 建图：加边最快的是边表

| 图的密度 | 邻接矩阵 ms | 邻接表 ms | 边表 ms |
|---|---|---|---|
| 稀疏 | 9.677 | 2.472 | **0.303** |
| 中等 | 18.163 | 12.674 | **3.270** |
| 稠密 | 51.042 | 89.198 | **60.900** |

边表加一条边就是一次追加，因此它一直最快（稀疏时比邻接表快 8 倍）。
稠密时矩阵反而比邻接表快七成（51 对 89 毫秒），
因为矩阵只置两个位，而邻接表要 push 近两千万次、还要反复扩容。

> [!NOTE]
> 这一节的四张表可以压成两句话：
> **矩阵拿 `V²` 的空间换「查边 `O(1)`」，代价是遍历邻居要扫全场；
> 邻接表拿「查边要扫一个数组」换「遍历邻居 `O(度数)` 且内存与边数成正比」。
> 两者在稀疏图上的差距是 1197 倍对 1.2 倍——各有各的赢面，选错方向代价极大。**

# 第 6 节 怎么选

| 你的需求 | 选择 | 理由 |
|---|---|---|
| 图是稀疏的，要反复取邻居 | **邻接表** | 遍历邻居 `O(度数)`；内存与边数成正比 |
| 要反复判断两点是否相连 | **邻接矩阵** | 查边 `O(1)`，不随密度变化 |
| 只需要把所有边过一遍 | **边表** | 顺序访问最紧凑，加边最便宜 |
| 点很少（几百个）而边很密 | 邻接矩阵 | `V²` 小到可以忽略，换来的常数时间很值 |
| 点很多（几十万）而边很稀 | 邻接表 | 矩阵要 `V²/8` 字节，装不下 |
| 带权图 | 邻接表（邻居带权值） | 矩阵每格从一位变成一个权值，内存涨 8 倍 |
| 要判断「这两个点是否连通」 | 邻接表 + 图上走一遍 | 走法归 `08` 板块 |

> [!IMPORTANT]
> **选存法的判据是「图有多密」与「最常问哪个问题」，不是「哪种更高级」。**
> 同一个图，问「邻居有哪些」用邻接表，问「这条边在不在」用矩阵，
> 两者在稀疏图上的差距是 1197 倍与 1.2 倍——
> **先写下最常问的那个问题，再挑结构。**

**几点复现说明**：

- 图是**随机规则图**：每个点连 `degree` 个互不相同的随机邻居（用固定种子生成），
  因此边数约为 `V×degree/2`，重跑完全一致；
- 「遍历邻居」把邻居的编号累加起来，保证每个邻居都被真的读一次；
- 采样点号与查询点对都在计时区间之外生成，不计进耗时；
- 边表的每次操作要扫全表，因此它的两列按反推出来的采样次数折算，
  采样次数在输出里逐行列出（稀疏 4991 次、中等 313 次、稠密 10 次）；
- 建图时间与三个耗时列都是计时量，每次重跑会浮动；总字节、每边字节、
  边数与平均度是结构量，重跑逐位相同。

`待确认`

- 本章的程序是为了测量而写的最小实现：只有加边、查边、遍历邻居三个操作，
  没有删边、没有迭代器、没有内存池。**把它写对、写稳在 `B-04-手写：平衡树` 的量级之上**，
  本章不展开；
- 机器与编译器不同，纳秒数会变，但「矩阵的邻居遍历与度数无关」这个形状不会变；
- 带权图、有向图的三项对照没有单独测（本章的图都是无向无权），
  差异可以从「每格从一位变成一个权值」推算，属于 `待确认`。
