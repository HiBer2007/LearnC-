`A-03` 到最后留下了一个没有回答的问题：**为什么那张索引表是一棵树，而不是一个排好序的数组。**
当时的账是这么算的——排序数组的查找比 `map` 还快两倍多，
但插入慢一百倍、删除慢一千八百倍，于是选了树。

这一章补上后半句：树凭什么同时做到「查得快」和「改得快」。
答案不在平衡技巧里，而在于**树把「位置」与「顺序」这两件事分开了**：
数组里元素的位置就代表它的顺序，插一个进去必须把后面的全部挪走；
树里元素的顺序由节点之间的连接表示，位置则随便放，
插入只需要改几个指针。代价是每个节点要多存几个指针——
`map` 每个键值对因此要付 40 字节，而数据本身只有 8 字节。

但这份便宜有一个前提：**树不能长歪。** 一路插入递增的键，
朴素搜索树会长成一条链，查找退化成线性。
本章用实测把这件事说清楚：十万个键按有序顺序插入，
树高十万层，每次查找 142188 ns（程序 `bst_height.cpp`），是随机插入时的三千倍。
接下来的三节就是围绕这个前提展开的——旋转怎么把树扳正、
AVL 的高度条件与代价、以及红黑树为什么只求「近似平衡」就够用。
最后把自建的三种结构与标准库的 `map` 放在一起对照。

**这一章讲的是「为什么」。** 完整的平衡树实现（含删除与迭代器）见【待补：09-高阶数据结构/B-04-手写：平衡树.md】；
标准库那套红黑树的源码级分析不在本教材范围内。

# 第 1 节 有序数组的短板

## 1.1 三件事要同时满足

把 `A-03` 的那张表重新摆一次，这次只留一行：

| 做法 | 查找 | 插入 | 删除 | 按序遍历 |
|---|---|---|---|---|
| 排好序的数组 | `O(log n)` | **`O(n)`** | **`O(n)`** | `O(n)` |
| ？ | `O(log n)` | `O(log n)` | `O(log n)` | `O(n)` |

`实测数据`

| 20 万个键、2 万次插入、2 万次删除 | 有序 `vector` | `map` |
|---|---|---|
| 插入 | 175.879 ms | 1.658 ms |
| 删除 | 2415.484 ms | 1.343 ms |

**排序数组的查找够快，卡在改动上。** 一次插入要挪走的元素平均是一半，
两万次插入就是二十亿次搬移；删除更贵，因为每一次都要从删除点往前挪一整段。

## 1.2 树把「位置」与「顺序」分开

数组的缺陷在于**顺序由位置决定**：第 3 个元素比第 4 个小，
这件事是靠「它们在内存里挨着」实现的，于是插入必须重新排列位置。

树把这两件事分开：**顺序由连接决定，位置随便放。**

`Text`

```text
   数组：顺序 = 位置            树：顺序 = 连接

   ┌────┬────┬────┬────┐        ┌────────┐
   │ 10 │ 30 │ 50 │ 70 │        │   30   │  节点的位置由分配器决定，
   └────┴────┴────┴────┘        └───┬────┘  与它的大小关系无关
   插入 40 要挪走 50、70            ┌─┴─┐
                                    ▼   ▼
                                 ┌────┐┌────┐
                                 │ 10 ││ 50 │
                                 └────┘└────┘
   插入 40 只需挂一个新节点，改两个指针
```

这样一来，**查找路径的长度**成了唯一的代价来源：
树高多少，查找最坏就要比较多少次。于是问题变成「怎样让树尽量矮」，
这正是本章后面三节的内容。

至于每个节点要多付的指针，代价在 `A-03` 已经测过：

`实测数据`

| `map<int,int>` | 数值 |
|---|---|
| 容器对象自身大小 | 48 字节 |
| 每元素堆字节（10 万个键值对） | 40.00 字节/元素 |

**8 字节的数据，40 字节的开销。** 这笔钱买的是「改动便宜」。

# 第 2 节 朴素二叉搜索树

## 2.1 不变式

一棵二叉搜索树要满足一条性质：

> **对每个节点，它左子树里所有键都小于它，右子树里所有键都大于它。**

这一条性质加上「树是唯一的」，就保证了**中序遍历得到的是升序序列**。
查找、插入、删除三个操作全部依靠它：
每一步比较都能排除一整棵子树。

## 2.2 三个操作各做什么

| 操作 | 做法 | 复杂度 |
|---|---|---|
| 查找 | 从根开始，比目标小就往左，大就往右 | `O(树高)` |
| 插入 | 查找失败的位置就是新节点的位置 | `O(树高)` |
| 删除 | 分三种情况：叶子直接摘掉；只有一个孩子就用孩子顶上；有两个孩子就把后继（右子树里最小的）搬过来 | `O(树高)` |

**三个操作的复杂度都是「树高」，不是 `log n`。** 这个区别是这一章的全部要点：
树高等于 `log n` 时它就是 `log n`，树高等于 `n` 时它就是 `n`。

## 2.3 退化：有序输入下的实测

`C++`

```cpp
/* bst_height.cpp    编译：g++ -std=c++17 -O2 bst_height.cpp -o bst_height
 * 朴素二叉搜索树：随机输入与有序输入下，高度与查找代价随规模的变化。
 * 树高可能到十万层，因此插入、求高、销毁都写成迭代版本，避免递归爆栈。 */
#include <algorithm>
#include <chrono>
#include <cstdio>
#include <random>
#include <utility>
#include <vector>

struct Node {
    int key;
    Node* left = nullptr;
    Node* right = nullptr;
    explicit Node(int k) : key(k) {}
};

class Bst {
public:
    ~Bst() { clear(); }

    void insert(int k) {
        Node** slot = &root_;
        while (*slot) {
            if (k < (*slot)->key) slot = &(*slot)->left;
            else if (k > (*slot)->key) slot = &(*slot)->right;
            else return;                       // 相等的键不重复插入
        }
        *slot = new Node(k);
    }

    bool find(int k) const {
        const Node* p = root_;
        while (p) {
            if (k == p->key) return true;
            p = (k < p->key) ? p->left : p->right;
        }
        return false;
    }

    int height() const {
        int best = 0;
        std::vector<std::pair<const Node*, int>> st;
        if (root_) st.push_back({root_, 1});
        while (!st.empty()) {
            const auto [p, d] = st.back();
            st.pop_back();
            if (d > best) best = d;
            if (p->left) st.push_back({p->left, d + 1});
            if (p->right) st.push_back({p->right, d + 1});
        }
        return best;
    }

    void clear() {
        std::vector<Node*> st;
        if (root_) st.push_back(root_);
        while (!st.empty()) {
            Node* p = st.back();
            st.pop_back();
            if (p->left) st.push_back(p->left);
            if (p->right) st.push_back(p->right);
            delete p;
        }
        root_ = nullptr;
    }

private:
    Node* root_ = nullptr;
};

struct Row {
    int height;
    double ns_per_query;
};

static Row measure(const std::vector<int>& keys, const std::vector<int>& queries, int rounds) {
    Bst t;
    for (int k : keys) t.insert(k);

    volatile long long sink = 0;
    const auto t0 = std::chrono::steady_clock::now();
    long long hits = 0;
    for (int r = 0; r < rounds; ++r) {
        for (int q : queries) hits += t.find(q) ? 1 : 0;
    }
    const auto t1 = std::chrono::steady_clock::now();
    sink += hits;

    const double ns = std::chrono::duration<double, std::nano>(t1 - t0).count()
                      / (static_cast<double>(rounds) * static_cast<double>(queries.size()));
    return Row{t.height(), ns};
}

int main() {
    constexpr int Q = 1000;                 // 每次测量问 1000 个键
    std::printf("%9s %14s %10s %16s %8s\n", "元素数", "输入顺序", "树高", "每次查找 ns", "轮数");

    for (int n : {1000, 10000, 100000}) {
        std::vector<int> sorted(static_cast<std::size_t>(n));
        for (int i = 0; i < n; ++i) sorted[static_cast<std::size_t>(i)] = i;

        std::vector<int> shuffled = sorted;
        std::mt19937 rng(2024);
        std::shuffle(shuffled.begin(), shuffled.end(), rng);

        std::vector<int> queries(Q);
        for (int& q : queries) q = static_cast<int>(rng() % static_cast<unsigned>(n));

        const int rounds_random = 200;      // 平衡时每次查找只要几十步，多跑几轮
        const int rounds_sorted = 2;        // 退化成链时每次要走上万步，少跑几轮

        const Row r1 = measure(shuffled, queries, rounds_random);
        const Row r2 = measure(sorted, queries, rounds_sorted);

        std::printf("%9d %14s %10d %16.1f %8d\n", n, "随机", r1.height, r1.ns_per_query, rounds_random);
        std::printf("%9d %14s %10d %16.1f %8d\n", n, "有序", r2.height, r2.ns_per_query, rounds_sorted);
    }

    std::printf("\n理想高度（以 2 为底的对数上取整）：n=1000 约 10，n=10000 约 14，n=100000 约 17\n");
    return 0;
}
```

`待确认`

下面三条里，「随机二叉搜索树的期望高度约为 `4.3 ln n`」引自公开结论，
本章没有自己推导，也没有实测验证这条式子的常数。

**三件事一眼可见**：

- 有序输入下树高就等于元素个数——这棵树成了一条链，每个节点只有右孩子；
- 随机输入的树高也不是理想的 17，而是 45，**因为随机插入的树本来就不够矮**
  （随机二叉搜索树的期望高度约为 `4.3 ln n`；注意它是**期望值**，
  与 AVL 那个 `1.44 log₂ n` 的**最坏上界**不是同一类量，不能直接比大小）；
- 有序输入那一行的查找慢到 142188 ns，是随机输入那行的三千倍。

> [!IMPORTANT]
> **「二叉搜索树查找是 `O(log n)`」这句话只有在树平衡时才成立。**
> 三个操作的复杂度都是 `O(树高)`，而朴素插入不控制树高。
> 换成有序数据（时间戳、递增 ID、已经排好序的文件）就会退化——
> **这不是极端情况，而是最常见的情况之一。**

# 第 3 节 旋转：调整形状而不改变顺序

## 3.1 左旋与右旋各改哪几个指针

旋转是唯一的结构调整手段：**它改变树的形状，但不改变中序顺序。**
一次旋转只动三个指针。

`Text`

```text
   左旋：以 x 为轴，把它的右孩子 y 提上来

         x                    y
        / \                  / \
       A   y      ──►       x   C
          / \              / \
         B   C            A   B

   改的指针：
     1. x->right = y->left（B 换爸爸）
     2. y->left  = x
     3. 原来指向 x 的那个指针（父节点的孩子、或者根指针）改成指向 y
   中序：A x B y C  →  A x B y C（顺序没变）
```

`Text`

```text
   右旋：与左旋完全对称，把左孩子提上来

         y                    x
        / \                  / \
       x   C      ──►       A   y
      / \                      / \
     A   B                    B   C
```

**为什么中序不变**：旋转前 `A < x < B < y < C`，旋转后仍然是这个顺序，
只是 `x` 与 `y` 的父子关系对调了。这条性质是平衡树能成立的根本：
结构调整不影响「按序遍历得到升序」这个承诺。

## 3.2 旋转的实测

`C++`

```cpp
/* bst_rotate.cpp    编译：g++ -std=c++17 -O2 bst_rotate.cpp -o bst_rotate
 * 左旋与右旋改的是哪几个指针；旋转前后中序遍历不变 */
#include <cstdio>
#include <vector>

struct Node {
    int key;
    Node* left = nullptr;
    Node* right = nullptr;
    Node* parent = nullptr;
    explicit Node(int k) : key(k) {}
};

// 左旋：x 的右孩子 y 上位，成为 x 的父节点
static void rotate_left(Node*& root, Node* x) {
    Node* y = x->right;
    x->right = y->left;
    if (y->left) y->left->parent = x;
    y->parent = x->parent;
    if (!x->parent) root = y;
    else if (x == x->parent->left) x->parent->left = y;
    else x->parent->right = y;
    y->left = x;
    x->parent = y;
}

// 右旋：与左旋完全对称
static void rotate_right(Node*& root, Node* x) {
    Node* y = x->left;
    x->left = y->right;
    if (y->right) y->right->parent = x;
    y->parent = x->parent;
    if (!x->parent) root = y;
    else if (x == x->parent->right) x->parent->right = y;
    else x->parent->left = y;
    y->right = x;
    x->parent = y;
}

static Node* insert(Node*& root, int k) {
    Node** slot = &root;
    Node* par = nullptr;
    while (*slot) {
        par = *slot;
        if (k < (*slot)->key) slot = &(*slot)->left;
        else if (k > (*slot)->key) slot = &(*slot)->right;
        else return *slot;
    }
    *slot = new Node(k);
    (*slot)->parent = par;
    return *slot;
}

static void inorder(const Node* p) {
    if (!p) return;
    inorder(p->left);
    std::printf(" %d", p->key);
    inorder(p->right);
}

static void levelorder(const Node* root) {
    std::vector<const Node*> cur;
    if (root) cur.push_back(root);
    while (!cur.empty()) {
        std::vector<const Node*> next;
        std::printf("     ");
        for (const Node* p : cur) {
            std::printf("%4d", p->key);
            if (p->left) next.push_back(p->left);
            if (p->right) next.push_back(p->right);
        }
        std::printf("\n");
        cur.swap(next);
    }
}

static void free_tree(Node* p) {
    if (!p) return;
    free_tree(p->left);
    free_tree(p->right);
    delete p;
}

int main() {
    Node* root = nullptr;
    for (int k : {4, 2, 6, 1, 3, 5, 7}) insert(root, k);

    std::printf("== 初始 ==\n  中序：");
    inorder(root);
    std::printf("\n  按层：\n");
    levelorder(root);

    std::printf("\n== 对根做一次左旋 ==\n");
    rotate_left(root, root);
    std::printf("  新的根是 %d\n", root->key);
    std::printf("  中序：");
    inorder(root);
    std::printf("（与旋转前完全一样）\n");
    std::printf("  按层：\n");
    levelorder(root);

    std::printf("\n== 再对根做一次右旋（转回去）==\n");
    rotate_right(root, root);
    std::printf("  新的根是 %d\n", root->key);
    std::printf("  中序：");
    inorder(root);
    std::printf("\n  按层：\n");
    levelorder(root);

    std::printf("\n左孩子：%d  右孩子：%d\n",
                root->left ? root->left->key : -1,
                root->right ? root->right->key : -1);
    free_tree(root);
    return 0;
}
```

```text
        2   6
        1   3   5   7

左孩子：2  右孩子：6
```

**中序两次都是 `1 2 3 4 5 6 7`，而按层的形状变了两回。**
这就是旋转的全部意义：**换形状，不换顺序。**

# 第 4 节 平衡：AVL 树

## 4.1 高度条件

既然代价由树高决定，那就直接管住树高。AVL 树的条件是：

> **每个节点的左右子树高度之差不超过 1。**

这个条件足够强，能推出树高不超过约 `1.44 log₂ n`——
也就是说，最坏情况下也只比理想高度多四成。
代价是每次插入或删除之后都要检查条件，不满足就旋转。

## 4.2 四种失衡与对应旋转

插入之后，从插入点往上找**第一个失衡的节点**（高度差变成 2 的那个），
按新节点落在它的哪一侧，分成四种情形：

| 情形 | 形状 | 处理 |
|---|---|---|
| 左左 | 插在左孩子的左子树 | 一次右旋 |
| 右右 | 插在右孩子的右子树 | 一次左旋 |
| 左右 | 插在左孩子的右子树 | 先对左孩子左旋，再对自己右旋 |
| 右左 | 插在右孩子的左子树 | 先对右孩子右旋，再对自己左旋 |

**只有这四种**，而且处理完之后这棵子树的高度回到插入前的高度，
因此再往上的节点不必继续检查。

## 4.3 代价实测

下面这份程序把三种结构放在一起：朴素搜索树、自己写的 AVL、标准库的 `map`。
为了公平，三者都数**比较次数**——它就是查找走过的路径长度。
**这里的 AVL 是为了测量而写的最小实现**：只有插入与查找，
没有删除、没有迭代器、没有分配器与异常安全的处理；
完整的平衡树见【待补：09-高阶数据结构/B-04-手写：平衡树.md】。

`C++`

```cpp
/* bst_vs_balanced.cpp    编译：g++ -std=c++17 -O2 bst_vs_balanced.cpp -o bst_vs_balanced
 * 朴素搜索树、AVL 树、标准库 map 三者对照：树高、旋转次数、查找时的比较次数与耗时。
 * 比较次数用「路径长度」来量：每次比较一次键就是走了一层。 */
#include <algorithm>
#include <chrono>
#include <cmath>
#include <cstdio>
#include <map>
#include <random>
#include <utility>
#include <vector>

static long long g_cmp = 0;             // 比较计数器

// ---------------- 朴素二叉搜索树 ----------------
struct BNode {
    int key;
    BNode* left = nullptr;
    BNode* right = nullptr;
    explicit BNode(int k) : key(k) {}
};

class PlainBst {
public:
    ~PlainBst() { clear(root_); }
    void insert(int k) {
        BNode** slot = &root_;
        while (*slot) {
            if (k < (*slot)->key) slot = &(*slot)->left;
            else if (k > (*slot)->key) slot = &(*slot)->right;
            else return;
        }
        *slot = new BNode(k);
    }
    bool find(int k) const {
        const BNode* p = root_;
        while (p) {
            ++g_cmp;
            if (k == p->key) return true;
            p = (k < p->key) ? p->left : p->right;
        }
        return false;
    }
    int height() const {
        int best = 0;
        std::vector<std::pair<const BNode*, int>> st;
        if (root_) st.push_back({root_, 1});
        while (!st.empty()) {
            const auto [p, d] = st.back();
            st.pop_back();
            if (d > best) best = d;
            if (p->left) st.push_back({p->left, d + 1});
            if (p->right) st.push_back({p->right, d + 1});
        }
        return best;
    }

private:
    BNode* root_ = nullptr;
    static void clear(BNode* p) {
        std::vector<BNode*> st;
        if (p) st.push_back(p);
        while (!st.empty()) {
            BNode* q = st.back();
            st.pop_back();
            if (q->left) st.push_back(q->left);
            if (q->right) st.push_back(q->right);
            delete q;
        }
    }
};

// ---------------- AVL 树（只实现插入与查找）----------------
struct ANode {
    int key;
    int h = 1;
    ANode* left = nullptr;
    ANode* right = nullptr;
    explicit ANode(int k) : key(k) {}
};

class Avl {
public:
    ~Avl() { clear(root_); }
    void insert(int k) { root_ = insert(root_, k); }
    bool find(int k) const {
        const ANode* p = root_;
        while (p) {
            ++g_cmp;
            if (k == p->key) return true;
            p = (k < p->key) ? p->left : p->right;
        }
        return false;
    }
    int height() const { return root_ ? root_->h : 0; }
    long long rotations() const { return rotations_; }

private:
    ANode* root_ = nullptr;
    long long rotations_ = 0;

    static int h(const ANode* p) { return p ? p->h : 0; }
    static void fix(ANode* p) { p->h = 1 + std::max(h(p->left), h(p->right)); }
    static int balance(const ANode* p) { return p ? h(p->left) - h(p->right) : 0; }

    ANode* rotate_left(ANode* x) {
        ++rotations_;
        ANode* y = x->right;
        x->right = y->left;
        y->left = x;
        fix(x);
        fix(y);
        return y;
    }
    ANode* rotate_right(ANode* x) {
        ++rotations_;
        ANode* y = x->left;
        x->left = y->right;
        y->right = x;
        fix(x);
        fix(y);
        return y;
    }

    ANode* insert(ANode* p, int k) {
        if (!p) return new ANode(k);
        if (k < p->key) p->left = insert(p->left, k);
        else if (k > p->key) p->right = insert(p->right, k);
        else return p;
        fix(p);
        const int b = balance(p);
        if (b > 1 && k < p->left->key) return rotate_right(p);            // 左左
        if (b < -1 && k > p->right->key) return rotate_left(p);           // 右右
        if (b > 1 && k > p->left->key) {                                  // 左右
            p->left = rotate_left(p->left);
            return rotate_right(p);
        }
        if (b < -1 && k < p->right->key) {                                // 右左
            p->right = rotate_right(p->right);
            return rotate_left(p);
        }
        return p;
    }

    static void clear(ANode* p) {
        std::vector<ANode*> st;
        if (p) st.push_back(p);
        while (!st.empty()) {
            ANode* q = st.back();
            st.pop_back();
            if (q->left) st.push_back(q->left);
            if (q->right) st.push_back(q->right);
            delete q;
        }
    }
};

// ---------------- 标准库 map，带计数比较器 ----------------
struct CountingLess {
    bool operator()(int a, int b) const {
        ++g_cmp;
        return a < b;
    }
};

int main() {
    constexpr int N = 100000;
    constexpr int Q = 1000;
    std::mt19937 rng(2024);

    std::vector<int> sorted(static_cast<std::size_t>(N));
    for (int i = 0; i < N; ++i) sorted[static_cast<std::size_t>(i)] = i;
    std::vector<int> shuffled = sorted;
    std::shuffle(shuffled.begin(), shuffled.end(), rng);
    std::vector<int> queries(Q);
    for (int& q : queries) q = static_cast<int>(rng() % static_cast<unsigned>(N));

    struct Row {
        const char* name;
        int height;            // -1 表示测不到
        long long rotations;
        double cmp_per_query;
        double ns_per_query;
    };
    std::vector<Row> rows;

    auto run = [&](const char* name, auto&& insert_fn, auto&& find_fn, auto&& height_fn,
                   long long rotations, const std::vector<int>& keys, int rounds) {
        insert_fn(keys);
        g_cmp = 0;
        volatile long long sink = 0;
        const auto t0 = std::chrono::steady_clock::now();
        long long hits = 0;
        for (int r = 0; r < rounds; ++r) {
            for (int q : queries) hits += find_fn(q) ? 1 : 0;
        }
        const auto t1 = std::chrono::steady_clock::now();
        sink += hits;
        const double total = static_cast<double>(rounds) * static_cast<double>(Q);
        rows.push_back(Row{name, height_fn(), rotations, static_cast<double>(g_cmp) / total,
                           std::chrono::duration<double, std::nano>(t1 - t0).count() / total});
    };

    // 随机输入
    {
        PlainBst t;
        run("朴素 BST（随机输入）", [&](const std::vector<int>& k) { for (int x : k) t.insert(x); },
            [&](int q) { return t.find(q); }, [&] { return t.height(); }, 0, shuffled, 10);
    }
    {
        Avl t;
        run("AVL（随机输入）", [&](const std::vector<int>& k) { for (int x : k) t.insert(x); },
            [&](int q) { return t.find(q); }, [&] { return t.height(); }, 0, shuffled, 10);
        rows.back().rotations = t.rotations();
    }
    {
        std::map<int, int, CountingLess> m;
        run("std::map（随机输入）", [&](const std::vector<int>& k) { for (int x : k) m[x] = x; },
            [&](int q) { return m.find(q) != m.end(); }, [&] { return -1; }, 0, shuffled, 10);
    }

    // 有序输入
    {
        PlainBst t;
        run("朴素 BST（有序输入）", [&](const std::vector<int>& k) { for (int x : k) t.insert(x); },
            [&](int q) { return t.find(q); }, [&] { return t.height(); }, 0, sorted, 10);
    }
    {
        Avl t;
        run("AVL（有序输入）", [&](const std::vector<int>& k) { for (int x : k) t.insert(x); },
            [&](int q) { return t.find(q); }, [&] { return t.height(); }, 0, sorted, 10);
        rows.back().rotations = t.rotations();
    }
    {
        std::map<int, int, CountingLess> m;
        run("std::map（有序输入）", [&](const std::vector<int>& k) { for (int x : k) m[x] = x; },
            [&](int q) { return m.find(q) != m.end(); }, [&] { return -1; }, 0, sorted, 10);
    }

    std::printf("插入 %d 个键；每行测量都问同样 %d 个键、重复 10 轮（一行一项，便于横向比较）\n\n",
                N, Q);
    for (const Row& r : rows) {
        std::printf("[%s] 树高=", r.name);
        if (r.height < 0) std::printf("测不到");
        else std::printf("%d", r.height);
        if (r.rotations > 0) std::printf(" 旋转=%lld 次", r.rotations);
        std::printf(" 平均比较=%.1f 次/查询 每次查找=%.1f ns\n",
                    r.cmp_per_query, r.ns_per_query);
    }
    std::printf("\n理想高度：log2(%d) 约 %.0f\n", N, std::log2(static_cast<double>(N)));
    return 0;
}
```

|---|---|---|---|---|
| 朴素 BST | 45 | **100000** | 23.4 / 49933.5 | 0 |

| `std::map` | 不公开 | 不公开 | 18.0 / 18.1 | 不公开 |

三行数字各自说明一件事：

- **AVL 把有序输入下的树高从十万压到 17**，正好等于理想高度；

- **AVL 的旋转次数在有序输入下是 99983 次**，几乎每插入一个键就要转一次；

- **`std::map` 的平均比较次数是 18.0，比 AVL 的 16.0 多两次**，

> [!IMPORTANT]
> **AVL 的树高比朴素搜索树矮，是「平衡条件」直接换来的，不是旋转本身带来的；旋转只是把条件恢复回去的手段。**
> 旋转只是手段；真正决定代价的是那条条件——
> 「左右子树高度差不超过 1」把树高锁在了 `1.44 log₂ n` 以内。

# 第 5 节 红黑树：近似平衡就够用

## 5.1 条件放宽到哪一步

AVL 要求高度差不超过 1，是很强的条件。红黑树换了一条弱得多的条件，
它给每个节点加一个颜色（红或黑），并要求：

| 条件 | 作用 |
|---|---|
| 根是黑的 | 排除退化情形 |
| 每个节点非红即黑，空的叶子（NIL）算黑 | 第三条里的「黑节点个数」要有定义的对象 |
| 红节点的孩子必须是黑的 | **同一路径上不能连着两个红节点** |
| 从任一节点到它所有叶子的路径上，黑节点个数相同 | 各条路径的长度被锁在一个范围内 |

**前两条加第三条合起来推出的结论是：最长路径不超过最短路径的两倍。**
换句话说，树高被锁在 `2 log₂(n+1)` 以内，而 AVL 是 `1.44 log₂ n`——
十万个键时约 33 次比较对约 24 次，最坏情形多出四成上下。
红黑树就是用这四成换结构调整的次数。

## 5.2 为什么这四成可以接受

关键在代价的量级上：

| 平衡方式 | 树高上界 | 十万个键时的最坏比较次数 | 插入时的旋转 |
|---|---|---|---|
| 没有平衡 | `n` | 100 000 | 0 |
| AVL | `1.44 log₂ n` | 约 24 | 严格，可能连续多次 |
| 红黑树 | `2 log₂(n+1)` | 约 33 | 插入、删除各自只需常数次旋转 |

`待确认`

上表最后一行里「插入最多两次旋转、删除最多三次旋转」是红黑树的已知性质，
不是标准的规定；本章没有实测，也没有在本机程序里数过旋转次数。
AVL 与红黑树的树高上界同样引自公开结论，本章只实测了比较次数。

**每层多走一点，换掉的是结构调整的次数**：最坏比较次数从约 24 涨到约 33（约四成），
插入时却不必像 AVL 那样沿路径连续旋转。
这在「改得比查得还频繁」的场景里更值钱。
这就是「近似平衡够用」的完整理由：**用每次查找多几次比较，换掉大量结构调整。**

本机的实测把「比较次数」这一半测了出来：

`实测数据`
`Text`

```text
[AVL（随机输入）] 树高=20 旋转=69937 次 平均比较=16.0 次/查询 每次查找=27.4 ns
[std::map（随机输入）] 树高=测不到 平均比较=18.0 次/查询 每次查找=96.9 ns
[AVL（有序输入）] 树高=17 旋转=99983 次 平均比较=15.7 次/查询 每次查找=40.6 ns
[std::map（有序输入）] 树高=测不到 平均比较=18.1 次/查询 每次查找=113.6 ns
```

**两条结论**：

- 比较次数上，`std::map` 比 AVL 多约两次（18.0 对 16.0，18.1 对 15.7）；
  这两次里有一部分是记账口径的差别——本机 `std::map::find` 先走到下界、
  再做一次相等判断，比「一路比到相等就停」的自建查找多计一次比较，
  余下的才是「近似平衡」与「严格平衡」的路径长度差；
- 耗时上 `std::map` 更慢（96.9 对 27.4 ns），
  **但这不能归因于「红黑树比 AVL 差」**：两者是两个不同的实现，
  节点布局、内存分配方式、接口层次都不一样。
  能直接横向比较的只有结构量（树高与比较次数）。

> [!CAUTION]
> **不要用「自己写的 AVL 比 `std::map` 快」来论证 AVL 优于红黑树。**
> 上面那组耗时差异里混着实现差异：自建的树是几十行的裸结构，
> `std::map` 还要经过一层层的转发、支撑节点句柄与分配器接口。
> 要比平衡策略，只能比**路径长度**这类与实现无关的量。

## 5.3 标准只承诺复杂度

`文档`

> Table 90 —— `b.find(k)`：returns an iterator pointing to an element with the key
> equivalent to `k`, or `b.end()` if such an element is not found. 复杂度一栏：**logarithmic**。
> `a_uniq.insert(t)`：复杂度一栏 **logarithmic**。
> `a.erase(q1, q2)`：复杂度一栏 **`log(a.size()) + N`**, where `N` has the value
> `distance(q1, q2)`。
>
> —— N4659 §26.2.6 表 90

**标准从头到尾没有规定用什么树。** 它只要求「查找是对数、插入是对数」，
剩下的交给实现。这一点值得记住：`map` 的承诺是复杂度，不是红黑树；
换一套标准库换成 AVL、B 树或者跳表，只要复杂度达标都符合标准。

本机这套标准库用的是红黑树，这一点从它自己的头文件里就能看到。

`文档`

> "// Red-black tree class, designed for use in implementing STL
> // associative containers (set, multiset, map, and multimap)."
> `template<typename _Key, typename _Val, typename _KeyOfValue,`
> `         typename _Compare, typename _Alloc = allocator<_Val> >`
> `  class _Rb_tree`
>
> —— `<MinGW>/lib/gcc/<目标>/<版本号>/include/c++/bits/stl_tree.h`

**注意这是实现的选择，不是标准的要求。** 这也解释了为什么
`A-03` 里说「`map` 的迭代器是双向迭代器」而不是「随机访问」：

`文档`

> "iterator of an associative container is of the bidirectional iterator category."
>
> —— N4659 §26.2.6/6

**双向迭代器是标准的规定，不是节点式结构的必然结果**——
标准既然只承诺双向，`it + n` 这类操作在树上就不必提供常数时间的做法，
要跳 `n` 步就得走 `n` 次 `++`。

# 第 6 节 与 `std::map` 的对照

## 6.1 三组数字

| 对照 | 数字 | 说明 |
|---|---|---|
| 退化有多贵 | 排序插入 10 万个键后，查找 135288 ns 对 40.6 ns（程序 `bst_vs_balanced.cpp`） | 一棵链与一棵平衡树，差三千倍 |
| 平衡的代价 | AVL 有序插入 10 万次，旋转 99983 次 | 几乎每次插入都要转 |
| 平衡的收益 | 平均比较 16.0 次 对 23.4 次（朴素树随机输入） | 矮的树省的是比较次数 |

## 6.2 自己写还是用标准库

| 你的情况 | 选择 |
|---|---|
| 只要一个按键有序的容器 | **`std::map` / `std::set`**，标准库的实现比手写更周到 |
| 需要「按区间统计」「取前驱后继」 | 同上，接口已经齐了 |
| 要理解树怎么工作、要改结构（例如做区间树、持久化树） | 自己写，参考【待补：09-高阶数据结构/B-04-手写：平衡树.md】 |
| 数据只读、建好不再改 | 排序数组 + 二分（`A-03` 第 6 节） |
| 不需要有序 | 哈希表（`A-04`） |

**标准库那棵树值得用，理由有三条**：接口齐（迭代器、区间查询、节点句柄）、
删除也做了平衡（本章的 AVL 只实现了插入）、
分配器与异常安全都处理过。**自己写只在「要改结构」时才划算。**

# 第 7 节 怎么选

> [!NOTE]
> 这一章收成三句话：
> **树把「顺序」从「位置」里解放出来，因此查找与改动都能做到 `O(log n)`，
> 代价是每个节点多付几个指针；
> 但这个 `log n` 有前提——树必须平衡，朴素插入在有序数据上会退化成链，
> 十万个键实测慢三千倍；
> 平衡的做法不止一种：AVL 用严格的高度条件换矮树，红黑树用放宽的条件
> 换「旋转次数是常数」，两者都够用，标准只承诺复杂度、不指定实现。**

# 术语表

| 术语 | 含义 |
|---|---|
| **二叉搜索树** | 满足「左子树都小、右子树都大」的二叉树 |
| **不变式** | 结构必须始终满足的性质；插入删除后要恢复它 |
| **树高** | 从根到最远叶子的节点数 |
| **退化** | 树长成一条链，树高等于元素个数 |
| **旋转** | 改变树的形状但不改变中序顺序的局部调整 |
| **平衡因子** | 左右子树高度之差 |
| **AVL 树** | 要求每个节点平衡因子绝对值不超过 1 的搜索树 |
| **红黑树** | 用节点颜色约束路径长度的搜索树；最长路径不超过最短路径的两倍 |
| **摊还** | 把偶发的高代价分摊到多次操作上平均计算 |

**几点复现说明**：

- `bst_height.cpp` 里「有序」那几行的轮数少（2 轮），因为每次查找要走上万步；
- 第 1 节与第 2.3 小节引的是 `bst_height.cpp` 的数，第 4.3、5.2、6.1 小节引的是
  `bst_vs_balanced.cpp` 的数；同一现象（有序插入十万键后的朴素 BST 查找）
  两份程序分别测到 142188 ns 与 135288 ns，差别来自程序与轮数不同，不是矛盾；
  同一张表里的「每次查找 ns」是折算过的，两栏可以直接比；
- `bst_vs_balanced.cpp` 的六行用同样的轮数（10 轮），因此可以横向比较；
- `std::map` 的树高与旋转次数**测不到**——标准库不提供这两个接口，
  表里那一列只能空着，用比较次数代替；
- 树高与比较次数是结构量，随规模变化的趋势稳定；耗时数字每次重跑都会浮动。

`待确认`

同一份 `bst_vs_balanced.cpp` 重跑数次后观察到的区间：
AVL 的查找在 20 到 55 ns 之间，`std::map` 的查找在 80 到 120 ns 之间，
