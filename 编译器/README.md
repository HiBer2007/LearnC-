## 建议阅读顺序

```

    ↓
再动手搭环境        02-环境配置
    ↓
看真实代码怎么写     03-语言与案例

深入底层（可选）     04-嵌入式与交叉编译
```

**若时间有限**，只读 01 与 02 即可开始写程序。
