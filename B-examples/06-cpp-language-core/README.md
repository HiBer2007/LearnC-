# 示例 06 · 命令行统计小工具（单文件）

一个能真的用起来的小工具：把命令行上给的一串数读进来，按指定单位换算，
打印个数、总和、平均、最小、最大、中位数与总体标准差，最后跑一遍内置自测。

```
build\gcc\main.exe --unit cm 100 250 30
```

## 这个项目要解决什么问题

命令行给的是一串裸数字，人看不出门道。程序把它们变成一份统计报告，
并把输入单位换算成米一起给出，省得读者自己按计算器。

规模不大，但它把「一个完整的 C++ 小工具」该有的部分都占了：
命令行解析、错误提示、数据结构、计算、格式化输出、自带测试。

## 做完能掌握什么

- 知道 `const` 该加在哪一层：视图类里是成员指针，函数参数上是引用
- 知道花括号初始化与圆括号初始化在什么情况下给出不同结果
- 能从析构顺序看出临时对象的生存期被延长到哪里
- 会把能在编译期算完的东西写进 `constexpr` 与 `static_assert`
- 会写一个「程序自己核对结果」的自测段，而不是靠肉眼看输出

## 阶段推进

| 阶段 | 目标 | 做什么 | 怎么验收 |
|---|---|---|---|
| **阶段 1** | 跑通 | 按下面的命令编译并运行，看报告与自测 | 末尾出现「14 项中 14 项通过，全部通过」，退出码 0 |
| **阶段 2** | 改一处统计 | 加一个「极差」（最大减最小）输出，加一条自测核对它；`Summary` 与 `print_report` 都要动 | 新自测项通过；故意把公式写错一次，看自测能否指出是第几项 |
| **阶段 3** | 加一个单位 | 往 `kUnits` 里加 `{"inch", 0.0254}`，再跑一次；顺便把 `static_assert` 补一条 | 不必改别的代码，`--unit inch` 直接可用；自测仍全通过 |

阶段 3 是这个小项目的重点：单位表在编译期，加一行就多一种单位，
查表、换算、错误提示三处一起生效。


## 代码里哪几处是要点

| 位置 | 要点 |
|---|---|
| `main.cpp` 文件头 | `constexpr` 单位表与 `unit_to_meter`，四条 `static_assert` 把查表钉在编译期 |
| `Summary` / `Options` | 每个成员都带类内初始化器：某个分支忘了赋值也不会读到未定义值 |
| `class SampleView` | 成员是 `const double *` 与长度，视图不拥有数据，因此不能改调用者的数据 |
| `summarize(const SampleView &)` | 收引用不拷贝；中位数要排序，于是单独拷贝一份，不动调用者的数据 |
| `main` 里的 `const Summary &` | `const` 引用绑定到函数返回的临时对象，生存期延长到引用离开作用域 |
| `class LifetimeProbe` | 静态成员计数，构造与析构配不配对一眼可见；静态成员的类外定义也在这里 |
| `class SelfTest` | 自测把每一项写成一行，最后给出「几项中几项通过」，返回值直接当退出码 |

## 已知问题

- 报告中浮点数固定三位小数，标准差因此有舍入；自测里比较浮点用的是
  `nearly_equal`，不直接用 `==`
- 输入上限是 64 个数、单个数值绝对值不超过一百万，超过会给出提示而不是硬算
