抽奖、抽样、模拟、压测，这些程序里都有一句「随便挑一个」。写起来只有一行，
出错的时候却很难发现：抽出来的东西看上去随机，只是**某几个结果比另几个多了一点**。
多一点本身不会让程序崩溃，它只会让抽奖不公平、让抽样有偏、让模拟的结论偏一点点，
而这一点点偏差在跑够多次之后会稳定地留在结果里。

随机数从哪里来、怎么把它变成一个等概率的选择，这两步都有确定的写法；
难的是**验证**它确实等概率，因为「看上去随机」不是判据——
四个元素只有 24 种排列，洗几百万次把 24 个计数全打出来，
正确与错误的差别会直接写在数字上，不需要靠感觉。

最后一节把种子与可复现收成一条工程纪律：随机不等于不可复现，
**能让同一个种子跑出同一串数，才谈得上事后复现一次出问题的抽样。**

# 第 1 节 伪随机与真随机

## 1.1 一个真实的问题

一个压测工具要给每个请求生成一个随机的用户标识，从一万个候选里挑。
上线之后有人反馈：**排在前面的那几个标识出现得明显多一些。**
代码只有一行，`candidates[rand() % 10000]`，看不出哪里不对。

这一行有两个问题叠在一起：`rand()` 的值域与 10000 不成整数倍，以及
`RAND_MAX` 到底有多大取决于实现。第一个问题下一节展开，这一节先说清
「随机数」在程序里到底是什么东西。

## 1.2 伪随机是一个确定的序列

程序里能拿到的随机数，绝大多数来自一个**确定的状态机**：
它有一个内部状态，每次调用把它推进到下一个状态，并把状态的一部分作为输出返回。
这个状态机叫随机数引擎。它的行为完全确定——**给同一个初始状态，输出序列一模一样。**

初始状态叫种子。种子一旦定下，整条序列就定下了，因此：

| 说法 | 对不对 |
|---|---|
| 「随机数就是每次都不一样」 | 不对，同一个种子跑两次是一样的 |
| 「随机数是一串看不出规律的数」 | 对，规律在，只是不体现在相邻两项上 |
| 「设了种子就不随机了」 | 不对，设种子只是让这条序列可以重放 |

「周期」指序列多久重复一次。好的引擎周期长到在程序的生命周期里用不完：
`std::mt19937` 的周期是 `2^19937 − 1`，这个数字有六千多位十进制数。

## 1.3 标准把引擎写死了

伪随机的可复现性在 C++ 里不是「大概能复现」，而是**标准写明的硬性要求**。
`mt19937` 不只是一个名字，它是一整套参数：

`文档`

> "using `mt19937` = `mersenne_twister_engine`<`uint_fast32_t`,
> 32, 624, 397, 31, 0x9908b0df, 11, 0xffffffff, 7, 0x9d2c5680, 15, 0xefc60000, 18, 1812433253>;"
>
> "**Required behavior**: The 10000 th consecutive invocation of a default-constructed object
> of type `mt19937` shall produce the value 4123659995."
>
> —— N4659 §29.6.5/2、§29.6.5/3

第二句可以直接核对：默认构造一个 `mt19937`，连着调用一万次，把第一万次的返回值打出来。
下面这个程序做了这件事，并把另外三件事一起测了。

`C++`

```cpp
/* fixed_seed.cpp    编译：g++ -std=c++17 -O2 fixed_seed.cpp -o fixed_seed
 * 固定种子能不能换来可复现：同一个种子跑两遍、换一个种子、以及不设种子的
 * std::random_device，各自把前几个数打出来对照；洗牌同理。 */
#include <algorithm>
#include <cstdio>
#include <random>
#include <vector>

static void show(const char* tag, const std::vector<unsigned int>& v) {
    std::printf("  %s：", tag);
    for (unsigned int x : v) std::printf(" %u", x);
    std::printf("\n");
}

int main() {
    const int K = 5;
    {
        std::mt19937 a(42), b(42), c(43);
        std::vector<unsigned int> va, vb, vc;
        for (int i = 0; i < K; ++i) {
            va.push_back(a());
            vb.push_back(b());
            vc.push_back(c());
        }
        std::printf("== std::mt19937 的前 %d 个数 ==\n", K);
        show("种子 42 第一遍", va);
        show("种子 42 第二遍", vb);
        show("种子 43      ", vc);
        std::printf("  同种子两遍是否逐位相同：%s；换种子后是否相同：%s\n", va == vb ? "是" : "否",
                    va == vc ? "是" : "否");
    }
    {
        std::random_device d1, d2;
        std::vector<unsigned int> v1, v2;
        for (int i = 0; i < K; ++i) {
            v1.push_back(d1());
            v2.push_back(d2());
        }
        std::printf("== std::random_device 的前 %d 个数 ==\n", K);
        show("第一遍", v1);
        show("第二遍", v2);
        std::printf("  两遍是否逐位相同：%s\n", v1 == v2 ? "是" : "否");
        std::printf("  entropy = %.1f，范围 [%u, %u]\n", d1.entropy(), d1.min(), d1.max());
    }
    {
        std::vector<int> a(10), b(10);
        for (int i = 0; i < 10; ++i) a[i] = b[i] = i;
        std::mt19937 r1(7), r2(7);
        std::shuffle(a.begin(), a.end(), r1);
        std::shuffle(b.begin(), b.end(), r2);
        std::printf("== std::shuffle 用种子 7 洗两次 ==\n");
        std::printf("  第一遍：");
        for (int x : a) std::printf(" %d", x);
        std::printf("\n  第二遍：");
        for (int x : b) std::printf(" %d", x);
        std::printf("\n  两遍是否逐位相同：%s\n", a == b ? "是" : "否");
    }
    {
        // 标准把 mt19937 的第 10000 次输出写成了硬性要求，可以直接核对
        std::mt19937 g;                     // 默认构造，用默认种子 5489
        unsigned int x = 0;
        for (int i = 0; i < 10000; ++i) x = g();
        std::printf("== 默认构造的 std::mt19937 ==\n");
        std::printf("  第 10000 次调用得到 %u（标准写的是 4123659995）\n", x);
    }
    {
        // seed_seq：把好几个整数混成一个种子序列
        std::seed_seq s1{1, 2, 3, 4}, s2{1, 2, 3, 4};
        std::mt19937 a(s1), b(s2);
        std::vector<unsigned int> va, vb;
        for (int i = 0; i < K; ++i) {
            va.push_back(a());
            vb.push_back(b());
        }
        std::printf("== std::seed_seq{1,2,3,4} 两次 ==\n");
        show("第一遍", va);
        show("第二遍", vb);
        std::printf("  两遍是否逐位相同：%s\n", va == vb ? "是" : "否");
    }
    return 0;
}
```

块里 `random_device` 那两行每次运行都会变——这正是它的定义（见 12.1.4），**它们不是结构量，重跑对不上是正常的**；块里其余各行重跑都逐位相同。

这不是巧合，是标准规定的行为，换一个编译器、换一台机器都应当是这个数。
固定种子能跨实现复现，靠的就是这一类硬性要求。

## 1.4 `random_device`：唯一被允许不确定的那个

上面第二段输出里，`random_device` 两次调用给出的数不同，看上去正是「真随机」。
但同一段输出里还有一行：`entropy = 0.0`。

`文档`

> "**Returns**: A nondeterministic random value, uniformly distributed between `min()` and `max()`,
> inclusive. It is implementation-defined how these values are generated."
>
> —— N4659 §29.6.6/6

标准说 `random_device` 返回的值是**非确定的**，但**它怎么生成是实现定义的**。
`entropy()` 是它对「自己有多少不确定性」的估计：
返回 0 表示这个实现没有声称自己有不确定性——本机实测就是 0.0。

| 事实 | 本机实测结果 |
|---|---|
| 两次调用的前 5 个数 | 不同 |
| `entropy()` | 0.0 |
| `min()` 与 `max()` | 0 与 4294967295 |

> [!WARNING]
> **`random_device` 并不保证在每台机器上都是真随机源。**
> 本机（MinGW-w64 的 libstdc++）实测 `entropy()` 返回 0.0，
> 说明它不声称自己有不确定性；两次调用给出不同的数，只说明它有自己的状态，
> **不说明这个状态来自硬件。** 需要密码学强度的随机数时，
> 应当查清目标平台上这个类的实现，或者改用平台自己的接口。

这条结论只对本机这一套工具链成立，换一个标准库实现就是另一个结果，
因此不能推广成「`random_device` 都是假的」。

# 第 2 节 `<random>` 的正确用法与误用

## 2.1 取模偏差

回到 12.1.1 那一行 `candidates[rand() % 10000]`。把它缩小到可以数的规模：
从 0 到 999 里等概率取一个数，抽两千万次，数每个数出现多少回。

`C++`

```cpp
/* mod_bias.cpp    编译：g++ -std=c++17 -O2 mod_bias.cpp -o mod_bias
 * 三种「取 0 到 n-1 之间的随机数」的写法各抽两千万次，数每个数出现多少回：
 *   一、rand() % n；
 *   二、按比例缩放（把 rand() 的值映射到 [0, n)）；
 *   三、std::uniform_int_distribution。
 * 前两种用的是 C 的 rand()，第三种用 std::mt19937。 */
#include <cstdio>
#include <cstdlib>
#include <random>
#include <vector>

struct Stat {
    long long lo = 0, hi = 0;
    double chi2 = 0;
};

static Stat summarize(const std::vector<long long>& cnt, long long trials) {
    Stat s;
    s.lo = cnt[0];
    s.hi = cnt[0];
    const double expect = static_cast<double>(trials) / static_cast<double>(cnt.size());
    for (long long c : cnt) {
        if (c < s.lo) s.lo = c;
        if (c > s.hi) s.hi = c;
        const double d = static_cast<double>(c) - expect;
        s.chi2 += d * d / expect;
    }
    return s;
}

int main() {
    const int n = 1000;
    const long long trials = 20000000;
    std::printf("RAND_MAX = %d，取数范围 0 到 %d，抽 %lld 次\n", RAND_MAX, n - 1, trials);
    std::printf("每个数平均该出现 %.1f 次\n", static_cast<double>(trials) / n);
    std::printf("RAND_MAX + 1 = %lld，除以 %d 余 %lld\n", static_cast<long long>(RAND_MAX) + 1, n,
                (static_cast<long long>(RAND_MAX) + 1) % n);

    {
        std::vector<long long> cnt(n, 0);
        std::srand(20261002u);
        for (long long i = 0; i < trials; ++i) ++cnt[std::rand() % n];
        const Stat s = summarize(cnt, trials);
        std::printf("== rand() %% %d ==\n", n);
        std::printf("  最多的一格 %lld 次，最少的一格 %lld 次，相差 %.2f%%\n", s.hi, s.lo,
                    100.0 * (s.hi - s.lo) / (static_cast<double>(trials) / n));
        std::printf("  前 3 格：%lld %lld %lld；第 767 到 769 格：%lld %lld %lld\n", cnt[0], cnt[1],
                    cnt[2], cnt[767], cnt[768], cnt[769]);
        std::printf("  卡方 %.0f（自由度 %d，理论值应当在 %d 上下）\n", s.chi2, n - 1, n - 1);
    }
    {
        std::vector<long long> cnt(n, 0);
        std::srand(20261002u);
        for (long long i = 0; i < trials; ++i) {
            // 先算 rand() / (RAND_MAX + 1.0) 得到 [0,1)，再乘 n
            const int v = static_cast<int>(static_cast<double>(std::rand()) / (RAND_MAX + 1.0) * n);
            ++cnt[v];
        }
        const Stat s = summarize(cnt, trials);
        std::printf("== 按比例缩放（不用取模）==\n");
        std::printf("  最多的一格 %lld 次，最少的一格 %lld 次，相差 %.2f%%\n", s.hi, s.lo,
                    100.0 * (s.hi - s.lo) / (static_cast<double>(trials) / n));
        std::printf("  卡方 %.0f\n", s.chi2);
    }
    {
        std::vector<long long> cnt(n, 0);
        std::mt19937 rng(20261002u);
        for (long long i = 0; i < trials; ++i) ++cnt[rng() % static_cast<unsigned>(n)];
        const Stat s = summarize(cnt, trials);
        std::printf("== std::mt19937 取模 %% %d ==\n", n);
        std::printf("  最多的一格 %lld 次，最少的一格 %lld 次，相差 %.2f%%\n", s.hi, s.lo,
                    100.0 * (s.hi - s.lo) / (static_cast<double>(trials) / n));
        std::printf("  卡方 %.0f\n", s.chi2);
    }
    {
        std::vector<long long> cnt(n, 0);
        std::mt19937 rng(20261002u);
        std::uniform_int_distribution<int> dist(0, n - 1);
        for (long long i = 0; i < trials; ++i) ++cnt[dist(rng)];
        const Stat s = summarize(cnt, trials);
        std::printf("== std::uniform_int_distribution(0, %d) ==\n", n - 1);
        std::printf("  最多的一格 %lld 次，最少的一格 %lld 次，相差 %.2f%%\n", s.hi, s.lo,
                    100.0 * (s.hi - s.lo) / (static_cast<double>(trials) / n));
        std::printf("  卡方 %.0f\n", s.chi2);
    }
    return 0;
}
```

四千多意味着「这些数出现得明显不均」，不是运气问题。

## 2.2 偏差的根源不在取模

第二组是把 `rand()` 按比例缩放，完全不用取模。它的卡方是 4238，
**与第一组几乎一样。** 这一点是本节的要点：

`RAND_MAX` 在本机是 32767，于是 `rand()` 能取 32768 个不同的值。
32768 除以 1000 余 768，意思是**无论怎么映射，1000 个格子里必然有 768 个多分到一个值**。
取模时多分到的是前 768 个；按比例缩放时多分到的是另外一批——
**换了哪几个格子多，偏差的总量没变。**

| 写法 | 值域能被 1000 整除吗 | 卡方 |
|---|---|---|
| `rand() % 1000` | 不能（余 768） | 4246 |
| `rand()` 按比例缩放 | 不能（余 768） | 4238 |
| `std::mt19937` 直接取模 | 不能（余 296） | 983 |
| `std::uniform_int_distribution` | 与值域无关，实现自己处理 | 993 |

第三、四组的卡方落在 999 上下，说明它们没有可测量的偏差。
第三组**也是取模**，它量不出偏差的算术原因是 `mt19937` 的值域是 `2^32`：
`2^32 = 4294967296` 除以 1000 余 296，1000 个格子里有 296 个少分到一个值，
相对偏差是 `296 ÷ 2^32` ≈ `7 × 10^-8`——这是**算术事实**，由值域与 1000 的整除关系定下，与抽了多少次无关。
块里第三组的卡方 983 是**这一次抽样的观测值**：两千万次抽样在这个量级上量不出偏差，
观测结果与算术事实一致；一个说偏差有多小，一个说这次抽样测没测出来，两者不能互相代替。

> [!IMPORTANT]
> **「取模有偏差」这句话不完整，准确的说法是「值域的模长与 n 不成整数倍时有偏差」。**
> 值域越大，同样的偏差越小；`rand()` 在 `RAND_MAX = 32767` 的实现上，
> 值域小到取 1000 个数就露出 7% 的差。
> 换一个 `RAND_MAX = 2147483647` 的实现，同一行代码的偏差会小三个数量级——
> **同一份代码在不同平台上偏差不同，这类问题因此很难在开发机上发现。**

`std::uniform_int_distribution` 的做法是拒绝采样：
把值域切成若干个长度为 n 的整段，落在最后那个不满一段的尾部时重新抽一次。
标准对它的输出是这样要求的：

`文档`

> "A `uniform_int_distribution` random number distribution produces random integers `i`,
> `a` ≤ `i` ≤ `b`, distributed according to the constant discrete probability function
> P(i|a, b) = 1/(b − a + 1)."
>
> —— N4659 §29.6.8.2.1/1

「概率恒为 `1/(b − a + 1)`」正是「每个数等概率」的写法。
用它的时候，取模、缩放、值域这些事都不用自己管。

## 2.3 用法纪律

| 纪律 | 反面写法 | 后果 |
|---|---|---|
| 引擎与分布分开 | 每次抽都构造一个分布对象 | 分布对象可能带内部状态，重建会浪费并改变序列 |
| 分布对象只建一次 | `for (...) v.push_back(std::uniform_int_distribution<int>(0,9)(rng));` | 每轮一次构造，慢且语义不清 |
| 需要均匀整数就用 `uniform_int_distribution` | 自己写 `% n` | 见 12.2.2 |
| 需要 `[0,1)` 的浮点就用 `uniform_real_distribution` | `rng() / (double)UINT32_MAX` | 端点取值与精度都要自己论证 |
| 不要用 `rand()` 写新代码 | `srand(time(0))` 加 `rand()%n` | 值域小、周期短、全局状态、不可复现 |
| 种子的类型要对 | `std::mt19937 rng(1.5)` | 隐式转换后种子含义不明，改用 `seed_seq` |

# 第 3 节 洗牌

## 3.1 一个真实的问题

一个抽奖程序要把参与者的名单打乱，然后按顺序取前几名。
「打乱」这件事看上去随便换几下就行，实际上有一个硬性要求：
**每一种排列出现的概率必须相同。**

十个元素的排列有一百万种以上，靠肉眼看不出差别；
但四个元素只有 24 种排列，把 24 种各出现多少次打出来，正确与错误的差别一眼可见。
这就是验证洗牌的办法：**把规模缩到能数清，把每个结果的出现次数全列出来。**

## 3.2 Fisher–Yates

正确写法只有三行：

（下面是节选，取自本节下面那个程序）

`C++`

```cpp
    for (int i = N - 1; i > 0; --i) {
        std::uniform_int_distribution<int> d(0, i);
        std::swap(a[i], a[d(rng)]);
    }
```

从最后一位开始，把它与「从第 0 位到它自己」之间的随机一位交换，然后往前挪一位。
第 i 位可选的搭档有 `i + 1` 个，因此第 i 位最终落到哪个值的概率是 `1/(i+1)`；
连乘起来，每一种排列的概率是 `1/n × 1/(n-1) × … × 1/2 = 1/n!`，正好是等概率。

`Text`

```text
   n = 4 时，正确写法的三次交换：

   第 3 位 ← 与 [0,3] 里的随机一位换     4 种可能
   第 2 位 ← 与 [0,2] 里的随机一位换     3 种可能
   第 1 位 ← 与 [0,1] 里的随机一位换     2 种可能
                                         ─────────
                                         4×3×2 = 24 种路径

   24 条路径对应 24 种排列，一条对一种，因此每种排列的概率都是 1/24。
```

## 3.3 怎么验「每个排列等概率」

`C++`

```cpp
/* shuffle_check.cpp    编译：g++ -std=c++17 -O2 shuffle_check.cpp -o shuffle_check
 * 四个元素的洗牌，两种写法各洗 480 万次，数出 24 种排列各出现多少回：
 *   正确版：从后往前，第 i 位与 [0, i] 里的随机一位交换；
 *   错误版：从前往后，第 i 位与 [0, n-1] 里的随机一位交换。
 * 正确版的 24 个计数应当都在平均值附近，错误版会明显不均。 */
#include <algorithm>
#include <cstdio>
#include <random>
#include <vector>

static const int N = 4;

// 四个元素取值 0..3，直接编码成四位四进制数
static int code_of(const std::vector<int>& a) {
    return ((a[0] * N + a[1]) * N + a[2]) * N + a[3];
}

static void shuffle_right(std::vector<int>& a, std::mt19937& rng) {
    for (int i = N - 1; i > 0; --i) {
        std::uniform_int_distribution<int> d(0, i);
        std::swap(a[i], a[d(rng)]);
    }
}

static void shuffle_wrong(std::vector<int>& a, std::mt19937& rng) {
    for (int i = 0; i < N; ++i) {
        std::uniform_int_distribution<int> d(0, N - 1);
        std::swap(a[i], a[d(rng)]);
    }
}

struct Stat {
    long long lo = 0, hi = 0;
    double chi2 = 0;
};

static Stat summarize(const std::vector<long long>& cnt, long long total, int kinds) {
    Stat s;
    s.lo = -1;
    s.hi = 0;
    const double expect = static_cast<double>(total) / kinds;
    for (long long c : cnt) {
        if (c == 0) continue;                 // 只统计合法排列
        if (s.lo < 0 || c < s.lo) s.lo = c;
        if (c > s.hi) s.hi = c;
        const double d = static_cast<double>(c) - expect;
        s.chi2 += d * d / expect;
    }
    return s;
}

int main() {
    const long long trials = 4800000;          // 每种排列平均 20 万次
    std::vector<long long> right(256, 0), wrong(256, 0);
    std::mt19937 rng1(20261002u), rng2(20261002u);
    std::vector<int> a(N);
    for (long long t = 0; t < trials; ++t) {
        for (int i = 0; i < N; ++i) a[i] = i;
        shuffle_right(a, rng1);
        ++right[code_of(a)];
        for (int i = 0; i < N; ++i) a[i] = i;
        shuffle_wrong(a, rng2);
        ++wrong[code_of(a)];
    }

    std::printf("四个元素，洗 %lld 次，每种排列平均 %.0f 次\n", trials,
                static_cast<double>(trials) / 24);
    std::printf("%-8s %12s %12s\n", "排列", "正确版", "错误版");
    std::vector<int> p(N);
    for (int i = 0; i < N; ++i) p[i] = i;
    do {
        const int c = code_of(p);
        std::printf("%d%d%d%d     %12lld %12lld\n", p[0], p[1], p[2], p[3], right[c], wrong[c]);
    } while (std::next_permutation(p.begin(), p.end()));

    const Stat sr = summarize(right, trials, 24);
    const Stat sw = summarize(wrong, trials, 24);
    std::printf("正确版：最多 %lld，最少 %lld，最多是最少的 %.2f 倍，卡方 %.1f\n", sr.hi, sr.lo,
                static_cast<double>(sr.hi) / static_cast<double>(sr.lo), sr.chi2);
    std::printf("错误版：最多 %lld，最少 %lld，最多是最少的 %.2f 倍，卡方 %.1f\n", sw.hi, sw.lo,
                static_cast<double>(sw.hi) / static_cast<double>(sw.lo), sw.chi2);
    std::printf("自由度 23 的卡方，理论值应当在 23 上下，超过 44 就说明分布明显不均\n");
    return 0;
}
```

## 3.4 错误版为什么错

错误写法是从前往后，每一位都与**整个数组**里的随机一位交换。
它也有 24 种可能的路径吗？没有：每一位有 4 种选择，一共 `4^4 = 256` 条路径。
256 条路径要摊到 24 种排列上，256 除以 24 不是整数，
**因此必然有一些排列对应更多条路径**，概率不再相同。

正确写法只有 `4 × 3 × 2 = 24` 条路径，一条对一种排列，这才是等概率的来源。
判据可以背下来：**每一位可选的搭档数必须正好等于「还剩多少个位置没定」，不能多。**

| 写法 | 每一位的选择范围 | 路径数 | 等概率吗 |
|---|---|---|---|
| 从后往前，第 i 位与 `[0, i]` 换 | `i + 1` | `n!` | 是 |
| 从前往后，第 i 位与 `[0, n-1]` 换 | `n` | `n^n` | 否 |
| 从前往后，第 i 位与 `[i, n-1]` 换 | `n - i` | `n!` | 是（另一种等价写法） |
| 随机取两个下标交换，重复 n 次 | — | — | 否，次数不够时离均匀还很远 |

标准对 `std::shuffle` 的要求正是「每种排列等概率」，同时把交换次数写死：

`文档`

> "**Effects**: Permutes the elements in the range `[first, last)` such that each possible
> permutation of those elements has equal probability of appearance."
>
> "**Complexity**: Exactly `(last - first) - 1` swaps."
>
> —— N4659 §28.6.13/2、§28.6.13/3

「恰好 `n − 1` 次交换」就是 Fisher–Yates 的次数。
自己写洗牌时对照这一条，比对着代码逐行读更快发现问题：
**循环里做了几次交换，是不是 `n − 1` 次。**

# 第 4 节 蓄水池抽样

## 4.1 不知道总数

日志是流式来的，长度事先不知道，可能是一千行，也可能是一亿行。
需求是「随机留 10 行做样本，每行被留下的概率相同」。

难点在于**概率里的分母不知道**。抽第 i 行时，你不知道后面还有多少行，
因此无法算出「它最终被留下的概率应该是多少」。
蓄水池抽样（reservoir sampling）绕开了这一点：
它按「读到第几行」来算概率，读完最后一行时，每一行被留下的概率都相同。

## 4.2 算法 R

规则只有两句：

| 读到第 i 行（从 1 开始数） | 怎么做 |
|---|---|
| `i ≤ k` | 直接放进池子（池子还没满） |
| `i > k` | 以 `k / i` 的概率替换掉池子里随机一行 |

实现时不必真的算 `k / i` 再抽一次，可以取一个 `[0, i]` 的随机整数 `j`，
`j < k` 就替换第 `j` 行——两种写法等价，后者少一次浮点运算。

`Text`

```text
   k = 2，读到第 5 行时：

   池子：[第 1 行] [第 4 行]
   取 j = uniform(0, 5)，j 有 6 个取值
   j < 2（也就是 j 为 0 或 1）时替换，概率 2/6 = 1/3 = k/i

   第 5 行被留下的概率是 1/3；
   池子里那两行各自被替换掉的概率是 1/6。
```

## 4.3 实测：数每个位置被留下的次数

`C++`

```cpp
/* reservoir_check.cpp    编译：g++ -std=c++17 -O2 reservoir_check.cpp -o reservoir_check
 * 蓄水池抽样：流里有 100 个数，只留 10 个，等概率。
 *   正确版：前 10 个先进池；第 i 个（从 11 起）以 10/i 的概率替换掉池里随机一格；
 *   错误版：前 10 个先进池；之后每个都以二分之一的概率替换掉池里随机一格。
 * 两种写法各跑 20 万遍，数每个位置被留下的次数。 */
#include <cstdio>
#include <random>
#include <vector>

static const int STREAM = 100;
static const int KEEP = 10;

// 正确版：第 i 个元素（0 基，i >= KEEP）以 KEEP/(i+1) 的概率进池
static void reservoir_right(std::mt19937& rng, std::vector<long long>& hit) {
    int pool[KEEP];
    for (int i = 0; i < STREAM; ++i) {
        if (i < KEEP) {
            pool[i] = i;
        } else {
            std::uniform_int_distribution<int> d(0, i);
            const int j = d(rng);
            if (j < KEEP) pool[j] = i;
        }
    }
    for (int x : pool) ++hit[x];
}

// 错误版：不管读到第几个，都用固定的二分之一概率替换
static void reservoir_wrong(std::mt19937& rng, std::vector<long long>& hit) {
    int pool[KEEP];
    for (int i = 0; i < STREAM; ++i) {
        if (i < KEEP) {
            pool[i] = i;
        } else {
            std::uniform_int_distribution<int> d(0, KEEP - 1);
            if (rng() % 2u == 0) pool[d(rng)] = i;
        }
    }
    for (int x : pool) ++hit[x];
}

static double chi_square(const std::vector<long long>& hit, double expect) {
    double s = 0;
    for (long long h : hit) {
        const double d = static_cast<double>(h) - expect;
        s += d * d / expect;
    }
    return s;
}

int main() {
    const long long trials = 200000;
    const double expect = static_cast<double>(trials) * KEEP / STREAM;
    std::printf("流里 %d 个数，留 %d 个，跑 %lld 遍\n", STREAM, KEEP, trials);
    std::printf("每个位置平均该被留下 %.0f 次\n", expect);

    std::vector<long long> hr(STREAM, 0), hw(STREAM, 0);
    std::mt19937 rng1(20261002u), rng2(20261002u);
    for (long long t = 0; t < trials; ++t) {
        reservoir_right(rng1, hr);
        reservoir_wrong(rng2, hw);
    }

    long long rlo = hr[0], rhi = hr[0], wlo = hw[0], whi = hw[0];
    for (int i = 0; i < STREAM; ++i) {
        rlo = hr[i] < rlo ? hr[i] : rlo;
        rhi = hr[i] > rhi ? hr[i] : rhi;
        wlo = hw[i] < wlo ? hw[i] : wlo;
        whi = hw[i] > whi ? hw[i] : whi;
    }
    std::printf("正确版：最少 %lld，最多 %lld，最多是最少的 %.2f 倍，卡方 %.1f\n", rlo, rhi,
                static_cast<double>(rhi) / static_cast<double>(rlo), chi_square(hr, expect));
    std::printf("错误版：最少 %lld，最多 %lld，最多是最少的 %.2f 倍，卡方 %.1f\n", wlo, whi,
                static_cast<double>(whi) / static_cast<double>(wlo), chi_square(hw, expect));
    std::printf("前 5 个位置：正确版");
    for (int i = 0; i < 5; ++i) std::printf(" %lld", hr[i]);
    std::printf("；错误版");
    for (int i = 0; i < 5; ++i) std::printf(" %lld", hw[i]);
    std::printf("\n后 5 个位置：正确版");
    for (int i = STREAM - 5; i < STREAM; ++i) std::printf(" %lld", hr[i]);
    std::printf("；错误版");
    for (int i = STREAM - 5; i < STREAM; ++i) std::printf(" %lld", hw[i]);
    std::printf("\n自由度 %d 的卡方，理论值应当在 %d 上下，超过 %d 就说明分布明显不均\n",
                STREAM - 1, STREAM - 1, STREAM + 45);
    return 0;
}
```

## 4.4 标准里的 `std::sample`

C++17 起标准库直接提供了这个功能，`std::sample` 从一个已知范围里抽 n 个，
不重复且等概率：

`文档`

> "**Effects**: Copies `min(last - first, n)` elements (the *sample*) from `[first, last)`
> (the *population*) to `out` such that each possible sample has equal probability of appearance.
> [*Note*: Algorithms that obtain such effects include *selection sampling* and *reservoir sampling*.
> — *end note*]"
>
> "**Complexity**: `O(last - first)`."
>
> —— N4659 §28.6.12/2、§28.6.12/4

标准原文里点了 reservoir sampling 这个名字，也说明了复杂度是**一遍扫描**。
两者怎么选：

| 情形 | 用哪个 |
|---|---|
| 输入是一个已知的区间（有首尾迭代器） | `std::sample` |
| 输入是流，长度事先不知道 | 自己写蓄水池 |
| 输入已知但只想读一遍（网络流、管道） | 自己写蓄水池 |
| 要按权重抽 | 两者都不行，见 12.5 |

# 第 5 节 加权抽样与别名法

## 5.1 一个真实的问题

广告投放要按权重选一个广告位：权重大的多投，权重小的少投，比例要准。
候选有 1000 个，权重是 1 到 1000，一次投放要抽一次。
抽一次很快，问题是**一天要抽几十亿次**。

加权抽样的两种做法差别不在正确性，而在**每次抽的代价**：

| 做法 | 建表 | 每次抽 |
|---|---|---|
| 前缀和 + 二分查找 | `O(n)` | `O(log n)` |
| 别名法（Vose） | `O(n)` | `O(1)` |

## 5.2 别名法在做什么

把每个格子的权重按平均权重缩放：权重正好等于平均值的格子缩放成 1，
比平均值小的缩成小于 1，比平均值大的缩成大于 1。
然后反复做一件事：**拿一个不满的格子，从某个超出的格子里借一点补满它。**

`Text`

```text
   三个元素，权重 1、1、4，平均权重 2：

   缩放后：  0.5    0.5    2.0
             ─┘     ─┘     └── 超出部分要分给别人

   第 0 格借第 2 格的 0.5 补满 → prob[0] = 0.5, alias[0] = 2
   第 1 格借第 2 格的 0.5 补满 → prob[1] = 0.5, alias[1] = 2
   第 2 格剩下 1.0              → prob[2] = 1.0, alias[2] = 2

   抽一次：先等概率选一格 i，再取 u = uniform(0,1)；
           u < prob[i] 就返回 i，否则返回 alias[i]。
```

每次抽只需要「一次等概率选格 + 一次比较」，与元素个数无关。
建表要遍历两遍，代价是 `O(n)`，但只在权重变化时做一次。

`C++`

```cpp
/* alias_method.cpp    编译：g++ -std=c++17 -O2 alias_method.cpp -o alias_method
 * 加权抽样：1000 个元素，权重 1 到 1000，抽一次要按权重挑一个。
 *   方法一：前缀和数组 + 二分查找，每次抽 O(log n)；
 *   方法二：别名法，先花 O(n) 建两张表，之后每次抽 O(1)。
 * 两张表各建一千次取平均（单次建表贴着时钟分辨率，测不准），
 * 再各抽一千万次计时，最后用一百万次抽样核对分布。 */
#include <algorithm>
#include <chrono>
#include <cstdio>
#include <random>
#include <vector>

using Clock = std::chrono::steady_clock;

static const int N = 1000;

int main() {
    std::vector<long long> w(N);
    long long total = 0;
    for (int i = 0; i < N; ++i) {
        w[i] = i + 1;
        total += w[i];
    }
    std::printf("== %d 个元素，权重 1 到 %d，权重和 %lld ==\n", N, N, total);

    std::vector<long long> prefix(N);
    std::vector<double> prob(N);
    std::vector<int> alias(N);

    // ---- 两张表各建一千次，取每次的平均耗时 ----
    const int build_reps = 1000;
    double t_prefix = 0, t_alias = 0;
    long long sink = 0;
    for (int rep = 0; rep < build_reps; ++rep) {
        const auto b0 = Clock::now();
        long long acc = 0;
        for (int i = 0; i < N; ++i) {
            acc += w[i];
            prefix[i] = acc;
        }
        const auto b1 = Clock::now();
        {
            std::vector<double> scaled(N);
            for (int i = 0; i < N; ++i) scaled[i] = static_cast<double>(w[i]) * N / total;
            std::vector<int> small, large;
            for (int i = 0; i < N; ++i)
                (scaled[i] < 1.0 ? small : large).push_back(i);
            while (!small.empty() && !large.empty()) {
                const int l = small.back();
                small.pop_back();
                const int g = large.back();
                large.pop_back();
                prob[l] = scaled[l];
                alias[l] = g;
                scaled[g] = scaled[g] - (1.0 - scaled[l]);
                (scaled[g] < 1.0 ? small : large).push_back(g);
            }
            while (!large.empty()) {
                prob[large.back()] = 1.0;
                alias[large.back()] = large.back();
                large.pop_back();
            }
            while (!small.empty()) {
                prob[small.back()] = 1.0;
                alias[small.back()] = small.back();
                small.pop_back();
            }
        }
        const auto b2 = Clock::now();
        t_prefix += std::chrono::duration<double, std::micro>(b1 - b0).count();
        t_alias += std::chrono::duration<double, std::micro>(b2 - b1).count();
        sink += prefix[N - 1] + alias[0];
    }
    std::printf("  建表 %d 次的平均耗时：前缀和 %.3f 微秒，别名表 %.3f 微秒\n", build_reps,
                t_prefix / build_reps, t_alias / build_reps);
    std::printf("  别名表前 3 项：prob %.4f %.4f %.4f，alias %d %d %d\n", prob[0], prob[1],
                prob[2], alias[0], alias[1], alias[2]);

    // ---- 抽样计时 ----
    const long long samples = 10000000;
    std::mt19937 rng(20261002u);
    std::uniform_int_distribution<long long> pick(0, total - 1);
    long long sum1 = 0;
    const auto t0 = Clock::now();
    for (long long i = 0; i < samples; ++i) {
        const long long r = pick(rng);
        sum1 += static_cast<long long>(
            std::lower_bound(prefix.begin(), prefix.end(), r + 1) - prefix.begin());
    }
    const auto t1 = Clock::now();
    std::uniform_int_distribution<int> picki(0, N - 1);
    std::uniform_real_distribution<double> unit(0.0, 1.0);
    long long sum2 = 0;
    const auto t2 = Clock::now();
    for (long long i = 0; i < samples; ++i) {
        const int c = picki(rng);
        sum2 += (unit(rng) < prob[c]) ? c : alias[c];
    }
    const auto t3 = Clock::now();
    const double t_pick1 = std::chrono::duration<double, std::milli>(t1 - t0).count();
    const double t_pick2 = std::chrono::duration<double, std::milli>(t3 - t2).count();
    std::printf("  抽 %lld 次：前缀和 + 二分 %.3f ms，别名法 %.3f ms\n", samples, t_pick1, t_pick2);
    std::printf("  每次抽样的平均耗时：%.1f ns 与 %.1f ns\n", t_pick1 * 1e6 / samples,
                t_pick2 * 1e6 / samples);

    // ---- 分布核对：两种方法各抽一百万次，看每个元素被抽中的次数 ----
    const long long check = 1000000;
    std::vector<long long> c1(N, 0), c2(N, 0);
    std::mt19937 rng2(20261002u), rng3(20261002u);
    std::uniform_int_distribution<long long> pick2(0, total - 1);
    std::uniform_int_distribution<int> picki2(0, N - 1);
    std::uniform_real_distribution<double> unit2(0.0, 1.0);
    for (long long i = 0; i < check; ++i) {
        const long long r = pick2(rng2);
        ++c1[std::lower_bound(prefix.begin(), prefix.end(), r + 1) - prefix.begin()];
        const int c = picki2(rng3);
        ++c2[(unit2(rng3) < prob[c]) ? c : alias[c]];
    }
    double chi1 = 0, chi2 = 0;
    for (int i = 0; i < N; ++i) {
        const double e = static_cast<double>(check) * w[i] / total;
        chi1 += (c1[i] - e) * (c1[i] - e) / e;
        chi2 += (c2[i] - e) * (c2[i] - e) / e;
    }
    std::printf("== 各抽 %lld 次核对分布 ==\n", check);
    std::printf("  权重 1 的元素被抽中：前缀和 %lld 次，别名法 %lld 次（理论 %.1f 次）\n", c1[0],
                c2[0], static_cast<double>(check) / total);
    std::printf("  权重 %d 的元素被抽中：前缀和 %lld 次，别名法 %lld 次（理论 %.0f 次）\n", N,
                c1[N - 1], c2[N - 1], static_cast<double>(check) * N / total);
    std::printf("  卡方：前缀和 %.1f，别名法 %.1f（自由度 %d）\n", chi1, chi2, N - 1);
    asm volatile("" : : "r"(&sum1), "r"(&sum2), "r"(&sink) : "memory");
    return 0;
}
```

建表那一行是把两张表各建一千次取的平均——单次建表贴着时钟分辨率，
测出来的 0.000 毫秒不能当数据用，这一点在附录 A 里再说明一次。

## 5.3 回本点

两组数字放在一起，回本点可以算出来：

| 量 | 前缀和 + 二分 | 别名法 |
|---|---|---|
| 建表 | 0.204 微秒 | 5.272 微秒 |
| 每次抽 | 37.2 纳秒 | 10.6 纳秒 |
| 每次抽省下 | — | 26.6 纳秒 |

别名法建表多花 `5.272 − 0.204 = 5.068` 微秒，每次抽省 26.6 纳秒，
两者相除得到**约 190 次**。抽不到两百次，别名法还没回本；抽几十亿次，它省下的时间是几个数量级。

> [!TIP]
> **判据只有一句：把建表的差价除以每次省下的时间，看抽的次数够不够。**
> 这与《09-高阶数据结构/A-11-区间查询：前缀和、差分与稀疏表.md》里前缀和的回本点出自同一条取舍：
> 预先算好一部分结果，只在反复使用时才划算。

分布核对那一行也值得看：权重 1 的元素理论上是 2 次，两种方法各抽到 3 次与 0 次。
**期望只有 2 的时候，抽到 0 或 3 都是正常的**——这不是偏差，
而是「次数太少时计数本身波动大」。判偏差要看卡方（1073.3 与 1038.6，
都落在自由度 999 附近），不能看单个格子。

# 第 6 节 固定种子与可复现

## 6.1 把种子变成一条纪律

12.1 的实测已经说明：同一个种子、同一个引擎，两次跑出逐位相同的序列。
把这条性质用起来，就是四条纪律：

| 纪律 | 做法 | 为什么 |
|---|---|---|
| **种子从外面进来** | 命令行参数、配置文件、环境变量 | 出问题时能拿同一个种子重跑一次 |
| **种子写进日志** | 每次运行把种子打印或记下来 | 事后复现要的正是这个数 |
| **引擎与分布分开** | 引擎作为参数传进函数，不要在函数里构造 | 同一段逻辑换个引擎就能对照 |
| **随机与业务分开** | 抽样逻辑接受一个「取值函数」 | 测试时换成固定序列，结果可预期 |

第一条最容易被跳过。用 `std::random_device` 做种子的程序，
每次运行都不同，出问题时**没有任何办法重放**——
而随机相关的问题几乎都是「偶尔出现一次」的那种。

## 6.2 复现的边界在哪

「同一个种子跑出同一串数」这句话有两个前提，缺一不可：

| 前提 | 是否成立 |
|---|---|
| 引擎的输出被标准写死 | **成立**，见 12.1.3 的原文与实测 |
| 分布怎么用引擎也被标准写死 | **不成立** |

第二行是复现的边界。`uniform_int_distribution` 只被要求「输出满足那个概率函数」，
具体用几次引擎、怎么拒绝采样，由实现自己定。
`std::shuffle` 同理：标准要求每种排列等概率、恰好交换 `n − 1` 次，
但**哪一次交换用哪个随机数**没有写死。

`待确认`

| 问题 | 现状 |
|---|---|
| 同一份用 `uniform_int_distribution` 的程序，换一个标准库实现，输出序列是否相同 | 没有验证。标准没有要求相同，本机只有一套标准库，无法对照 |
| `std::shuffle` 的排列换一个实现是否相同 | 同上 |

> [!WARNING]
> **跨编译器复现随机序列，不能只固定种子。**
> 要跨实现复现，只能绕开标准库的分布与 `shuffle`：
> 自己写「用引擎的原始输出算下标」的那几行，或者直接用引擎输出取模
> （值域足够大时偏差可以忽略，见 12.2.2 的第三组）。
> 只在同一台机器、同一套工具链上复现时，固定种子就够了。

## 6.3 一处实测里的旁证

12.1 的输出里还有一行容易被跳过：`std::seed_seq{1,2,3,4}` 两次的结果相同。
`seed_seq` 是把若干个整数「混」成一个种子序列的工具，
标准同样写死了它的算法，因此它也可以用来复现。

同一次运行里，`random_device` 两次不同、`mt19937` 同种子两次相同、
`shuffle` 同种子两次相同、默认构造的 `mt19937` 第一万次是 4123659995——
这四行放在一起，正好是这一章的收口：
**程序里的随机是确定的，能复现；不能复现的是种子的来源，而不是随机数本身。**

# 术语表

| 术语 | 含义 |
|---|---|
| **伪随机** | 由确定的状态机按种子生成、看上去没有规律的序列 |
| **种子** | 随机数引擎的初始状态，决定整条序列 |
| **周期** | 序列多久重复一次；`mt19937` 的周期是 `2^19937 − 1` |
| **均匀分布** | 每个结果出现的概率相同 |
| **取模偏差** | 值域长度不是 n 的整数倍时，取模得到的结果不均匀 |
| **拒绝采样** | 落在不均匀的尾部时重新抽一次，用它换掉偏差 |
| **Fisher–Yates** | 从后往前、第 i 位与 `[0, i]` 里随机一位交换的洗牌法 |
| **蓄水池抽样** | 总数未知时，在流上等概率留下 k 个的算法 |
| **别名法** | 把权重表削平成两张表，使每次加权抽样的代价与元素个数无关 |
| **回本点** | 建表的成本被后续操作省下的时间追平所需的次数 |

计时量的三条口径：

| 量 | 口径 | 被优化掉的风险 |
|---|---|---|
| `alias_method` 的建表耗时 | 各建一千次取平均；单次建表在时钟分辨率附近，因此不进数据块 | 建表结果写进了 `sink`，不会被删 |
| `alias_method` 的抽样耗时 | 各抽一千万次，总工作量固定 | 抽到的下标累加进 `sum1`／`sum2`，最后用内联汇编屏障挡住删除 |
| `mod_bias` 的卡方 | **结构量**，同一个种子下逐位相同 | 不涉及计时 |

`shuffle_check` 与 `reservoir_check` 的卡方同样是结构量：
种子固定、抽样次数固定，重跑必须给出同一个数。
计时量只看比值，不看绝对值——同一份程序换一台机器，绝对值会变，
「别名法比二分快三倍」这个结论不会变。
