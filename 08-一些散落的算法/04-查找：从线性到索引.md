同步工具启动时要回答的第一个问题是「这个文件在不在清单里」。清单有十万条，
要问两千次；把它当成一个查找问题，数据怎么摆有三种常见答案：
一条一条比过去、排好序做二分、建一张哈希表。
第三种看上去最先进，代价却排在另一头：建表的开销比前两种都大，
十万条点查快不了多少，而「列出这一段区间里的全部文件」这件事它根本做不了。

选择不是靠印象做的。规模小的时候，从头扫过去比二分更快，因为每一步都踩在连续的内存上；
规模大起来之后，二分每问一次只需二十次比较；而哈希表在键集大于缓存时也会开始变慢，
它的优势要用「只做点查、不需要顺序、不在乎内存」三个条件去换。
这三笔账都有确定的算法，也都有各自的前提；一份真实项目里的
文件比对代码把六处选择摆在一起，算清这三笔账，那六处选择各自在换什么也就清楚了。

# 第 4.1 节 线性什么时候就是最优解

## 4.1.1 一个真实的问题

增量同步的做法如下：服务器保存一份文件清单，客户端每次启动时把本地目录扫一遍，
对每个本地文件问一句「服务器清单里有它吗」，有就比时间戳，没有就上传。
清单十万条，一次启动问两千次。

这份需求没有说「要按名字排序输出」，也没有说「要取出第几名」，
它只要求回答一个是非问题。是非问题是最容易满足的：排好序做二分、建一张哈希表、
或者什么都不做直接从头找，三种都能回答。差别只在代价。

代价有两个来源，而且方向相反。**比较的次数**随做法变化：
逐条比对平均要看一半的元素，排好序之后每问一次只要二十次比较。
**每一次比较的开销**也随做法变化：连续内存里的一次比较几乎不花钱，
顺着指针跳到另一个节点上去比较，代价可能是前者的十倍。
判断该用哪一种，就是判断这两项里哪一项占主导。

## 4.1.2 三种摆法在十种规模上的代价

下面这份程序把三种摆法放在同一批数据上：同一组键、同一批问题、同一个随机种子。
每一种摆法的查询次数按它自己每一步的代价反比设置，让总工作量大致固定——
否则小规模那一头会贴着时钟分辨率，测出来的数字没有意义。

`C++`

```cpp
/* find_threshold.cpp    编译：g++ -std=c++17 -O2 find_threshold.cpp -o find_threshold
 * 对照构建：g++ -std=c++17 -O0 find_threshold.cpp -o find_threshold_O0
 * 同一个「某数在不在」的需求，三种摆法在十种规模上的查询代价。
 * 轮数按规模反比设置：规模越大问的次数越少，让每种摆法的总工作量大致固定，
 * 否则小规模那一头会贴着时钟分辨率、大规模那一头要跑很久。 */
#include <algorithm>
#include <chrono>
#include <cstdint>
#include <cstdio>
#include <random>
#include <unordered_map>
#include <vector>

static std::uint64_t g_sink = 0;   // 结果落到这里，防止优化器把整段查询删掉

template <class F>
static double time_ms(F&& f) {
    const auto t0 = std::chrono::steady_clock::now();
    f();
    const auto t1 = std::chrono::steady_clock::now();
    return std::chrono::duration<double, std::milli>(t1 - t0).count();
}

// 线性扫描：带比较计数，返回下标，找不到返回 n
static long long linear_scan(const int* a, int n, int key, long long& cmp) {
    for (int i = 0; i < n; ++i) {
        ++cmp;
        if (a[i] == key) return i;
    }
    return n;
}

// 二分：带比较计数，返回下标，找不到返回 -1
static long long binary_probe(const int* a, int n, int key, long long& cmp) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        const int mid = lo + (hi - lo) / 2;
        ++cmp;
        if (a[mid] == key) return mid;
        if (a[mid] < key) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}

int main() {
    const int sizes[] = {4, 8, 16, 32, 64, 128, 256, 1024, 65536, 1048576};
    const long long work = 4000000;      // 每种摆法每档的目标「基本操作」数
    std::mt19937 rng(20261003);
    int bits = 0;

    std::printf("%9s %9s %11s %11s %11s %11s %11s\n",
                "n", "每查询比较", "每查询比较", "线性", "二分", "哈希", "命中计数");
    std::printf("%9s %11s %11s %11s %11s %11s %11s\n",
                "", "（线性）", "（二分）", "ns/查询", "ns/查询", "ns/查询", "");

    for (int n : sizes) {
        std::vector<int> keys(n);
        for (int i = 0; i < n; ++i) keys[i] = i * 2;      // 递增，天然有序
        std::vector<int> unsorted = keys;
        std::shuffle(unsorted.begin(), unsorted.end(), rng);

        std::unordered_map<int, int> umap;
        umap.reserve(static_cast<std::size_t>(n) * 2);
        for (int k : keys) umap[k] = k;

        bits = 1;
        while ((1 << bits) < n) ++bits;                   // 二分最多比较 bits 次

        // 三种摆法问的是同一批问题；次数按各自每一步的代价反比设置
        const long long q_lin = std::min<long long>(1000000, std::max<long long>(200, work / n));
        const long long q_bin = std::min<long long>(2000000, std::max<long long>(2000, work / bits));
        const long long q_hash = 2000000;

        std::vector<int> qs(std::max(q_lin, std::max(q_bin, q_hash)));
        for (int& q : qs) q = static_cast<int>(rng() % (static_cast<unsigned>(n) * 2));

        long long cmp_lin = 0, cmp_bin = 0;
        const double t_lin = time_ms([&] {
            long long hits = 0;
            for (long long i = 0; i < q_lin; ++i)
                hits += linear_scan(unsorted.data(), n, qs[static_cast<std::size_t>(i)], cmp_lin) != n;
            g_sink += static_cast<std::uint64_t>(hits);
        });
        const double t_bin = time_ms([&] {
            long long hits = 0;
            for (long long i = 0; i < q_bin; ++i)
                hits += binary_probe(keys.data(), n, qs[static_cast<std::size_t>(i)], cmp_bin) >= 0;
            g_sink += static_cast<std::uint64_t>(hits);
        });
        const double t_hash = time_ms([&] {
            long long hits = 0;
            for (long long i = 0; i < q_hash; ++i)
                hits += umap.find(qs[static_cast<std::size_t>(i)]) != umap.end();
            g_sink += static_cast<std::uint64_t>(hits);
        });

        std::printf("%9d %11.2f %11.2f %11.3f %11.3f %11.3f %11lld\n",
                    n,
                    static_cast<double>(cmp_lin) / static_cast<double>(q_lin),
                    static_cast<double>(cmp_bin) / static_cast<double>(q_bin),
                    t_lin * 1e6 / static_cast<double>(q_lin),
                    t_bin * 1e6 / static_cast<double>(q_bin),
                    t_hash * 1e6 / static_cast<double>(q_hash),
                    static_cast<long long>(g_sink));
    }
    std::printf("查询总数（三种摆法各自）：线性 %lld 到 %lld，二分 %lld 到 %lld，哈希每档 %lld\n",
                std::min<long long>(1000000, std::max<long long>(200, work / 1048576)),
                std::min<long long>(1000000, std::max<long long>(200, work / 4)),
                std::min<long long>(2000000, std::max<long long>(2000, work / 21)),
                std::min<long long>(2000000, std::max<long long>(2000, work / 2)),
                2000000LL);
    return 0;
}
```

表的最后一行给了另一种读法：三种摆法的**查询次数本来就不一样**。
线性那一列规模越小，问得越多，从 n=4 的一百万次一直降到 n=1048576 的 200 次；
二分那一列从两百万次降到 190476 次；哈希每档都是两百万次。
次数按各自每一步的代价反比设置，目的是让每一格的总工作量大致固定。

表里前两列是**结构量**：每一次查询的比较次数，重跑逐位相同。
线性那一列在 n=4 时是 3.25，n 翻一倍它就翻一倍，到一百万时是 82 万次；
二分那一列从 2.25 涨到 19.50，**规模涨了二十六万倍，比较次数只涨了不到九倍**。

后三列是**计时量**，单位是纳秒每次查询，每次重跑都会浮动。
把线性与二分两列摆在一起看，交叉点落在 64 到 128 之间：
n=64 时线性 18.048 ns、二分 22.775 ns，线性还赢着；
n=128 时线性 26.048 ns、二分 25.953 ns，两者已经打平。

## 4.1.3 交叉点的位置由什么决定

线性扫描在 n=4 时每次查询只比较 3.25 次，比二分的 2.25 次多不了多少，
而且这四次比较全部落在同一块缓存行里；二分的头几次比较会跳到数组的中间、
四分之一处、八分之一处，每一跳都可能是一次缓存缺失。
**比较次数少不等于快，还要看每一次比较要等多久。**

> [!IMPORTANT]
> **查找的代价是「比较次数 × 每次比较的代价」。**
> 线性扫描用次数换常数：次数多，但每一步都便宜。
> 二分用常数换次数：次数少，但每一步都可能跳出缓存。
> 哈希表把次数压到接近一次，代价是另建一张表、多占约十倍内存，并且丢掉顺序。

`待确认`

交叉点的**具体数值**随机器而变：CPU 的缓存大小、内存延迟、编译器生成的代码都会影响它。
上表给出的 64 到 128 是本机（Windows 11，g++ 16.2.0，`-O2`）这一次的结果。
**可以确定的是交叉点存在，且落在几十到几百这个量级**；
换机器请以自己重跑的结果为准。

优化等级也会挪动它。同一份程序按首行注释里的第二条命令用 `-O0` 再编一次，
**比较次数那两列逐位相同**——优化器没有把带计数的循环删掉，因为它每次都要更新计数器；
变小的是计时那一列，交叉点也从 64 到 128 这一段前移到 32 附近。

# 第 4.2 节 二分与边界三写法

## 4.2.1 前提是有序，而有序是一种承诺

二分要求区间有序。标准对「有序」的定义不是「看着像排好了」，而是一条可检验的条件：

`文档`

> "A sequence is sorted with respect to a comparator comp if for every iterator i
> pointing to the sequence and every non-negative integer n such that i + n is a valid
> iterator pointing to an element of the sequence, comp(*(i + n), *i) == false."
>
> —— N4659 §28.7/5

`lower_bound` 这类函数对区间提的要求更具体：区间必须**关于某个式子分区**
（partitioned），也就是满足条件的元素全在前、不满足的全在后。

`文档`

> "Requires: The elements e of [first, last) shall be partitioned with respect to the
> expression e < value or comp(e, value)."
>
> —— N4659 §28.7.3.1/1

两条引文合起来说明一件事：**二分不检查数据是否有序，它把这个条件交给调用者保证。**
把没排序的数组交给二分，得到的是「随便一个答案」——
程序不会崩，也不会报错，只会给错的结果。这是二分最难查的一类问题。

## 4.2.2 三种写法，差别只在「区间怎么表示」

二分的骨架只有五行，三种写法却都常见。它们的区别不在算法，而在**区间的两端各指向什么**：
闭区间把两个端点都算在区间里，半开区间把右端点排除在外，
`lower_bound` 语义则完全不判相等，只求「第一个不小于键的位置」。

`C++`

```cpp
/* binary_bounds.cpp    编译：g++ -std=c++17 -O2 binary_bounds.cpp -o binary_bounds
 * 二分查找的三种边界写法，与标准库的 lower_bound / upper_bound / binary_search 并排对照。
 * 用例覆盖空区间、单元素、重复键、键落在区间外这几种边界。 */
#include <algorithm>
#include <cstdio>
#include <vector>

/* 写法一：闭区间 [lo, hi]，hi 指向最后一个元素 */
static int find_closed(const int* a, int n, int key, long long& cmp) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {                       // 区间非空就继续
        const int mid = lo + (hi - lo) / 2;  // 不写 (lo + hi) / 2，避免加法溢出
        ++cmp;
        if (a[mid] == key) return mid;
        if (a[mid] < key) lo = mid + 1;      // 答案在右半边
        else hi = mid - 1;                   // 答案在左半边
    }
    return -1;
}

/* 写法二：半开区间 [lo, hi)，hi 指向最后一个元素之后 */
static int find_half_open(const int* a, int n, int key, long long& cmp) {
    int lo = 0, hi = n;
    while (lo < hi) {
        const int mid = lo + (hi - lo) / 2;
        ++cmp;
        if (a[mid] < key) lo = mid + 1;
        else hi = mid;
    }
    return (lo < n && a[lo] == key) ? lo : -1;   // 循环里不判相等，收尾再判一次
}

/* 写法三：只求下界，等价于 std::lower_bound 的返回值下标 */
static int lower_bound_manual(const int* a, int n, int key, long long& cmp) {
    int lo = 0, hi = n;
    while (lo < hi) {
        const int mid = lo + (hi - lo) / 2;
        ++cmp;
        if (a[mid] < key) lo = mid + 1;
        else hi = mid;
    }
    return lo;                                   // 第一个不小于 key 的位置，可能等于 n
}

static long long g_cmp[3] = {0, 0, 0};

static void run_case(const char* name, const std::vector<int>& a, int key) {
    const int n = static_cast<int>(a.size());
    const int* p = a.empty() ? nullptr : a.data();
    long long c0 = 0, c1 = 0, c2 = 0;
    const int r0 = find_closed(p, n, key, c0);
    const int r1 = find_half_open(p, n, key, c1);
    const int r2 = lower_bound_manual(p, n, key, c2);
    g_cmp[0] += c0;
    g_cmp[1] += c1;
    g_cmp[2] += c2;

    const auto lb = std::lower_bound(a.begin(), a.end(), key);
    const auto ub = std::upper_bound(a.begin(), a.end(), key);
    std::printf("%-22s %6d %6d %6d %8d %8d %10s\n",
                name, r0, r1, r2,
                static_cast<int>(lb - a.begin()), static_cast<int>(ub - a.begin()),
                std::binary_search(a.begin(), a.end(), key) ? "true" : "false");
}

int main() {
    std::printf("%-22s %6s %6s %6s %8s %8s %10s\n",
                "用例", "闭区间", "半开", "下界", "std下界", "std上界", "binary_search");
    std::printf("%-22s %6s %6s %6s %8s %8s %10s\n",
                "", "下标", "下标", "下标", "下标", "下标", "布尔");
    run_case("空区间，键 5", {}, 5);
    run_case("单元素 {5}，键 5", {5}, 5);
    run_case("单元素 {5}，键 4", {5}, 4);
    run_case("单元素 {5}，键 6", {5}, 6);
    run_case("{1,3,3,3,5,7}，键 0", {1, 3, 3, 3, 5, 7}, 0);
    run_case("{1,3,3,3,5,7}，键 3", {1, 3, 3, 3, 5, 7}, 3);
    run_case("{1,3,3,3,5,7}，键 4", {1, 3, 3, 3, 5, 7}, 4);
    run_case("{1,3,3,3,5,7}，键 7", {1, 3, 3, 3, 5, 7}, 7);
    run_case("{1,3,3,3,5,7}，键 8", {1, 3, 3, 3, 5, 7}, 8);
    std::printf("三种写法的比较次数合计：闭区间 %lld、半开 %lld、下界 %lld\n",
                g_cmp[0], g_cmp[1], g_cmp[2]);

    /* 中点算式：不是真的建四十亿个元素的数组，而是直接把两个下标交给两种算法。
     * 无符号的溢出是回绕（有符号则是未定义行为），因此这里用无符号演示。 */
    const unsigned lo = 2000000000u, hi = 4000000000u;
    std::printf("中点：lo=%u hi=%u\n", lo, hi);
    std::printf("(lo + hi) / 2      = %u\n", (lo + hi) / 2);
    std::printf("lo + (hi - lo) / 2 = %u\n", lo + (hi - lo) / 2);
    return 0;
}
```

## 4.2.3 差一错误与中点溢出

三处是差一错误的常发地，改错任何一处都会让循环不结束或漏掉端点：

| 位置 | 闭区间 | 半开区间 | 出错的表现 |
|---|---|---|---|
| 初值 | `hi = n - 1` | `hi = n` | 半开写成 `n - 1` 会漏掉最后一个元素 |
| 循环条件 | `lo <= hi` | `lo < hi` | 闭区间写成 `<` 会漏掉只剩一个元素的区间 |
| 缩左边界 | `hi = mid - 1` | `hi = mid` | 半开写成 `mid - 1`，`mid` 为 0 时 `hi` 变成负数 |
| 缩右边界 | `lo = mid + 1` | `lo = mid + 1` | 写成 `lo = mid` 会死循环 |

> [!WARNING]
> **半开区间里写 `hi = mid - 1` 是最危险的一处。**
> `hi` 是无符号类型时，`mid` 为 0 会让 `hi` 回绕成极大值，循环把整块内存都读一遍；
> 有符号时得到负数，`lo < hi` 立刻为假，结果是漏答案而不是崩。
> 判断办法只有一条：**「`hi` 指向元素还是指向元素之后」从头到尾不许改口。**

另一处不在边界上，在中点算式里。

`C++`

```cpp
// （下面是节选）中点的两种算法，取自上面的 binary_bounds.cpp
const unsigned lo = 2000000000u, hi = 4000000000u;
std::printf("(lo + hi) / 2      = %u\n", (lo + hi) / 2);
std::printf("lo + (hi - lo) / 2 = %u\n", lo + (hi - lo) / 2);
```

`(lo + hi)` 在 32 位无符号里回绕成 1705032704，除以 2 得到 852516352，
**比真实的 3000000000 小得多**；`lo + (hi - lo) / 2` 则是对的。

> [!CAUTION]
> **`(lo + hi) / 2` 在元素个数超过 `INT_MAX` 时是有符号溢出，属于未定义行为。**
> 未定义行为不只是「算出个错的数」：`-O2` 下编译器可以假设它不会发生，
> 把整个循环改写成你想要之外的样子。写成 `lo + (hi - lo) / 2` 没有额外代价，
> 现代编译器会把它优化成一条移位加一条加法。

> [!NOTE]
> 二分这一节收成三句话：
> **它的前提是区间有序，而这个前提由调用者保证，函数自己不检查；
> 它的骨架只有五行，出错的位置集中在「右端点指向元素还是元素之后」这一件事上；
> 它的比较次数是 `log2(n)` 量级，因此每查询代价几乎不随规模增长——
> 这是后面拿它跟哈希表比的基础。**

# 第 4.3 节 插值查找与跳表思想

## 4.3.1 插值查找：把「分布均匀」当成条件

查字典的时候没人从中间翻开。要找「Zhang」，手会直接落在靠后的位置。
这种做法叫插值查找：不看中点，而按**键在值域里的相对位置**猜下一次比较的位置。
这个算式只有一行：

`Text`

```text
   pos = lo + (key - a[lo]) * (hi - lo) / (a[hi] - a[lo])
```

它假设「键的分布是均匀的」：键落在值域的百分之几处，下标就在区间的百分之几处。
这个假设成立时，一次比较就能命中；不成立时，猜出来的位置会反复偏到同一侧。

`C++`

```cpp
/* interp_skip.cpp    编译：g++ -std=c++17 -O2 interp_skip.cpp -o interp_skip
 * 一、插值查找与二分查找在「均匀」与「聚集」两种键分布下的探测次数；
 * 二、跳表：有序加随机层数就能把探测次数压到与二分同级，代价落在指针跳转上。 */
#include <chrono>
#include <cstdint>
#include <cstdio>
#include <random>
#include <vector>

static std::uint64_t g_sink = 0;

template <class F>
static double time_ms(F&& f) {
    const auto t0 = std::chrono::steady_clock::now();
    f();
    const auto t1 = std::chrono::steady_clock::now();
    return std::chrono::duration<double, std::milli>(t1 - t0).count();
}

/* 二分：返回下标，找不到返回 -1；probes 记比较次数 */
static int binary_search_probe(const long long* a, int n, long long key, long long& probes) {
    int lo = 0, hi = n - 1;
    while (lo <= hi) {
        const int mid = lo + (hi - lo) / 2;
        ++probes;
        if (a[mid] == key) return mid;
        if (a[mid] < key) lo = mid + 1;
        else hi = mid - 1;
    }
    return -1;
}

/* 插值查找：按「键在值域里的相对位置」猜下一次比较的位置。
 * 两处保护是必需的：值域退化成一点时不能做除法；猜出来的位置要夹回区间。 */
static int interp_search(const long long* a, int n, long long key, long long& probes) {
    int lo = 0, hi = n - 1;
    while (lo <= hi && key >= a[lo] && key <= a[hi]) {
        ++probes;
        if (a[hi] == a[lo]) return a[lo] == key ? lo : -1;
        long long pos = lo + (key - a[lo]) * (hi - lo) / (a[hi] - a[lo]);
        if (pos < lo) pos = lo;
        if (pos > hi) pos = hi;
        if (a[pos] == key) return static_cast<int>(pos);
        if (a[pos] < key) lo = static_cast<int>(pos) + 1;
        else hi = static_cast<int>(pos) - 1;
    }
    return -1;
}

/* ---- 跳表：每个节点带一个「层数」，第 k 层是一条稀疏的有序链 ---- */
struct SkipNode {
    long long key;
    std::vector<SkipNode*> next;      // next[k] 是第 k 层的后继
};

struct SkipList {
    SkipNode* head;
    int max_level;
    std::uint32_t seed;
    std::vector<long long> level_count;

    explicit SkipList(int levels) : head(new SkipNode{0, std::vector<SkipNode*>(levels, nullptr)}),
                                    max_level(levels), seed(20261003u),
                                    level_count(static_cast<std::size_t>(levels), 0) {}

    // xorshift32：层数用固定种子生成，结构量才能逐位复现
    std::uint32_t next_rand() {
        seed ^= seed << 13;
        seed ^= seed >> 17;
        seed ^= seed << 5;
        return seed;
    }
    int random_level() {
        int lv = 1;
        while (lv < max_level && (next_rand() & 3u) == 0u) ++lv;   // 每层晋升概率 1/4
        return lv;
    }
    void insert(long long key) {
        const int lv = random_level();
        std::vector<SkipNode*> update(static_cast<std::size_t>(max_level), nullptr);
        SkipNode* cur = head;
        for (int k = max_level - 1; k >= 0; --k) {
            while (cur->next[static_cast<std::size_t>(k)] &&
                   cur->next[static_cast<std::size_t>(k)]->key < key)
                cur = cur->next[static_cast<std::size_t>(k)];
            update[static_cast<std::size_t>(k)] = cur;
        }
        SkipNode* node = new SkipNode{key, std::vector<SkipNode*>(static_cast<std::size_t>(lv), nullptr)};
        for (int k = 0; k < lv; ++k) {
            node->next[static_cast<std::size_t>(k)] = update[static_cast<std::size_t>(k)]->next[static_cast<std::size_t>(k)];
            update[static_cast<std::size_t>(k)]->next[static_cast<std::size_t>(k)] = node;
        }
        ++level_count[static_cast<std::size_t>(lv - 1)];
    }
    // 查找：probes 记「沿第 0 层走了一步」的次数，hops 记「降一层」的次数
    bool find(long long key, long long& probes, long long& hops) const {
        const SkipNode* cur = head;
        for (int k = max_level - 1; k >= 0; --k) {
            ++hops;
            while (cur->next[static_cast<std::size_t>(k)] &&
                   cur->next[static_cast<std::size_t>(k)]->key < key) {
                cur = cur->next[static_cast<std::size_t>(k)];
                ++probes;
            }
        }
        const SkipNode* p = cur->next[0];
        return p && p->key == key;
    }
};

int main() {
    const int n = 65536;
    std::mt19937 rng(20261003);
    std::vector<int> idx(n);
    for (int i = 0; i < n; ++i) idx[i] = static_cast<int>(rng() % static_cast<unsigned>(n));

    // 查询集：一半命中（取真实键），一半落空（键加一）
    std::vector<long long> qs(200000);
    for (std::size_t i = 0; i < qs.size(); ++i) {
        const long long k = static_cast<long long>(i % static_cast<std::size_t>(n)) * 64;
        qs[i] = (i % 2 == 0) ? k : k + 1;
    }

    // 一、两种分布下的探测次数
    std::vector<long long> uniform(n), clustered(n);
    for (int i = 0; i < n; ++i) {
        uniform[i] = static_cast<long long>(i) * 64;                  // 间隔相等
        clustered[i] = static_cast<long long>(i) * i;                 // 间隔越来越大
    }
    const char* names[2] = {"均匀（键=i*64）", "聚集（键=i*i）"};
    const std::vector<long long>* sets[2] = {&uniform, &clustered};
    for (int s = 0; s < 2; ++s) {
        const std::vector<long long>& a = *sets[s];
        std::vector<long long> local(qs.size());     // 每种分布用自己那几个键提问
        for (std::size_t i = 0; i < local.size(); ++i) {
            const long long k = a[i % static_cast<std::size_t>(n)];
            local[i] = (i % 2 == 0) ? k : k + 1;
        }
        long long pb = 0, pi = 0, hitb = 0, hiti = 0;
        for (std::size_t i = 0; i < local.size(); ++i) {
            hitb += binary_search_probe(a.data(), n, local[i], pb) >= 0;
            hiti += interp_search(a.data(), n, local[i], pi) >= 0;
        }
        g_sink += static_cast<std::uint64_t>(hitb + hiti);
        std::printf("%-18s 二分 %8.2f 次/查询   插值 %8.2f 次/查询   命中 %lld / %lld\n",
                    names[s],
                    static_cast<double>(pb) / static_cast<double>(qs.size()),
                    static_cast<double>(pi) / static_cast<double>(qs.size()),
                    hitb, hiti);
    }

    // 二、跳表与二分：探测次数与耗时
    SkipList sl(17);
    for (int i = 0; i < n; ++i) sl.insert(static_cast<long long>(i) * 2);
    std::printf("跳表层数分布（第 1 层起）：");
    for (std::size_t k = 0; k < sl.level_count.size(); ++k) {
        if (sl.level_count[k] == 0) break;
        std::printf(" %lld", sl.level_count[k]);
    }
    std::printf("\n");

    std::vector<long long> sorted_keys(n);
    for (int i = 0; i < n; ++i) sorted_keys[i] = static_cast<long long>(i) * 2;
    std::vector<long long> qs2(200000);
    for (std::size_t i = 0; i < qs2.size(); ++i) {
        const long long k = static_cast<long long>(i % static_cast<std::size_t>(n)) * 2;
        qs2[i] = (i % 2 == 0) ? k : k + 1;
    }

    long long probes = 0, hops = 0, hits = 0, bprobes = 0, bhits = 0;
    const double t_skip = time_ms([&] {
        for (std::size_t i = 0; i < qs2.size(); ++i) {
            hits += sl.find(qs2[i], probes, hops);
            g_sink += static_cast<std::uint64_t>(probes & 1u);
        }
    });
    const double t_bin = time_ms([&] {
        for (std::size_t i = 0; i < qs2.size(); ++i) {
            bhits += binary_search_probe(sorted_keys.data(), n, qs2[i], bprobes) >= 0;
            g_sink += static_cast<std::uint64_t>(bprobes & 1u);
        }
    });
    std::printf("跳表：沿链走 %lld 步、降层 %lld 次（共 %zu 次查询），命中 %lld\n",
                probes, hops, qs2.size(), hits);
    std::printf("二分：比较 %lld 次（共 %zu 次查询），命中 %lld\n", bprobes, qs2.size(), bhits);
    std::printf("每查询耗时：跳表 %.1f ns，有序数组二分 %.1f ns\n",
                t_skip * 1e6 / static_cast<double>(qs2.size()),
                t_bin * 1e6 / static_cast<double>(qs2.size()));
    return 0;
}
```

`实测数据`
`Text`

```text
均匀（键=i*64） 二分    16.00 次/查询   插值     1.00 次/查询   命中 100000 / 100000
聚集（键=i*i） 二分    16.00 次/查询   插值    22.46 次/查询   命中 100000 / 100000
```

同一份代码、同一批问题，只换了键的分布：
**均匀分布下插值一次命中，聚集分布下反而比二分多出六次多探测**。
`i*i` 这种分布的前四分之一挤在很小的值域里，后四分之一却拉得很开，
按比例猜位置永远猜不准。所以插值查找不是「更好的二分」，
它是**用分布假设换探测次数**：假设成立时省下探测次数，不成立时反而更贵，而数据的分布不受程序控制。

两处保护在代码里必须写出来：值域缩成一点（`a[hi] == a[lo]`）时不能做除法，
以及猜出来的位置要夹回 `[lo, hi]`——键不在数组里时，算式会算出越界的位置。

## 4.3.2 跳表：有序之外的第二个条件

跳表回答了另一个问题：不用连续内存，能不能也把探测次数压到 `log` 级。
做法是给每个节点随机定一个层数，第 k 层是一条跳过更多节点的稀疏链，
查找时从最高层往下走，走到不能再走就降一层。

`实测数据`
`Text`

```text
跳表层数分布（第 1 层起）： 49143 12330 3062 752 190 45 11 1 2
跳表：沿链走 4383825 步、降层 3400000 次（共 200000 次查询），命中 100000
二分：比较 3200003 次（共 200000 次查询），命中 100000
每查询耗时：跳表 84.3 ns，有序数组二分 30.7 ns
```

65536 个键、每层晋升概率四分之一，得到的层数分布是
`49143、12330、3062、752、190、45、11、1、2`——每往上一层就剩下约四分之一，
最高一层只有两个节点，这正是它能「一层跳一大段」的原因。

探测次数与二分在同一量级：**二分比较 3200003 次，跳表沿链走 4383825 步**（再加每查询十七次降层）。
差距落在耗时上：跳表 84.3 ns，二分 30.7 ns，慢了约 1.7 倍。
差别不在次数，在**每一次访问落在哪里**：二分在连续数组里跳，跳表顺着指针跳，
每次指针跳转都可能是一次缓存缺失。

> [!IMPORTANT]
> **有序只是二分的一半条件，另一半是「能按下标一步跳到中间」。**
> 换掉连续存储，`O(log n)` 的探测次数还能用随机层数换来，
> 但每一步的代价从「一块缓存行里的比较」变成「一次指针追下去」，
> 这笔账要单独算。跳表的完整结构在《09-高阶数据结构》里讲，这里只取它的思想。

## 4.3.3 四种做法的前提

| 做法 | 额外条件 | 探测次数 | 每一步的代价 |
|---|---|---|---|
| 线性扫描 | 无 | `O(n)` | 最低，连续内存 |
| 二分 | 有序，且能随机访问 | `O(log n)` | 低，连续内存 |
| 插值查找 | 有序、随机访问，**且键近似均匀分布** | 均匀时 `O(log log n)`，聚集时退化 | 低 |
| 跳表 | 有序，**且肯多花一倍的指针** | 期望 `O(log n)` | 高，每次是一跳 |

表里「额外条件」那一列是本节的要点：四种做法都不是无条件可用的。
拿不到条件就用不出效果，甚至会写出错误的程序——
把无序数组交给二分，把聚集分布交给插值，都属于这一类。

# 第 4.4 节 什么时候二分比哈希更合适

## 4.4.1 六项并排对照

哈希表在直觉上总是更快：一次哈希加一次比较，跟 `log n` 没有关系。
下面这份程序把两种做法放在同一批数据上——一百万个键、二十万次点查、一百次范围查询，
再看建表开销、内存占用、遍历顺序和最坏情况。

`C++`

```cpp
/* hash_vs_binary.cpp    编译：g++ -std=c++17 -O2 hash_vs_binary.cpp -o hash_vs_binary
 * 同一批数据的哈希表与有序数组：建表、点查、范围查、占用字节、遍历顺序、最坏情况。
 * 六项都由程序真跑出来，其中比较次数与字节数是结构量，重跑逐位相同。 */
#include <algorithm>
#include <chrono>
#include <cstdint>
#include <cstdio>
#include <functional>
#include <new>
#include <random>
#include <unordered_map>
#include <vector>

static std::uint64_t g_sink = 0;

template <class F>
static double time_ms(F&& f) {
    const auto t0 = std::chrono::steady_clock::now();
    f();
    const auto t1 = std::chrono::steady_clock::now();
    return std::chrono::duration<double, std::milli>(t1 - t0).count();
}

/* 计数分配器：unordered_map 向堆要的每一个字节都记下来（节点加桶数组） */
static long long g_heap_bytes = 0;
template <class T>
struct CountAlloc {
    using value_type = T;
    CountAlloc() = default;
    template <class U>
    CountAlloc(const CountAlloc<U>&) {}
    T* allocate(std::size_t n) {
        g_heap_bytes += static_cast<long long>(n * sizeof(T));
        return static_cast<T*>(::operator new(n * sizeof(T)));
    }
    void deallocate(T* p, std::size_t) { ::operator delete(p); }
    template <class U>
    bool operator==(const CountAlloc<U>&) const { return true; }
    template <class U>
    bool operator!=(const CountAlloc<U>&) const { return false; }
};

/* 会数相等比较次数的键：用来把「平均 O(1)」与「最坏 O(n)」变成两个整数 */
struct Key {
    int v;
    static long long eqs;
};
long long Key::eqs = 0;
bool operator==(const Key& a, const Key& b) {
    ++Key::eqs;
    return a.v == b.v;
}
struct BadHash {                    // 恶意哈希：全部键落进同一个桶
    std::size_t operator()(const Key&) const { return 0; }
};
struct GoodHash {
    std::size_t operator()(const Key& k) const { return std::hash<int>()(k.v); }
};

int main() {
    const int n = 1000000;
    const int q = 200000;           // 点查次数
    std::mt19937 rng(20261003);

    std::vector<int> keys(n);
    for (int i = 0; i < n; ++i) keys[i] = i * 2;
    std::vector<int> queries(q);
    for (int& x : queries) x = static_cast<int>(rng() % (static_cast<unsigned>(n) * 2));

    // 一、建起来要多久
    std::vector<int> sorted = keys;
    const double t_sort = time_ms([&] { std::sort(sorted.begin(), sorted.end()); });
    std::unordered_map<int, int> umap;
    const double t_build = time_ms([&] {
        umap.reserve(static_cast<std::size_t>(n) * 2);
        for (int k : keys) umap.emplace(k, k);
    });
    std::printf("建立索引：排序 %8.3f ms；哈希表（先 reserve）%8.3f ms\n", t_sort, t_build);

    // 二、点查：同一批问题
    long long hits1 = 0, hits2 = 0;
    const double t_bin = time_ms([&] {
        for (int x : queries) hits1 += std::binary_search(sorted.begin(), sorted.end(), x);
        g_sink += static_cast<std::uint64_t>(hits1);
    });
    const double t_hash = time_ms([&] {
        for (int x : queries) hits2 += umap.find(x) != umap.end();
        g_sink += static_cast<std::uint64_t>(hits2);
    });
    std::printf("点查 %d 次（一半命中）：二分 %8.3f ms；哈希 %8.3f ms；命中 %lld 对 %lld\n",
                q, t_bin, t_hash, hits1, hits2);

    // 三、范围查：数出落在 [a, b) 里的键有多少个
    const int ranges = 100;
    std::vector<std::pair<int, int>> rs(ranges);
    for (auto& r : rs) {
        const int a = static_cast<int>(rng() % static_cast<unsigned>(n));
        r = {a * 2, (a + 1000) * 2};
    }
    long long cnt_bin = 0, cnt_hash = 0;
    const double t_range_bin = time_ms([&] {
        for (const auto& r : rs) {
            cnt_bin += std::lower_bound(sorted.begin(), sorted.end(), r.second) -
                       std::lower_bound(sorted.begin(), sorted.end(), r.first);
        }
        g_sink += static_cast<std::uint64_t>(cnt_bin);
    });
    const double t_range_hash = time_ms([&] {
        for (const auto& r : rs)
            for (int k : keys) cnt_hash += (k >= r.first && k < r.second);
        g_sink += static_cast<std::uint64_t>(cnt_hash);
    });
    std::printf("范围查 %d 次：二分 %8.3f ms；哈希（只能整表扫）%8.3f ms；计数 %lld 对 %lld\n",
                ranges, t_range_bin, t_range_hash, cnt_bin, cnt_hash);

    // 四、占用：有序数组是 capacity * 4 字节，哈希表用计数分配器数出来
    long long bytes_map = 0;
    {
        g_heap_bytes = 0;
        std::unordered_map<int, int, std::hash<int>, std::equal_to<int>,
                           CountAlloc<std::pair<const int, int>>> m;
        for (int k : keys) m.emplace(k, k);
        bytes_map = g_heap_bytes;
    }
    const long long bytes_vec = static_cast<long long>(sorted.capacity()) * 4;
    std::printf("占用：有序数组 %lld 字节（容量 %zu）；哈希表 %lld 字节（桶 %zu 个）；倍数 %.2f\n",
                bytes_vec, sorted.capacity(), bytes_map, umap.bucket_count(),
                static_cast<double>(bytes_map) / static_cast<double>(bytes_vec));

    // 五、遍历顺序：哈希顺序不是排序顺序；改一个键，顺序的校验和就变了
    auto order_sum = [](const std::unordered_map<int, int>& m) {
        std::uint64_t h = 1469598103934665603ull;      // FNV-1a
        for (const auto& kv : m) {
            h ^= static_cast<std::uint64_t>(static_cast<unsigned>(kv.first));
            h *= 1099511628211ull;
        }
        return h;
    };
    const std::uint64_t h1 = order_sum(umap);
    std::unordered_map<int, int> umap2 = umap;
    const std::uint64_t h2 = order_sum(umap2);
    umap2.erase(12345);
    umap2.emplace(12345, 12345);
    const std::uint64_t h3 = order_sum(umap2);
    std::printf("遍历顺序校验和：同一份内容建两次 %llu 与 %llu；删一个键再插回去 %llu\n",
                static_cast<unsigned long long>(h1), static_cast<unsigned long long>(h2),
                static_cast<unsigned long long>(h3));
    std::printf("哈希顺序前三个键：");
    int shown = 0;
    for (const auto& kv : umap) {
        std::printf(" %d", kv.first);
        if (++shown == 3) break;
    }
    std::printf("；排序后前三个键：%d %d %d\n", sorted[0], sorted[1], sorted[2]);

    // 六、最坏情况：哈希函数把全部键塞进一个桶，查找退化成沿链比较
    const int m = 20000;
    std::unordered_map<Key, int, GoodHash> good;
    std::unordered_map<Key, int, BadHash> bad;
    for (int i = 0; i < m; ++i) {
        good.emplace(Key{i}, i);
        bad.emplace(Key{i}, i);
    }
    Key::eqs = 0;
    for (int i = 0; i < m; ++i) g_sink += good.find(Key{i}) != good.end();
    const long long eq_good = Key::eqs;
    Key::eqs = 0;
    for (int i = 0; i < m; ++i) g_sink += bad.find(Key{i}) != bad.end();
    const long long eq_bad = Key::eqs;
    std::printf("相等比较次数：正常哈希查 %d 个键 %lld 次；全部撞进一个桶 %lld 次；比值 %.1f\n",
                m, eq_good, eq_bad,
                static_cast<double>(eq_bad) / static_cast<double>(eq_good));
    std::printf("结果校验和 %llu\n", static_cast<unsigned long long>(g_sink));
    return 0;
}
```

`实测数据`
`Text`

```text

点查 200000 次（一半命中）：二分   22.452 ms；哈希   15.547 ms；命中 99650 对 99650
```

第一项就与直觉相反：**建索引这件事上二分快六倍多**。
排好序只要把一百万个整数搬一遍，哈希表要为每个键分配一个节点、
算一次哈希、处理桶数组的扩容。哈希表的优势在查询那一边，不在建立那一边。

点查这一项哈希表赢了，但**只快了一点四倍**：15.547 ms 对 22.452 ms。
按「一次哈希对二十次比较」的直觉，这里本该差出一个数量级。
差的这部分来自缓存：一百万个键的表装不进缓存，一次 `find` 要先读桶、
再顺着节点指针读键，两三次随机访存；二分虽然比较二十次，但每一次都在同一块数组上。

`实测数据`
`Text`

```text

```

范围查询是两者差距最大的一项：**二分快 275 倍**。
二分只要两次 `lower_bound` 就夹出了区间；哈希表不知道键的顺序，
只能把整张表扫一遍——一百次查询扫了一亿个键。
这一项不是实现问题，是**模型问题**：哈希把顺序信息丢掉了，找不回来。

`Text`

内存是九点七倍：四百万字节对三千八百多万字节。这一行不是估计——
程序用一个计数分配器把 `unordered_map` 向堆要的每一个字节都记了下来，
**连桶数组本身也计入**（两百多万个桶、每个桶一个指针）。

顺序那一行要分两半读。同一份内容建两次，遍历顺序的校验和相同；
**删掉一个键再插回去，校验和就变了**——顺序不是内容的函数。
后半行说明它更不是排序顺序：哈希顺序的头三个键是 `1999998、1999996、1999994`，
排序后的头三个是 `0、2、4`。

`实测数据`
`Text`


最后一项是最坏情况。程序里换了一个「恶意」哈希函数，让所有键都落进同一个桶：
两万次查找的相等比较次数从 20000 涨到 200010000，**一万倍**。
这就是「平均 `O(1)`、最坏 `O(n)`」里的那个最坏情况——
它不需要攻击者，只需要一个选得不好的哈希函数，加上一批恰好都撞在一起的键。

## 4.4.2 遍历顺序不在哈希表的保证里

标准把这件事写得很直接：

`文档`

> "Thus, although the absolute order of elements in an unordered container is not
> specified, its elements are grouped into equivalent-key groups such that all elements
> of each group have equivalent keys."
>
> —— N4659 §26.2.7/6

标准只保证「等价键彼此相邻」，**不保证任何其它顺序**。
本机上两次建表顺序相同，是因为 libstdc++ 对整数用恒等哈希、对字符串用固定种子的散列，
换一套标准库、换一个哈希函数，顺序就换了。
因此凡是「输出要可比较、要能进版本库、要能给人看」的场合，
都要在输出之前排一次序，不能依赖容器的遍历顺序。

## 4.4.3 三条判据

| 判据 | 选二分（有序数组） | 选哈希表 |
|---|---|---|
| 查询里有范围、前缀、相邻、排名 | **必须** | 做不到 |
| 数据量小、建表次数多、查询次数少 | **更好**（建得快） | 建表贵 |
| 只要点查、且能接受内存翻十倍与最坏情况 | 也够用 | **更好**，但优势在缓存装不下时会缩小 |
| 需要确定性的遍历顺序 | **更好** | 顺序不可依赖 |

> [!IMPORTANT]
> **二分与哈希不是「先进」与「落后」的关系，而是两种把顺序卖掉的价钱。**
> 哈希用「顺序 + 内存 + 最坏情况」这三样换点查的常数；
> 一旦需求里出现范围、排名、稳定输出中的任何一项，这笔交易就做不成，
> 有序数组反而是唯一能满足需求的那一种。

# 第 4.5 节 `FileScanner::diff` 的六条取舍

## 4.5.1 素材与场景

本节讨论的代码来自一份真实项目的文件扫描器，素材副本在
`A-教学素材/04-语法/STL与算法/file_scanner.cpp`（326 行）。
素材的来源与许可登记在 `A-教学素材/README.md` 的素材表里：作者 HiBer2007，GPL-3.0。
下面只取其中六处选择，另写一份自包含的程序把每一条的代价各测一遍。
它的任务是比对两份元数据清单：本地扫描出来的一份，服务器记录的一份，
输出「新增、删除、修改过、没变」四类结果。

那段代码里有六处选择值得单独看：用哈希表把两两比较降成一次遍历、
用 `reserve` 省下再哈希、把比较分成强弱两级、两趟循环才能算出「新增」、
输出之前必须先排序、以及中途出错时要保留已经算出的结果。
六条都不是理论上的取舍，每一条都能在同一份程序里复现。

下面这份程序用合成元数据，逐条检验这六条取舍的代价。合成的方式是固定的：
一万条路径、每条带一 KB 内容、由固定种子生成，因此所有结构量重跑逐位相同。
内容哈希用的是真正的 SHA-256，程序开头先用两个公开测试向量证明它实现对了。

## 4.5.2 六条取舍

`C++`

```cpp
/* diff_cost.cpp    编译：g++ -std=c++17 -O2 diff_cost.cpp -o diff_cost
 * FileScanner::diff 的六条取舍，每条都由程序真跑出来：
 *   一 哈希索引把两两比较降成一次遍历；二 reserve 省下再哈希；三 两级比较的次序；
 *   四 两趟循环才能算出 added；五 遍历顺序可预测；六 中途出错时保留已有结果。 */
#include <algorithm>
#include <array>
#include <chrono>
#include <cstdint>
#include <cstdio>
#include <cstring>
#include <stdexcept>
#include <string>
#include <unordered_map>
#include <vector>

static std::uint64_t g_sink = 0;

template <class F>
static double time_ms(F&& f) {
    const auto t0 = std::chrono::steady_clock::now();
    f();
    const auto t1 = std::chrono::steady_clock::now();
    return std::chrono::duration<double, std::milli>(t1 - t0).count();
}

/* ---------------- SHA-256：内容哈希，用来做「强比较」 ---------------- */
struct Sha256 {
    std::uint32_t h[8];
    std::uint64_t total;
    unsigned char buf[64];
    std::size_t buflen;

    Sha256() { reset(); }
    void reset() {
        static const std::uint32_t iv[8] = {0x6a09e667u, 0xbb67ae85u, 0x3c6ef372u, 0xa54ff53au,
                                            0x510e527fu, 0x9b05688cu, 0x1f83d9abu, 0x5be0cd19u};
        std::memcpy(h, iv, sizeof(h));
        total = 0;
        buflen = 0;
    }
    static std::uint32_t ror(std::uint32_t x, int n) { return (x >> n) | (x << (32 - n)); }
    void block(const unsigned char* p) {
        static const std::uint32_t K[64] = {
            0x428a2f98,0x71374491,0xb5c0fbcf,0xe9b5dba5,0x3956c25b,0x59f111f1,0x923f82a4,0xab1c5ed5,
            0xd807aa98,0x12835b01,0x243185be,0x550c7dc3,0x72be5d74,0x80deb1fe,0x9bdc06a7,0xc19bf174,
            0xe49b69c1,0xefbe4786,0x0fc19dc6,0x240ca1cc,0x2de92c6f,0x4a7484aa,0x5cb0a9dc,0x76f988da,
            0x983e5152,0xa831c66d,0xb00327c8,0xbf597fc7,0xc6e00bf3,0xd5a79147,0x06ca6351,0x14292967,
            0x27b70a85,0x2e1b2138,0x4d2c6dfc,0x53380d13,0x650a7354,0x766a0abb,0x81c2c92e,0x92722c85,
            0xa2bfe8a1,0xa81a664b,0xc24b8b70,0xc76c51a3,0xd192e819,0xd6990624,0xf40e3585,0x106aa070,
            0x19a4c116,0x1e376c08,0x2748774c,0x34b0bcb5,0x391c0cb3,0x4ed8aa4a,0x5b9cca4f,0x682e6ff3,
            0x748f82ee,0x78a5636f,0x84c87814,0x8cc70208,0x90befffa,0xa4506ceb,0xbef9a3f7,0xc67178f2};
        std::uint32_t w[64];
        for (int i = 0; i < 16; ++i)
            w[i] = (static_cast<std::uint32_t>(p[i * 4]) << 24) |
                   (static_cast<std::uint32_t>(p[i * 4 + 1]) << 16) |
                   (static_cast<std::uint32_t>(p[i * 4 + 2]) << 8) |
                   static_cast<std::uint32_t>(p[i * 4 + 3]);
        for (int i = 16; i < 64; ++i) {
            const std::uint32_t s0 = ror(w[i - 15], 7) ^ ror(w[i - 15], 18) ^ (w[i - 15] >> 3);
            const std::uint32_t s1 = ror(w[i - 2], 17) ^ ror(w[i - 2], 19) ^ (w[i - 2] >> 10);
            w[i] = w[i - 16] + s0 + w[i - 7] + s1;
        }
        std::uint32_t a = h[0], b = h[1], c = h[2], d = h[3];
        std::uint32_t e = h[4], f = h[5], g = h[6], hh = h[7];
        for (int i = 0; i < 64; ++i) {
            const std::uint32_t S1 = ror(e, 6) ^ ror(e, 11) ^ ror(e, 25);
            const std::uint32_t ch = (e & f) ^ (~e & g);
            const std::uint32_t t1 = hh + S1 + ch + K[i] + w[i];
            const std::uint32_t S0 = ror(a, 2) ^ ror(a, 13) ^ ror(a, 22);
            const std::uint32_t maj = (a & b) ^ (a & c) ^ (b & c);
            const std::uint32_t t2 = S0 + maj;
            hh = g; g = f; f = e; e = d + t1; d = c; c = b; b = a; a = t1 + t2;
        }
        h[0] += a; h[1] += b; h[2] += c; h[3] += d;
        h[4] += e; h[5] += f; h[6] += g; h[7] += hh;
    }
    void update(const void* data, std::size_t n) {
        const unsigned char* p = static_cast<const unsigned char*>(data);
        total += n;
        while (n > 0) {
            const std::size_t take = std::min<std::size_t>(n, 64 - buflen);
            std::memcpy(buf + buflen, p, take);
            buflen += take;
            p += take;
            n -= take;
            if (buflen == 64) { block(buf); buflen = 0; }
        }
    }
    std::array<unsigned char, 32> final() {
        const std::uint64_t bits = total * 8;
        const unsigned char pad = 0x80;
        update(&pad, 1);
        const unsigned char zero = 0x00;
        while (buflen != 56) update(&zero, 1);
        unsigned char len[8];
        for (int i = 0; i < 8; ++i) len[i] = static_cast<unsigned char>(bits >> (56 - 8 * i));
        update(len, 8);
        std::array<unsigned char, 32> out{};
        for (int i = 0; i < 8; ++i) {
            out[i * 4] = static_cast<unsigned char>(h[i] >> 24);
            out[i * 4 + 1] = static_cast<unsigned char>(h[i] >> 16);
            out[i * 4 + 2] = static_cast<unsigned char>(h[i] >> 8);
            out[i * 4 + 3] = static_cast<unsigned char>(h[i]);
        }
        return out;
    }
};
static std::array<unsigned char, 32> sha256(const void* p, std::size_t n) {
    Sha256 s;
    s.update(p, n);
    return s.final();
}
static std::string hex(const std::array<unsigned char, 32>& d) {
    static const char* t = "0123456789abcdef";
    std::string s;
    for (unsigned char c : d) { s += t[c >> 4]; s += t[c & 15]; }
    return s;
}

/* ---------------- 合成元数据 ---------------- */
struct Entry {
    std::string path;
    std::uint64_t size = 0;
    std::uint64_t mtime = 0;
    std::array<unsigned char, 32> digest{};
    bool has_digest = false;
    std::string content;
};

static Entry make_entry(int i, bool with_content) {
    Entry e;
    e.path = "assets/textures/group_" + std::to_string(i / 100) + "/file_" + std::to_string(i) + ".dat";
    e.mtime = 1700000000ull + static_cast<std::uint64_t>(i) * 7ull;
    e.size = 1024ull + static_cast<std::uint64_t>(i % 97);
    if (with_content) {
        e.content.resize(static_cast<std::size_t>(e.size));
        std::uint32_t x = 0x9e3779b9u ^ static_cast<std::uint32_t>(i) * 2654435761u;
        for (char& c : e.content) { x ^= x << 13; x ^= x >> 17; x ^= x << 5; c = static_cast<char>(x & 0xff); }
        if (i % 20 != 0) {                 // 百分之九十五的文件有内容哈希
            e.digest = sha256(e.content.data(), e.content.size());
            e.has_digest = true;
        }
    }
    return e;
}

int main() {
    // 零、先证明这个 SHA-256 是标准的：两个公开测试向量
    const char* abc = "abc";
    std::printf("SHA-256(\"abc\") = %s\n", hex(sha256(abc, 3)).c_str());
    std::printf("SHA-256(\"\")    = %s\n", hex(sha256("", 0)).c_str());

    const int n = 10000;
    std::vector<Entry> a, b;
    a.reserve(static_cast<std::size_t>(n));
    for (int i = 0; i < n; ++i) a.push_back(make_entry(i, true));

    // b：改 300 个、少 200 个、多 200 个
    for (int i = 0; i < n; ++i) {
        if (i % 49 == 0 && b.size() < static_cast<std::size_t>(n - 200)) continue;   // 少掉
        Entry e = make_entry(i, true);
        if (i % 33 == 0) {                       // 改过：内容、大小、时间都变
            e.content[0] = static_cast<char>(e.content[0] + 1);
            e.size += 1;
            e.mtime += 100;
            if (e.has_digest) e.digest = sha256(e.content.data(), e.content.size());
            else { e.digest = sha256(e.content.data(), e.content.size()); e.has_digest = true; }
        }
        b.push_back(e);
    }
    for (int k = 0; k < 200; ++k) b.push_back(make_entry(n + k, true));
    std::printf("A 侧 %zu 条、B 侧 %zu 条（合成元数据，内容各 %llu 字节量级）\n",
                a.size(), b.size(), static_cast<unsigned long long>(a[0].size));

    // 一、两两比较与哈希索引
    long long found = 0, compares = 0;
    const double t_double = time_ms([&] {
        for (const Entry& eb : b)
            for (const Entry& ea : a) {
                ++compares;
                if (ea.path == eb.path) { ++found; break; }
            }
    });
    std::printf("双重循环：比较 %lld 次，找到 %lld 条，耗时 %.3f ms\n", compares, found, t_double);

    // 二、索引：不 reserve 与 reserve 的差别
    std::unordered_map<std::string, std::size_t> idx;
    const double t_idx_noreserve = time_ms([&] {
        for (std::size_t i = 0; i < a.size(); ++i) idx.emplace(a[i].path, i);
    });
    const std::size_t buckets_after = idx.bucket_count();
    std::unordered_map<std::string, std::size_t> idx2;
    idx2.reserve(a.size() * 2);
    const std::size_t buckets_reserved = idx2.bucket_count();
    const double t_idx_reserve = time_ms([&] {
        for (std::size_t i = 0; i < a.size(); ++i) idx2.emplace(a[i].path, i);
    });
    long long hits = 0;
    const double t_lookup = time_ms([&] {
        for (const Entry& eb : b) {
            const auto it = idx2.find(eb.path);
            if (it != idx2.end()) ++hits;
        }
    });
    std::printf("哈希索引：不 reserve 桶 %zu 个、耗时 %.3f ms；reserve(20000) 桶 %zu 个、耗时 %.3f ms\n",
                buckets_after, t_idx_noreserve, buckets_reserved, t_idx_reserve);
    std::printf("在索引里查 B 侧 %zu 条：找到 %lld 条，耗时 %.3f ms\n", b.size(), hits, t_lookup);

    // 三、两级比较：先比内容哈希，缺哈希时退回大小加修改时间
    std::unordered_map<std::string, std::size_t> b_index;      // 后面第四步还要用
    b_index.reserve(b.size() * 2);
    for (std::size_t i = 0; i < b.size(); ++i) b_index.emplace(b[i].path, i);

    std::vector<std::pair<std::size_t, std::size_t>> matched;
    long long level1 = 0, fallback = 0, decided_equal = 0;
    for (std::size_t i = 0; i < a.size(); ++i) {
        const auto it = b_index.find(a[i].path);
        if (it == b_index.end()) continue;
        const Entry& eb = b[it->second];
        matched.emplace_back(i, it->second);
        if (a[i].has_digest && eb.has_digest) {
            ++level1;
            if (a[i].digest == eb.digest) ++decided_equal;
        } else {
            ++fallback;
            decided_equal += (a[i].size == eb.size && a[i].mtime == eb.mtime);
        }
    }
    const double t_digest_all = time_ms([&] {
        std::uint64_t acc = 0;
        for (const Entry& e : a) {
            const auto d = sha256(e.content.data(), e.content.size());
            acc += d[0];
        }
        g_sink += acc;
    });
    const long long reps = 200000;
    const double t_cmp_digest = time_ms([&] {
        std::uint64_t acc = 0;
        for (long long r = 0; r < reps; ++r) {
            const auto& pr = matched[static_cast<std::size_t>(r) % matched.size()];
            acc += a[pr.first].digest == b[pr.second].digest;
        }
        g_sink += acc;
    });
    const double t_cmp_meta = time_ms([&] {
        std::uint64_t acc = 0;
        for (long long r = 0; r < reps; ++r) {
            const auto& pr = matched[static_cast<std::size_t>(r) % matched.size()];
            acc += (a[pr.first].size == b[pr.second].size) && (a[pr.first].mtime == b[pr.second].mtime);
        }
        g_sink += acc;
    });
    std::printf("两级比较：配对 %zu 对、比内容哈希 %lld 对、退回大小加时间 %lld 对、判为相同 %lld 对\n",
                matched.size(), level1, fallback, decided_equal);
    std::printf("算完 A 侧 %d 个文件的内容哈希：%.3f ms（一级比较真正贵的地方）\n", n, t_digest_all);
    std::printf("只比 32 字节哈希 %lld 次：%.3f ms（%.2f ns/次）；只比大小加时间 %lld 次：%.3f ms（%.2f ns/次）\n",
                reps, t_cmp_digest, t_cmp_digest * 1e6 / static_cast<double>(reps),
                reps, t_cmp_meta, t_cmp_meta * 1e6 / static_cast<double>(reps));

    // 四、两趟循环：added 只能在第二趟算出
    long long removed = 0, modified = 0, unchanged = 0;
    for (std::size_t i = 0; i < a.size(); ++i) {
        const auto it = b_index.find(a[i].path);
        if (it == b_index.end()) { ++removed; continue; }
        const Entry& eb = b[it->second];
        const bool same = (a[i].has_digest && eb.has_digest)
                              ? (a[i].digest == eb.digest)
                              : (a[i].size == eb.size && a[i].mtime == eb.mtime);
        if (same) ++unchanged; else ++modified;
    }
    long long added = 0;
    for (const Entry& eb : b)                                   // 第二趟
        if (idx2.find(eb.path) == idx2.end()) ++added;
    std::printf("两趟差集：added=%lld removed=%lld modified=%lld unchanged=%lld\n",
                added, removed, modified, unchanged);

    // 五、遍历顺序：哈希顺序与排序顺序
    auto order_hash = [](const std::unordered_map<std::string, std::size_t>& m) {
        std::uint64_t h = 1469598103934665603ull;
        for (const auto& kv : m) {
            for (char c : kv.first) { h ^= static_cast<unsigned char>(c); h *= 1099511628211ull; }
        }
        return h;
    };
    std::vector<std::string> paths;
    paths.reserve(a.size());
    for (const Entry& e : a) paths.push_back(e.path);
    std::sort(paths.begin(), paths.end());
    auto order_list = [](const std::vector<std::string>& v) {
        std::uint64_t h = 1469598103934665603ull;
        for (const std::string& s : v) {
            for (char c : s) { h ^= static_cast<unsigned char>(c); h *= 1099511628211ull; }
        }
        return h;
    };
    std::vector<std::string> hash_order;
    hash_order.reserve(idx2.size());
    for (const auto& kv : idx2) hash_order.push_back(kv.first);
    std::printf("哈希索引顺序校验和 %llu；按路径排序后顺序校验和 %llu\n",
                static_cast<unsigned long long>(order_list(hash_order)),
                static_cast<unsigned long long>(order_list(paths)));
    std::printf("哈希索引前三条：%s | %s | %s\n",
                hash_order[0].c_str(), hash_order[1].c_str(), hash_order[2].c_str());
    std::printf("排序后前三条：%s | %s | %s\n",
                paths[0].c_str(), paths[1].c_str(), paths[2].c_str());

    // 六、中途出错：捕获异常但保留已经算出的部分结果
    long long done = 0, same_so_far = 0;
    bool partial = false;
    try {
        for (std::size_t i = 0; i < a.size(); ++i) {
            if (i == 7000) throw std::runtime_error("file vanished while hashing");
            ++done;
            same_so_far += (a[i].size == b[i].size);
        }
    } catch (const std::exception& ex) {
        partial = true;
        std::printf("中途异常：%s\n", ex.what());
    }
    std::printf("部分结果：处理了 %lld 条、其中大小相同 %lld 条、partial=%s\n",
                done, same_so_far, partial ? "true" : "false");
    std::printf("结果校验和 %llu\n", static_cast<unsigned long long>(g_sink));
    return 0;
}
```

**第一条：哈希索引把两两比较降成一次遍历。** 两个清单各一万条，
双重循环最坏要比较一亿次，发现匹配就跳出之后，仍比较了五千多万次。

`实测数据`
`Text`

```text
SHA-256("abc") = ba7816bf8f01cfea414140de5dae2223b00361a396177a9cb410ff61f20015ad
SHA-256("")    = e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
A 侧 10000 条、B 侧 9995 条（合成元数据，内容各 1024 字节量级）
双重循环：比较 50980205 次，找到 9795 条，耗时 77.118 ms
```

两个测试向量与公开值一致，因此后面那些「哈希相同 / 不同」的结论有依据。

**第二条：`reserve` 省下的是再哈希，不是「扩容」这个概念本身。**
不 `reserve` 时表从默认桶数一路翻倍到 10273 个桶；
先 `reserve(20000)` 直接要 20753 个桶，一次也不用再哈希。

`实测数据`
`Text`

```text
哈希索引：不 reserve 桶 10273 个、耗时 0.944 ms；reserve(20000) 桶 20753 个、耗时 0.807 ms
在索引里查 B 侧 9995 条：找到 9795 条，耗时 0.211 ms
```

省下的时间在这一万条规模上只有约百分之十五，因为再哈希只发生十来次；
**规模越大越明显**，每一次再哈希都要把所有节点重新挂一遍。
桶数多出的一倍是代价：`reserve` 要留出余量，否则负载因子一过阈值就又要扩容。

**第三条：比较要分两级，先贵后便宜。**
两级比较的做法是：两边都有内容哈希时比哈希，缺哈希时退回比「大小加修改时间」。

`实测数据`
`Text`

```text
两级比较：配对 9795 对、比内容哈希 9306 对、退回大小加时间 489 对、判为相同 9498 对
算完 A 侧 10000 个文件的内容哈希：29.670 ms（一级比较真正贵的地方）
只比 32 字节哈希 200000 次：0.696 ms（3.48 ns/次）；只比大小加时间 200000 次：0.419 ms（2.10 ns/次）
```

这一条最容易被理解反。**比一次哈希**只花 3.48 ns，比「大小加时间」的 2.10 ns 贵不了多少；
真正贵的是**算出**哈希——要读完一万个文件各一 KB 的内容，29.670 ms，
是整份差集运算里最大的一笔开销。
所以两级次序的意义不是「省下比较」，而是：
**能用便宜且可靠的一级判掉时就不算二级。能把哈希算在扫描阶段（扫描时本来就要读内容），就不要留到比较阶段。**
退回那一级的价值在于哈希缺失时程序仍然能给出结论，代价是可能误判——
大小相同、修改时间也相同但内容不同的文件，会被判成没变。

**第四条：`added` 只能在第二趟算出。**
第一趟遍历本地清单，能判出「删了」「改了」「没变」；
「新增」要求「在本地清单里找不到」，那是另一侧的条件，只能在第二趟遍历里算。

`实测数据`
`Text`

```text
两趟差集：added=200 removed=205 modified=297 unchanged=9498
```

四个数加起来是 10200，正好是两边条目数之和减掉配对数的两倍——
这类和式是校验差集实现最简单的一招。

**第五条：输出之前要排序。** 哈希索引的遍历顺序不是排序顺序，也不能依赖。

`实测数据`
`Text`

```text
哈希索引顺序校验和 6649249162719201163；按路径排序后顺序校验和 8878472366843501941
哈希索引前三条：assets/textures/group_99/file_9997.dat | assets/textures/group_99/file_9996.dat | assets/textures/group_99/file_9995.dat
排序后前三条：assets/textures/group_0/file_0.dat | assets/textures/group_0/file_1.dat | assets/textures/group_0/file_10.dat
```

哈希顺序的头三条从 `group_99` 开始，排序后的头三条从 `group_0` 开始。

这里有一种容易先入为主的设想：「同一份输入跑两次，哈希顺序两次不同」。**在本机这套标准库上两次是相同的**：libstdc++ 对整数用恒等哈希，同一串插入顺序给出同一条遍历顺序（第 4.4.1 小节那一行校验和也说明这一点）。能当证据的不是「两次不同」，而是另外两条：**它不是排序顺序**（头三条落在 `group_99`），以及**改一个键就变**——那说明顺序不是内容的函数，也就不能依赖。
**要输出给人看、要写进文件、要两次运行结果可比，就必须先排序**，
否则同一份输入两次运行可能给出两个「不同」的结果（第 4.4.2 小节）。

**第六条：中途出错时保留已经算出的部分。**
程序在第七千条上抛异常，捕获之后返回的是「处理了 7000 条、其中大小相同 47 条」，
另带一个 `partial` 标志。

`实测数据`
`Text`

```text
中途异常：file vanished while hashing
部分结果：处理了 7000 条、其中大小相同 47 条、partial=true
```

扫描一个真实目录时，「文件在扫描中途被删掉」是常态而不是异常情况。
两种做法都合理：整份作废，或者返回带标志的部分结果。
**不能做的是把部分结果当成完整结果返回**——四个分类计数会静默偏小，
而且没有任何地方能看出它偏小。标志位是这个设计里唯一不能省的东西。

## 4.5.3 六条收成一张表

| 取舍 | 省下了什么 | 付出什么 |
|---|---|---|
| 哈希索引降复杂度 | 把两两比较的五千多万次降成一次遍历 | 一份索引的内存 |
| `reserve` | 十几次再哈希与重新挂链 | 桶数多留一倍 |
| 两级比较 | 有哈希时不做弱比较 | 缺哈希时可能误判 |
| 两趟循环 | 四个分类都能算全 | 遍历两遍 |
| 输出前排序 | 结果可比较、可复现 | 一次排序的时间 |
| 保留部分结果 | 一次失败不至于全部白跑 | 必须带标志位，调用方必须看 |

> [!NOTE]
> 查找这一章收成三句话：
> **查找的代价是「比较次数 × 每次比较的代价」，规模小的时候后者占主导，
> 规模大的时候前者占主导，交叉点落在几十到几百；**
> **二分的三种边界写法没有优劣，只有「右端点指向什么」这一件事要一次说清；
> 哈希表用顺序、内存与最坏情况换点查的常数，需求里出现范围或稳定输出时这笔交易做不成；**
> **真实的差集代码里，最贵的一笔往往不是比较，而是为了拿到可靠的比较依据去读全部内容。**

# 术语表

| 术语 | 含义 |
|---|---|
| **线性扫描** | 从头到尾逐个比较，不要求有序 |
| **二分查找** | 每次砍掉一半区间；要求区间有序且能随机访问 |
| **下界（`lower_bound`）** | 第一个不小于给定键的位置；键不存在时是它的插入点 |
| **上界（`upper_bound`）** | 第一个大于给定键的位置 |
| **分区（partitioned）** | 满足条件的元素全在前、不满足的全在后；`lower_bound` 的前提 |
| **插值查找** | 按键在值域里的相对位置猜下一次比较的位置；要求分布近似均匀 |
| **跳表** | 给每个节点随机层数、用多层稀疏链做 `log` 级查找的链式结构 |
| **负载因子** | 键数除以桶数；哈希表靠它决定何时再哈希 |
| **再哈希（rehash）** | 桶数变化后把全部节点重新挂到新桶上 |
| **强比较／弱比较** | 前者昂贵但可靠（内容哈希），后者便宜但可能误判（大小加时间） |
| **部分结果** | 中途失败时返回已经算出的那一部分，必须带标志位 |

# 附录 A 复现本章节实测

**环境**：Windows 11，g++ 16.2.0（MinGW-w64）。

|---|---|---|

| 三种边界写法与标准库的逐用例对照、中点溢出 | `binary_bounds.cpp` | 第 4.2.2、4.2.3 小节 |

**几点复现说明**：

- 上表的程序按顺序运行，全部跑完约四秒；
  `diff_cost.cpp` 里的双重循环一项独自占约 77 ms，把两边条目数各加十倍，它会变成约八秒；
- 结构量（比较次数、桶数、字节数、校验和、四个分类计数）重跑逐位相同；
- 计时量每次重跑都会浮动，正文引用的是其中一次的输出；
- `hash_vs_binary.cpp` 的「占用」一行由计数分配器累加得到，
  计入节点与桶数组，但不含分配器的对齐填充，因此是一个略偏小的值。
- 计时循环里的每一项都与当次查询有关（键与下标），没有把循环不变的东西留在循环里；
  结果都由全局变量接住并在最后打印，`-O2` 下不会被整段删掉——
  `find_threshold.cpp` 的 `-O0` 对照里比较次数逐位相同，可以旁证带计数的循环真的执行了；
- `find_threshold.cpp` 的两条编译命令都写在首行注释里，`-O0` 那条是给计时做对照用的，
  正文里两张表的**比较次数**逐位相同、**耗时**不同，这正说明结构量与计时量要分开看。

`待确认`

计时数据来自这一台机器，同一份程序重跑数次后观察到的区间：
`find_threshold.cpp` 在 n=1048576 时线性在 238 到 245 ms、二分在 165 到 172 ns/查询之间；
`hash_vs_binary.cpp` 的点查二分在 22.4 到 25.1 ms、哈希在 15.5 到 19.8 ms 之间；
`diff_cost.cpp` 的双重循环在 77 到 85 ms 之间。
**结论（线性随规模线性增长、二分的每查询代价几乎不变、范围查询上哈希落后两个数量级）
稳定，逐位数字不稳定。** 换机器、换编译器、换标准库，请以自己重跑的结果为准。
