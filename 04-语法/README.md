# 语法

本板块收录 **C 与 C++ 的语法本身**。

**它不是一份语法清单。** 本板块的组织方式建立在一条判断上：

> [!IMPORTANT]
> **语法点不是排成一列的清单，而是一张相互搭接的网。**
> 讲清一个点常常需要先懂另一个点，而那个点又反过来需要这一个。
> **因此章节的编号只是阅读顺序的建议，不是依赖顺序。**

**这张网的样子、以及本教材怎么处理它，见
《04-语法/00-导读：从记住规则到理解意图.md》第 5.1 小节。**

### 网上的几个环

**依赖关系里有环，这是语法的固有性质，不是编排失误。**

| 环 | 表现 |
|---|---|
| **引用 ↔ 函数** | 讲清「引用有什么用」需要先懂函数传参；讲清「函数传参的效率」需要先懂引用 |
| **数组 ↔ 指针** | 数组名退化成指针，而指针运算又要按元素大小缩放——两者互相定义 |
| **类型 ↔ 表达式** | 字面量的类型属于类型系统，但它由表达式规则决定 |
| **作用域 ↔ 生存期 ↔ 链接** | 三者常被当成一件事，但 `static` 恰好只影响其中两个，见 11 |

**本教材的处理方式**：在需要的地方先用一句话给出足够往下读的理解，
并指明完整讲解在哪一章。**这不是绕路，而是把环拆成两段直线。**

**做法见《04-语法/00-导读：从记住规则到理解意图.md》第 5.3 小节。**

## 版本基准

**本板块以 C++17 与 C23 为基准。**

| 标准 | 取值 | 说明 |
|---|---|---|
| C++17 | `__cplusplus == 201703L` | 不用 C++20 起的特性，用到时会注明 |
| C23 | `__STDC_VERSION__ == 202311L` | 不用 C23 新增但尚未普及的部分 |

**涉及两者差异时一律并列给出**，并指出差异背后的设计意图。
