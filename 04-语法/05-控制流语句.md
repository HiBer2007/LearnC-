# 第 1 节 只有六种语句

**C 与 C++ 的语句种类很少。**

| 种类 | 写法 |
|---|---|
| **表达式语句** | `a = 1;`、`f();`——**任何表达式加分号** |
| **复合语句** | `{ ... }`——也叫语句块 |
| **选择语句** | `if`、`switch` |
| **迭代语句** | `while`、`do-while`、`for` |
| **跳转语句** | `break`、`continue`、`return`、`goto` |
| **声明语句** | `int a;`（C++ 里声明也是语句） |

**注意第一行**：`a = 1;` 不是「赋值语句」，而是
**「一个表达式，后面加了个分号」**。

> [!IMPORTANT]
> **没有「赋值语句」「函数调用语句」这些类别。**
> 它们是表达式语句——`=` 和 `()` 都是运算符，整个东西是一个表达式。
> 这一点在《04-语法/03-表达式与运算符.md》第 1 节已经讲过。

**本章只讲后四种**（选择、迭代、跳转、复合）。
表达式语句归 `03`，声明语句归 `04` 与 `10`。

# 第 2 节 选择

## 2.1 `if`

<small style="color:gray">c</small>

```c
/* if_basic.c    编译：gcc -std=c23 if_basic.c -o if_basic */
#include <stdio.h>

int main(void) {
    int score = 72;

    if (score >= 90) {
        printf("优\n");
    } else if (score >= 60) {
        printf("及格\n");
    } else {
        printf("不及格\n");
    }
    return 0;
}
```

**输出**：`及格`

**`else` 与最近的 `if` 配对**，这一点在嵌套时容易看错：

<small style="color:gray">c</small>

```c
if (a)
    if (b)
        printf("ab\n");
else                    /* 这个 else 属于内层的 if (b) */
    printf("not b\n");
```

**想让它属于外层，就加大括号**：

<small style="color:gray">c</small>

```c
if (a) {
    if (b)
        printf("ab\n");
} else {
    printf("not a\n");
}
```

> [!TIP]
> **一律加大括号**，即使只有一条语句。
> 省下的是两行，换来的是「以后往里加一行不会出错」。

## 2.2 一个不警告就编过的错

**把 `==` 写成 `=`。**

<small style="color:gray">c</small>

```c
/* assign_cond.c    编译：gcc -std=c23 assign_cond.c -o assign_cond */
#include <stdio.h>

int main(void) {
    int a = 0;
    if (a = 1) {                        /* 本意大概是 a == 1 */
        printf("进入了分支，a=%d\n", a);
    }
    return 0;
}
```

**实测：不开选项时编译完全通过，运行时输出 `进入了分支，a=1`。**

<small style="color:gray">实测数据</small>

| 编译选项 | 结果 |
|---|---|
| （无） | **通过，无任何提示** |
| `-Wall` | 警告：`suggest parentheses around assignment used as truth value` |
| `-Wall -Wextra` | 同上 |

> [!CAUTION]
> **`if (a = 1)` 在不加 `-Wall` 时不会报错也不会警告。**
> 它的效果是「把 1 赋给 a，然后判断 a 非零」——**条件永远为真**。
> 这类错误在代码评审时很难一眼看出，**必须靠编译选项兜住**。

**一种防御写法是把常量写在左边**：

<small style="color:gray">c</small>

```c
if (1 = a) { }      /* 编译失败：lvalue required as left operand of assignment */
```

**实测报错**：`error: lvalue required as left operand of assignment`

**因为 `1` 不是左值，不能被赋值**，所以写错时编译器必然拦住。

> [!TIP]
> **两种做法都行，但 `-Wall` 更直接。**
> 把常量写左边只能防住「常量与变量比较」这一种情形，
> 而 `-Wall` 能拦住全部赋值当条件的地方。

## 2.3 `switch`

<small style="color:gray">c</small>

```c
/* switch_basic.c    编译：gcc -std=c23 switch_basic.c -o switch_basic */
#include <stdio.h>

int main(void) {
    int cmd = 2;

    switch (cmd) {
        case 1:
            printf("开始\n");
            break;
        case 2:
            printf("停止\n");
            break;
        default:
            printf("未知命令\n");
            break;
    }
    return 0;
}
```

**输出**：`停止`

**`switch` 与 `if` 链的区别在于跳转方式**：
`switch` 通常被编译成一张跳转表，因此分支多时比 `if` 链快。
分支少时两者差不多。

### `case` 后面必须是常量

<small style="color:gray">c</small>

```c
int y = 2;
switch (x) {
    case y:             /* 不合法 */
        break;
}
```

**实测报错**：

<small style="color:gray">实测数据</small>
<small style="color:gray">text</small>

```text
C23  : error: case label does not reduce to an integer constant
C++17: error: the value of 'y' is not usable in a constant expression
```

**原因**：`switch` 要生成跳转表，必须在**编译期**就知道所有分支的值。

### 贯穿（fallthrough）

**`case` 后面不写 `break`，会继续往下执行。**

<small style="color:gray">c</small>

```c
/* fallthrough.c    编译：gcc -std=c23 fallthrough.c -o fallthrough */
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 4; i++) {
        printf("i=%d -> ", i);
        switch (i) {
            case 1: printf("一 ");
            case 2: printf("二 ");      /* 没有 break，会继续往下走 */
            case 3: printf("三 "); break;
            case 4: printf("四 "); break;
            default: printf("其他 ");
        }
        printf("\n");
    }
    return 0;
}
```

**实测输出**：

<small style="color:gray">实测数据</small>
<small style="color:gray">text</small>

```text
i=1 -> 一 二 三
i=2 -> 二 三
i=3 -> 三
i=4 -> 四
```

**`i=1` 时把三个分支都走了一遍**，因为 `case 1` 与 `case 2` 后面都没有 `break`。

> [!WARNING]
> **`-Wall` 不会警告贯穿，要 `-Wextra` 才会。**
> 实测：`-Wall` 下无任何提示；加 `-Wextra`（或单开 `-Wimplicit-fallthrough`）
> 才给出 `this statement may fall through [-Wimplicit-fallthrough]`。
> **只开 `-Wall` 的工程里，漏写 `break` 会静默通过。**

**贯穿偶尔是有意为之**（比如多个值走同一段逻辑）：

<small style="color:gray">c</small>

```c
case 'a':
case 'e':
case 'i':
case 'o':
case 'u':
    printf("元音\n");
    break;
```

**空 `case` 不算贯穿**，编译器不会警告。**只有 `case` 后面跟了语句又没 `break` 才是。**

# 第 3 节 迭代

## 3.1 三种循环

<small style="color:gray">c</small>

```c
/* three_loops.c    编译：gcc -std=c23 three_loops.c -o three_loops */
#include <stdio.h>

int main(void) {
    int i;

    i = 0;
    while (i < 3) {                 /* 先判断，后执行 */
        printf("while %d\n", i);
        i++;
    }

    i = 0;
    do {                            /* 先执行，后判断 */
        printf("do-while %d\n", i);
        i++;
    } while (i < 3);

    for (i = 0; i < 3; i++) {       /* 判断、循环体、递增三件事写在一行 */
        printf("for %d\n", i);
    }
    return 0;
}
```

**三者的输出完全一样。**

## 3.2 `do-while` 的特殊之处

**循环体至少执行一次**，因为判断在末尾。

<small style="color:gray">c</small>

```c
/* dowhile.c    编译：gcc -std=c23 dowhile.c -o dowhile */
#include <stdio.h>

int main(void) {
    int n = 0;

    printf("while   : ");
    while (n > 0) { printf("执行了一次 "); n--; }
    printf("(结束)\n");

    n = 0;
    printf("do-while: ");
    do { printf("执行了一次 "); n--; } while (n > 0);
    printf("(结束)\n");
    return 0;
}
```

**实测输出**：

<small style="color:gray">实测数据</small>
<small style="color:gray">text</small>

```text
while   : (结束)
do-while: 执行了一次 (结束)
```

**条件一开始就是假时，`while` 一次都不执行，`do-while` 执行一次。**

> [!TIP]
> **`do-while` 适合「至少要试一次」的场景**：
> 读一个输入直到它合法、重试一个操作直到成功。

## 3.3 `for` 与 `while` 编译后相同

**`for` 不是新东西，它只是 `while` 的紧凑写法。**

<small style="color:gray">c</small>

```c
/* loop_equiv.c    编译：gcc -std=c23 -S loop_equiv.c -o loop_equiv.s */
int by_for(int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += i;
    return s;
}

int by_while(int n) {
    int s = 0;
    int i = 0;
    while (i < n) { s += i; i++; }
    return s;
}
```

**实测：两个函数生成的指令序列逐条相同**，只有跳转标签的编号不同
（`.L2` / `.L3` 与 `.L6` / `.L7`）。

<small style="color:gray">asm</small>

```asm
by_for:                          by_while:
    pushq   %rbp                     pushq   %rbp
    movq    %rsp, %rbp               movq    %rsp, %rbp
    subq    $16, %rsp                subq    $16, %rsp
    movl    %ecx, 16(%rbp)           movl    %ecx, 16(%rbp)
    movl    $0, -4(%rbp)             movl    $0, -4(%rbp)
    movl    $0, -8(%rbp)             movl    $0, -8(%rbp)
    jmp     .L2                      jmp     .L6
.L3:                             .L7:
    movl    -8(%rbp), %eax           movl    -8(%rbp), %eax
    addl    %eax, -4(%rbp)           addl    %eax, -4(%rbp)
    addl    $1, -8(%rbp)             addl    $1, -8(%rbp)
.L2:                             .L6:
    movl    -8(%rbp), %eax           movl    -8(%rbp), %eax
    cmpl    16(%rbp), %eax           cmpl    16(%rbp), %eax
    jl      .L3                      jl      .L7
```

> [!IMPORTANT]
> **`for` 与 `while` 没有性能差别。**
> 选哪个只看哪种写法更能说清意图——
> **循环次数已知、有明确的计数变量时用 `for`**，
> **循环条件是别的什么东西时用 `while`**。

## 3.4 循环里声明变量：C89 与 C99 的分界

<small style="color:gray">c</small>

```c
for (int i = 0; i < 3; i++) printf("%d ", i);
```

**实测**：

<small style="color:gray">实测数据</small>

| 标准 | 结果 |
|---|---|
| `-std=c89` | **失败**：`'for' loop initial declarations are only allowed in C99 mode` |
| `-std=c99` | 通过 |
| `-std=c17` | 通过 |
| `-std=c23` | 通过 |

**在 `for` 里声明 `i` 是 C99 才有的**，C89 必须在外面先声明。

**C++ 从第一版就允许。**

> [!TIP]
> **本教材的基准是 C23，因此正文里可以直接在 `for` 里声明变量。**
> 但读老代码时要知道，C89 风格的写法长这样：
> ```c
> int i;
> for (i = 0; i < 3; i++) { }
> ```

# 第 4 节 跳转

## 4.1 `break` 与 `continue` 只作用于最近的一层

<small style="color:gray">c</small>

```c
/* break_continue.c    编译：gcc -std=c23 break_continue.c -o break_continue */
#include <stdio.h>

int main(void) {
    printf("break 只跳出内层:\n");
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            if (j == 1) break;              /* 跳出 j 这一层 */
            printf("(%d,%d) ", i, j);
        }
        printf("| ");
    }

    printf("\n\ncontinue 只跳过内层本轮:\n");
    for (int i = 0; i < 3; i++) {
        for (int j = 0; j < 3; j++) {
            if (j == 1) continue;           /* 跳过 j=1 这一轮 */
            printf("(%d,%d) ", i, j);
        }
        printf("| ");
    }
    printf("\n");
    return 0;
}
```

**实测输出**：

<small style="color:gray">实测数据</small>
<small style="color:gray">text</small>

```text
break 只跳出内层:
(0,0) | (1,0) | (2,0) |

continue 只跳过内层本轮:
(0,0) (0,2) | (1,0) (1,2) | (2,0) (2,2) |
```

**`break` 之后外层的 `|` 照常打印**，说明外层循环没被打断。

> [!WARNING]
> **`break` 跳不出两层循环。**
> 想一次跳出多层，要么用标志变量，要么用 `goto`（见 4.2）。

**用标志变量的写法**：

<small style="color:gray">c</small>

```c
int found = 0;
for (int i = 0; i < 3 && !found; i++) {
    for (int j = 0; j < 3; j++) {
        if (条件) { found = 1; break; }
    }
}
```

**把条件写进外层循环的判断里**，就不需要额外的跳出机制。

## 4.2 `goto`

**`goto` 在教材里名声不好，但它有一个正当用途：一次跳出多层循环。**

<small style="color:gray">c</small>

```c
/* goto_out.c    编译：gcc -std=c23 goto_out.c -o goto_out */
#include <stdio.h>

int main(void) {
    for (int i = 0; i < 3; i++)
        for (int j = 0; j < 3; j++)
            if (i * 3 + j == 4) goto done;

done:
    printf("跳出来了\n");
    return 0;
}
```

**实测输出**：`跳出来了`

### `goto` 的两条限制

**第一条：可以跳进循环体。**

<small style="color:gray">c</small>

```c
/* goto_in.c    编译：gcc -std=c23 goto_in.c -o goto_in */
#include <stdio.h>

int main(void) {
    int i = 0;
    goto inside;
    for (i = 0; i < 3; i++) {
    inside:
        printf("%d ", i);
    }
    printf("\n");
    return 0;
}
```

**实测：编译通过，输出 `0 1 2`。**

**这条合法但没人这么写**——它让循环的进入点变得难以预测。

**第二条：不能跳过变长数组的声明。**

<small style="color:gray">c</small>

```c
int n = 3;
goto skip;
int vla[n];             /* 变长数组，C99 起 */
skip:
printf("到了\n");
```

**实测报错**：

<small style="color:gray">实测数据</small>
<small style="color:gray">text</small>

```text
error: jump into scope of identifier with variably modified type
```

**原因**：`vla` 的大小要到运行期才知道，跳过它的声明会让栈指针错位。
**普通数组没有这个问题**（大小在编译期已知）。

> [!TIP]
> **`goto` 的合理用途只有两个**：
> 一次跳出多层循环，以及**集中清理**（函数末尾统一释放资源，
> 出错时 `goto cleanup;`）。**其余场合都不该用。**

# 第 5 节 为什么语句这么少

**回到第 1 节那张表：只有六种语句。**

**这与多数语言不同**——不少语言把「赋值」「函数调用」
「打印」都算作独立的语句种类。

**C 与 C++ 的做法是：把这些都做成表达式，语句只负责控制走向。**

<small style="color:gray">text</small>

```
   表达式   负责「算出什么值」
   语句     负责「接下来往哪走」
```

**这样分的好处是「表达式可以嵌进任何需要值的地方」**：

<small style="color:gray">c</small>

```c
int a = (b = 3, b + 1);         /* 逗号表达式嵌在初始化里 */
while ((c = getchar()) != EOF)  /* 赋值嵌在循环条件里 */
    putchar(c);
f(a > b ? a : b);               /* 条件表达式嵌在实参里 */
```

**换成「赋值是语句」的语言，上面三句都写不出来。**

> [!IMPORTANT]
> **语句少不是「简陋」，是分工的结果。**
> 一旦把运算都做成表达式，语句就只剩「控制往哪走」这一件事可做，
> 自然就少了。

**代价是有些写法看起来紧凑得过头**——
`while ((c = getchar()) != EOF)` 里同时做了赋值与比较。
**这正是 2.2 节那个 `if (a = 1)` 陷阱的来源**：同一个语法既允许写对也允许写错。

# 术语表

| 术语 | 英文 | 含义 |
|---|---|---|
| 表达式语句 | Expression statement | 一个表达式后加分号 |
| 复合语句 | Compound statement | `{ ... }`，也叫语句块 |
| 贯穿 | Fallthrough | `switch` 的 `case` 没写 `break` 而继续往下 |
| 跳转表 | Jump table | `switch` 常被编译成的地址表 |
| 最令人烦恼的解析 | Most vexing parse | 能当声明解释时，编译器优先当声明 |
| 变长数组 | VLA, Variable-length array | 大小在运行期才确定的数组，C99 起 |

## A.1 `if (a = 1)` 什么时候才警告

<small style="color:gray">c</small>

```c

#include <stdio.h>
int main(void) {

    if (a = 1) { printf("进入了分支，a=%d\n", a); }

}
```

<small style="color:gray">bash</small>

```bash
gcc -std=c23 assign_cond.c -o assign_cond        # 通过，无提示
gcc -std=c23 -Wall assign_cond.c -o assign_cond  # 警告
./assign_cond                                    # 进入了分支，a=1
```

## A.2 `switch` 贯穿的警告选项

<small style="color:gray">c</small>

```c
/* fallthrough.c */
#include <stdio.h>
int main(void) {
    int i = 1;
    switch (i) {
        case 1: printf("一 ");
        case 2: printf("二 "); break;
        default: break;
    }
    return 0;
}
```

<small style="color:gray">bash</small>

```bash
gcc -std=c23 -Wall   -c fallthrough.c -o f.o   # 无警告
gcc -std=c23 -Wextra -c fallthrough.c -o f.o   # 警告 -Wimplicit-fallthrough
```

## A.3 `for` 与 `while` 的等价

<small style="color:gray">c</small>

```c
/* loop_equiv.c */
int by_for(int n) {
    int s = 0;
    for (int i = 0; i < n; i++) s += i;
    return s;
}
int by_while(int n) {
    int s = 0;
    int i = 0;
    while (i < n) { s += i; i++; }
    return s;
}
```

<small style="color:gray">bash</small>

```bash
gcc -std=c23 -O0 -S loop_equiv.c -o loop_equiv.s
```

**打开 `loop_equiv.s` 对照两个函数体**：指令逐条相同，只有标签编号不同。

## A.5 `case` 必须是常量

<small style="color:gray">c</small>

```c
/* case_var.c */
int main(void) {
    int x = 2, y = 2;
    switch (x) {
        case y: return 1;
        default: return 0;
    }
}
```

<small style="color:gray">bash</small>

```bash
gcc -std=c23 -c case_var.c -o c.o      # case label does not reduce to an integer constant
g++ -std=c++17 -c case_var.c -o c.o    # the value of 'y' is not usable in a constant expression
```
