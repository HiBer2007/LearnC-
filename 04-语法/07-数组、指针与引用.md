**这三样东西被放在同一章，是因为它们底层是同一件事。**

> [!IMPORTANT]
> **引用是「适用于函数传参的指针」的语法糖，**
> **数组是「适用于数据存储的指针」的语法糖。**

**这句话是本章的主线。** 它一次解释了六个「为什么」：

| 现象 | 由什么推出 |
|---|---|
| 数组为什么能写 `arr[i]` | 它就是 `*(arr + i)` |
| 数组名为什么能传给指针参数 | 它退化成指向首元素的指针 |
| 数组为什么不能整体赋值 | 退化之后只剩一个地址 |
| `&arr` 与 `arr` 为什么值相同而类型不同 | 退化发生与否决定的 |
| 引用为什么必须初始化 | 它是别名，没有「自己的值」可空着 |
| 引用为什么传参高效 | 它就是指针，只是自动解引用 |

**语法糖的含义见《04-语法/01-一些基础概念.md》第 1 节**：
**它不是「简单」，而是「同一件事的另一种写法」**——
底层机制相同，写法不同，限制也因此不同。

# 第 1 节 指针

## 1.1 指针是什么

**指针是一个整数，它的值是一个内存地址。**

**「是什么类型的指针」决定两件事**：

| 类型 | 决定 |
|---|---|
| `int *` 而不是 `char *` | 从那个地址**读几个字节** |
| | 加减 1 时**跳过几个字节** |

`C`

```c
/* ptr_basic.c    编译：gcc -std=c23 ptr_basic.c -o ptr_basic */
#include <stdio.h>

int main(void) {
    int a = 42;
    int *p = &a;                    /* p 存放 a 的地址 */

    printf("a 的值        = %d\n", a);
    printf("a 的地址      = %p\n", (void *)&a);
    printf("p 的值        = %p   （就是 a 的地址）\n", (void *)p);
    printf("*p 的值       = %d   （解引用：按 int 读 4 字节）\n", *p);

    *p = 100;                       /* 通过指针写回 */
    printf("写回之后 a    = %d\n", a);
    return 0;
}
```

**`&` 取地址，`*` 解引用**——这两个运算符互为逆运算。

## 1.2 指针运算按元素大小缩放

**这是指针与整数最关键的区别。**

`C`

```c
/* scale.c    编译：gcc -std=c23 scale.c -o scale */
#include <stdio.h>

int main(void) {
    int    ai[4];
    double ad[4];
    char   ac[4];

    printf("int*    : %td 字节\n", (char *)(ai + 1) - (char *)ai);
    printf("double* : %td 字节\n", (char *)(ad + 1) - (char *)ad);
    printf("char*   : %td 字节\n", (char *)(ac + 1) - (char *)ac);

    printf("两个 int 指针相减: %td  （单位是元素，不是字节）\n", &ai[3] - &ai[0]);
    return 0;
}
```

`实测数据`
`Text`

```text
int*    : 4 字节
double* : 8 字节
char*   : 1 字节
两个 int 指针相减: 3  （单位是元素，不是字节）
```

> [!IMPORTANT]
> **`p + 1` 不是「地址加 1」，而是「地址加 sizeof(*p)」。**
> 减法的结果也是元素个数，不是字节数。
> 这一条是 `arr[i]` 能等于 `*(arr + i)` 的前提。

## 1.3 空指针

**表示「不指向任何东西」。**

`C`

```c
int *p = NULL;              /* C：<stddef.h> 里定义 */
int *q = nullptr;           /* C++11 起，C 没有 */
```

**C++ 里两者不是一回事**：

`C++`

```cpp
// null_overload.cpp    编译：g++ -std=c++17 null_overload.cpp -o null_overload
#include <cstdio>

void f(int x)   { std::printf("调用了 f(int)\n"); }
void f(char *p) { std::printf("调用了 f(char*)\n"); }

int main() {
    // f(NULL);         // 编译失败：二义
    f(nullptr);         // 明确选 f(char*)
    return 0;
}
```

`实测数据`

| 写法 | C++17 的结果 |
|---|---|
| `f(NULL)` | **失败**：`call of overloaded 'f(long long int)' is ambiguous` |
| `f(nullptr)` | 通过，输出 `调用了 f(char*)` |

**原因**：`NULL` 在 C++ 里通常是整数 `0`，而 `0` 既能转成 `int` 也能转成指针，
两个重载都匹配，编译器无法选。
`nullptr` 是一个独立的类型，只能转成指针。

> [!TIP]
> **C++ 里一律用 `nullptr`**，不要用 `NULL` 或 `0`。
> 这不只是风格问题——用 `NULL` 会在重载时直接编译失败。

## 1.4 三种「不该用的指针」

| 名字 | 什么情况 | 后果 |
|---|---|---|
| **野指针** | 声明了但没初始化 | 指向随机地址 |
| **悬垂指针** | 指向的内存已经释放 | 读到的可能是别人的数据 |
| **越界指针** | 指到数组外面 | 未定义行为 |

**悬垂指针的典型来源**：

`C`

```c
int *p = malloc(10 * sizeof(int));
free(p);
p[0] = 1;               /* 悬垂：内存已经还回去了 */
```

**返回局部变量的地址也会造成悬垂**，
实测后果见《04-语法/06-函数.md》第 4.1 小节（程序直接崩溃）。

> [!CAUTION]
> **`free` 之后指针不会自动变成 `NULL`。**
> 它仍然指向那块地址，只是那块地址不再属于你。
> **`free(p);` 之后紧跟一句 `p = NULL;`** 是低成本的保险。

# 第 2 节 数组

## 2.1 数组是什么

**一块连续的、长度固定的内存。**

`C`

```c
int arr[5] = { 1, 2, 3, 4, 5 };
```

**它在内存里长这样**：

`Text`

```
   arr[0]   arr[1]   arr[2]   arr[3]   arr[4]
   ┌────┬────┬────┬────┬────┐
   │ 1  │ 2  │ 3  │ 4  │ 5  │      每个 4 字节，共 20 字节
   └────┴────┴────┴────┴────┘
   ↑
   arr 的值就是这个地址
```

**「连续」这一点很重要**：正因为连续，`arr + i` 才能算出第 `i` 个元素的地址。

## 2.2 退化

**数组名在大多数表达式里会「退化」成指向首元素的指针。**

**这是本章最重要的一条。**

`C`

```c
/* decay.c    编译：gcc -std=c23 decay.c -o decay */
#include <stdio.h>

int main(void) {
    int arr[5] = { 1, 2, 3, 4, 5 };

    printf("sizeof(arr)      = %zu   （整块）\n", sizeof(arr));
    printf("sizeof(arr[0])   = %zu   （一个元素）\n", sizeof(arr[0]));
    printf("sizeof(&arr)     = %zu   （指向整块的指针）\n", sizeof(&arr));
    printf("sizeof(arr + 0)  = %zu   （退化后的指针）\n", sizeof(arr + 0));

    printf("arr      = %p\n", (void *)arr);
    printf("&arr     = %p   （值相同）\n", (void *)&arr);
    printf("&arr[0]  = %p   （值相同）\n", (void *)&arr[0]);

    printf("arr + 1  = %p   （跳过一个元素，%zu 字节）\n", (void *)(arr + 1), sizeof(arr[0]));
    printf("&arr + 1 = %p   （跳过整块，%zu 字节）\n", (void *)(&arr + 1), sizeof(arr));
    return 0;
}
```

`实测数据`
`Text`

```text
sizeof(arr)      = 20   （整块）
sizeof(arr[0])   = 4    （一个元素）
sizeof(&arr)     = 8    （指向整块的指针）
sizeof(arr + 0)  = 8    （退化后的指针）

arr      = 00000059413ff6d0
&arr     = 00000059413ff6d0   （值相同）
&arr[0]  = 00000059413ff6d0   （值相同）

arr + 1  = 00000059413ff6d4   （跳过一个元素，4 字节）
&arr + 1 = 00000059413ff6e4   （跳过整块，20 字节）
```

**三处地址完全相同，`+1` 之后却差了 16 字节。**

`Text`

```
   arr      的类型是 int *          →  +1 跳过 4 字节
   &arr     的类型是 int (*)[5]     →  +1 跳过 20 字节
   &arr[0]  的类型是 int *          →  +1 跳过 4 字节
```

> [!IMPORTANT]
> **退化的判据是「这个位置需不需要一个值」。**
> `sizeof` 要的是类型，不需要值 → **不退化**。
> `&` 要的是对象本身 → **不退化**。
> 参与运算、传参、赋值 → **需要一个值，于是退化成指针**。

## 2.3 退化的四条推论

**初学者常把这四条当成互相矛盾的怪现象，各背各的。**

| 现象 | 死记的结论 |
|---|---|
| 数组名能传给指针参数 | 「数组就是指针」 |
| 可 `sizeof(arr)` 拿到的又不止是指针大小 | 「但 sizeof 的时候不是」 |
| 数组不能整体赋值 | 「数组不能赋值」 |
| `&arr` 与 `arr` 值相同、类型不同 | 「记住就行」 |

**换成退化的视角，四条全变成推论**：

| 现象 | 由什么推出 |
|---|---|
| 能传给指针参数 | 它退化成指针了 |
| `sizeof(arr)` 是整块大小 | `sizeof` 不触发退化 |
| 不能整体赋值 | 退化后只剩地址，没有「一整块」可赋 |
| `&arr` 类型不同 | 取整块时不退化，类型是 `int (*)[5]` |

**「数组不能整体赋值」，编译器报错**：

`实测数据`
`Text`

```text
C23  : error: assignment to expression with array type
C++17: error: invalid array assignment
```

> [!IMPORTANT]
> **「数组就是指针」这句话是错的。**
> 数组是**一块内存**，指针是**一个地址**。
> 准确的说法是「数组名在大多数表达式里**退化成**指针」。
> 差在「退化」两个字上，而 `sizeof` 的结果就是证据。

## 2.4 二维数组

**二维数组是「数组的数组」。**

`C`

```c
/* matrix.c    编译：gcc -std=c23 matrix.c -o matrix */
#include <stdio.h>

int main(void) {
    int m[3][4];
    printf("sizeof(m)       = %zu  （整块）\n", sizeof(m));
    printf("sizeof(m[0])    = %zu  （一行）\n", sizeof(m[0]));
    printf("sizeof(m[0][0]) = %zu  （一个元素）\n", sizeof(m[0][0]));
    printf("行数 = %zu，列数 = %zu\n",
           sizeof(m) / sizeof(m[0]), sizeof(m[0]) / sizeof(m[0][0]));

    int (*row)[4] = m;          /* 二维数组名退化后是「指向一行的指针」 */
    printf("row + 1 跳过 %td 字节\n", (char *)(row + 1) - (char *)row);
    return 0;
}
```

`实测数据`
`Text`

```text
sizeof(m)       = 48  （整块）
sizeof(m[0])    = 16  （一行）
sizeof(m[0][0]) = 4   （一个元素）
行数 = 3，列数 = 4
row + 1 跳过 16 字节
```

> [!WARNING]
> **`m` 退化后是 `int (*)[4]`，不是 `int *`。**
> 因此 `int *p = m;` 在 C 里只是警告、在 C++ 里直接报错。
> 二维数组的「行指针」类型里**必须写出列数**——
> 因为 `+1` 要跳过整整一行，编译器得知道一行有多长。

## 2.5 数组参数

**函数参数里写 `int arr[5]` 与写 `int *arr` 是一回事。**

`C`

```c
/* arr_param.c    编译：gcc -std=c23 arr_param.c -o arr_param */
#include <stdio.h>

void f(int arr[5]) {            /* 写成 [5] */
    printf("  函数里 sizeof(arr) = %zu\n", sizeof(arr));
}
void g(int *arr) {              /* 写成指针 */
    printf("  函数里 sizeof(arr) = %zu\n", sizeof(arr));
}

int main(void) {
    int a[5] = { 1, 2, 3, 4, 5 };
    printf("外面 sizeof(a) = %zu\n", sizeof(a));
    f(a);
    g(a);
    return 0;
}
```

`实测数据`
`Text`

```text
外面 sizeof(a) = 20
  函数里 sizeof(arr) = 8
  函数里 sizeof(arr) = 8
```

**两个函数的 `sizeof` 都是 8**，即使 `f` 写的是 `int arr[5]`。

> [!CAUTION]
> **方括号里的数字对编译器毫无约束力。**
> `void f(int arr[5])` 与 `void f(int *arr)` 完全等价，
> **函数内部无法知道数组有多长**。
> 因此凡是接收数组的函数，**必须另外传一个长度参数**。

**正确的写法**：

`C`

```c
void fill(int *arr, size_t n);      /* 长度单独传 */
```

**C99 起还可以写成**：

`C`

```c
void fill(size_t n, int arr[n]);    /* 文档性质，仍然不检查 */
```

**这里的 `n` 只是写给读者看的**，编译器不检查实际长度。

# 第 3 节 引用

## 3.1 引用是什么

**引用是给已有对象起的另一个名字。**

`C++`

```cpp
// ref_basic.cpp    编译：g++ -std=c++17 ref_basic.cpp -o ref_basic
#include <cstdio>

int main() {
    int a = 42;
    int &r = a;                 // r 是 a 的别名

    r = 100;                    // 改 r 就是改 a
    std::printf("a = %d, r = %d\n", a, r);
    std::printf("&a = %p, &r = %p\n", (void *)&a, (void *)&r);
    return 0;
}
```

`实测数据`
`Text`

```text
a = 100, r = 100
&a = 0000008f3b3ff9d4, &r = 0000008f3ff9d4   （同一个地址）
```

**`&a` 与 `&r` 完全相同**——`r` 不是另一个变量，它就是 `a`。

## 3.2 三条性质

**这三条全部由「它是别名」推出。**

`实测数据`

| 写法 | 结果 |
|---|---|
| `int &r;` | **失败**：`'r' declared as reference but not initialized` |
| `int a = 1; int &r = a;` | 通过 |
| `int &r = 5;` | **失败**：`cannot bind non-const lvalue reference to an rvalue` |
| `const int &r = 5;` | 通过 |
| `int &r = a; r = b;` | **通过**——但这是**给 `a` 赋值**，不是重新绑定 |

**逐条解释**：

| 性质 | 为什么 |
|---|---|
| **必须初始化** | 别名要有个「本名」，没有「空别名」这回事 |
| **不能绑字面量**（除非 `const`） | `5` 没有内存位置，没法给它起名字 |
| **不能重新绑定** | `r = b` 是**赋值**，改的是 `r` 所指的那个对象 |

> [!IMPORTANT]
> **`r = b;` 之后 `r` 仍然指向 `a`，只是 `a` 的值变成了 `b` 的值。**
> **引用一旦绑定就不能改指向**——这是它与指针最大的区别。

**`const int &r = 5;` 为什么可以**：编译器会为 `5` 造一个临时对象，
让 `r` 绑定到它。**这是 `const` 引用独有的待遇。**

## 3.3 引用就是指针：汇编对照

**这一条是整章最硬的证据。**

`C++`

```cpp
// ref_vs_ptr.cpp    编译：g++ -std=c++17 -O0 -S ref_vs_ptr.cpp -o ref_vs_ptr.s
int by_pointer(int *p)   { return *p + 1; }
int by_reference(int &r) { return r + 1; }
```

**两个函数生成的汇编**：

`Assembly`

```asm
_Z10by_pointerPi:                _Z12by_referenceRi:
    pushq   %rbp                     pushq   %rbp
    movq    %rsp, %rbp               movq    %rsp, %rbp
    movq    %rcx, 16(%rbp)           movq    %rcx, 16(%rbp)
    movq    16(%rbp), %rax           movq    16(%rbp), %rax
    movl    (%rax), %eax             movl    (%rax), %eax
    addl    $1, %eax                 addl    $1, %eax
    popq    %rbp                     popq    %rbp
    ret                              ret
```

**逐条完全相同，连寄存器都一样。**

**符号名也说明了同一件事**：

| 符号 | 拆开看 |
|---|---|
| `_Z10by_pointerPi` | `P` + `i` = **pointer to int** |
| `_Z12by_referenceRi` | `R` + `i` = **reference to int** |

**两者都接收一个「指针大小」的参数**（`movq %rcx` 搬的是 64 位）。

> [!IMPORTANT]
> **引用在底层就是一个自动解引用的指针。**
> 它不占额外空间、不产生额外指令、传参方式与指针完全相同。
> **「引用更高效」这种说法不成立**——它与指针一样高效。

## 3.4 那为什么还要引用

**因为它把「必须解引用」这件事交给了编译器。**

| | 指针 | 引用 |
|---|---|---|
| 语法 | 要写 `*p` | 直接写 `r` |
| 能不能为空 | 能（`NULL`） | **不能** |
| 能不能改指向 | 能 | **不能** |
| 底层 | 地址 | 地址 |

**引用换来的是两条编译期保证**：

`Text`

```
   不能为空      →  函数里不用写 if (p) 检查
   不能改指向    →  不用担心中途被别人换掉
```

> [!TIP]
> **参数不需要「可以不传」时，用引用。**
> `void print(const std::string &s)` 比 `void print(const std::string *s)`
> 少一次空指针检查，调用方也不用写 `&`。
> **需要「可以不传」或「需要改指向」时，才用指针。**

# 第 4 节 函数指针

**函数有地址，因此可以放进指针。** 这一点在
《04-语法/06-函数.md》第 6 节已经开过头，这里给出完整用法。

## 4.1 声明与使用

`C`

```c
/* func_ptr.c    编译：gcc -std=c23 func_ptr.c -o func_ptr */
#include <stdio.h>

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

/* 读法：从名字出发，先看右边，再看左边 */
int (*op)(int, int) = add;

int apply(int (*fn)(int, int), int a, int b) {
    return fn(a, b);            /* 通过指针调用，写法与普通调用一样 */
}

int main(void) {
    printf("%d\n", op(5, 3));           /* 8 */
    op = sub;
    printf("%d\n", op(5, 3));           /* 2 */
    printf("%d\n", apply(add, 10, 4));  /* 14 */
    return 0;
}
```

**用 `typedef` 起名之后好读得多**（做法见
《04-语法/02-数据类型与类型系统.md》第 4 节）：

`C`

```c
typedef int (*binop_t)(int, int);       /* 把变量名换成类型名，前面加 typedef */

int apply(binop_t fn, int a, int b) { return fn(a, b); }
```

## 4.2 典型用途：回调

**标准库的 `qsort` 就是一个例子。**

`C`

```c
/* qsort_demo.c    编译：gcc -std=c23 qsort_demo.c -o qsort_demo */
#include <stdio.h>
#include <stdlib.h>

/* 比较函数：返回负数表示 a 应排在 b 前 */
int cmp_int(const void *a, const void *b) {
    int x = *(const int *)a;
    int y = *(const int *)b;
    return (x > y) - (x < y);       /* 不用减法，避免溢出 */
}

int main(void) {
    int arr[] = { 5, 2, 8, 1, 9, 3 };
    size_t n = sizeof(arr) / sizeof(arr[0]);

    qsort(arr, n, sizeof(arr[0]), cmp_int);

    for (size_t i = 0; i < n; i++) printf("%d ", arr[i]);
    printf("\n");
    return 0;
}
```

**输出**：`1 2 3 5 8 9`

> [!TIP]
> **`qsort` 不知道你要排什么类型**，所以它接收 `void *` 与一个比较函数。
> **`void *` 能接任何指针**——这是 C 里唯一的「泛型」手段
> （C 与 C++ 在这里的差异见
> 《04-语法/02-数据类型与类型系统.md》第 6.2 小节）。

**比较函数写成 `(x > y) - (x < y)` 而不是 `x - y`**，
是为了避免两个大数相减时溢出。

| 术语 | 英文 | 含义 |
|---|---|---|
| 退化 | Decay | 数组名在表达式中变成指向首元素的指针 |
