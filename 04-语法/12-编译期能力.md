**有些事情不必等到程序跑起来才知道。**

**一个数是不是 4 字节、一个结构体的成员排在哪、
一段计算的结果是多少——这些在编译时就能确定。**

**把它们放到编译期做，好处有三个**：
**错误提前暴露**、**运行期少算一次**、**结果不进二进制**。

**这些手段在 C 与 C++ 里的分布并不相同**：
有的两门语言都有，有的只有一门有，还有的版本要求不同。

# 第 1 节 哪些东西在编译期就能确定

**先列出清单。**

| 东西 | 什么时候确定 | 语言 |
|---|---|---|
| `sizeof(T)` | **编译期** | C 与 C++ |
| `offsetof(S, m)` | **编译期** | C 与 C++ |
| `constexpr` 变量 | **编译期** | C23（只用于对象）与 C++ |
| 数组长度（常量表达式） | **编译期** | C 与 C++ |
| `static_assert` 的条件 | **编译期** | C11 起与 C++11 起，见第 4 节 |
| 模板参数 | **编译期** | C++ |
| 枚举值 | **编译期** | C 与 C++ |
| 字符串字面量的长度 | **编译期** | C 与 C++ |

**「编译期」意味着**：这个值在生成机器码之前就已知，
编译器可以直接把它填进去。

**`sizeof` 与 `offsetof` 是 C 与 C++ 都有的**，
两门语言里的写法只差头文件、类型名的写法与输出函数——
**C 里类型名必须带 `struct` 关键字**：

`C`

```c
/* compile_time.c    编译：gcc -std=c23 compile_time.c -o compile_time_c */
#include <stdio.h>
#include <stddef.h>

struct S { char c; int i; };

int main(void) {
    printf("sizeof(S) = %zu\n", sizeof(struct S));          /* C 里要写 struct S */
    printf("offsetof(S, i) = %zu\n", offsetof(struct S, i));

    int arr[sizeof(struct S)];  /* 能当数组长度用，说明它是常量 */
    printf("sizeof(arr) = %zu\n", sizeof(arr));
    return 0;
}
```

`C++`

```cpp
/* compile_time.cpp    编译：g++ -std=c++17 compile_time.cpp -o compile_time */
#include <cstdio>
#include <cstddef>

struct S { char c; int i; };

int main() {
    std::printf("sizeof(S) = %zu\n", sizeof(S));
    std::printf("offsetof(S, i) = %zu\n", offsetof(S, i));

    int arr[sizeof(S)];         // 能当数组长度用，说明它是常量
    std::printf("sizeof(arr) = %zu\n", sizeof(arr));
    return 0;
}
```

**两者输出相同**：

`实测数据`
`Text`

```text
sizeof(S) = 8
offsetof(S, i) = 4
sizeof(arr) = 32
```

**两个例子里的 `int arr[...]` 都是关键**：数组长度必须是编译期常量，
能这么写就证明了 `sizeof` 不是运行期函数。

# 第 2 节 `const` 不等于「编译期常量」

## 2.1 一个常见的误解

**`const` 是 C 与 C++ 都有的限定符**，它的意思是「不能改」，
不是「编译期就知道」。**它的完整讲解见《04-语法/03-常量与 const.md》第 2 节。**

**先看 C++ 里的情形**：

`C++`

```cpp
/* const_vs_constexpr.cpp    编译：g++ -std=c++17 -c const_vs_constexpr.cpp -o const_vs_constexpr.o */
int get() { return 5; }

const int a = 5;            // 常量初始化：可以当常量表达式用
const int b = get();        // 运行期初始化：不是常量表达式

int arr[a];                 // 通过
// int arr2[b];             // 失败：ISO C++ forbids variable length array
```

**C 里没有「带初值的 `const` 就是常量表达式」这条规则**：

`C`

```c
/* const_not_constant.c    编译：gcc -std=c23 const_not_constant.c -o const_not_constant */
#include <stdio.h>

int get(void) { return 5; }
const int a = 5;                /* 有初值：它仍然只是只读变量 */

int main(void) {
    const int b = get();        /* 块作用域的运行期初始化 */
    int vla_a[a];               /* 能编过，但这是变长数组 */
    int vla_b[b];               /* 也是变长数组 */
    printf("%zu %zu\n", sizeof(vla_a), sizeof(vla_b));
    return 0;
}
```

**需要常量表达式的位置，C 里的 `const` 变量顶不上去**：

`C`

```c
/* const_enum_err.c    编译：gcc -std=c23 -c const_enum_err.c -o const_enum_err.o （失败） */
const int a = 5;
enum { E = a };                 /* 失败：const int 不是整数常量表达式 */
```

`实测数据`

| 写法 | C23 | C++17 |
|---|---|---|
| 文件作用域的 `const int b = get();`（运行期初始化） | **失败**：`initializer element is not constant` | 通过 |
| 文件作用域 `const int a = 5;` 用作枚举值 | **失败**：`enumerator value for 'E' is not an integer constant` | 通过 |
| 块作用域 `const int b = get();` 当数组长度 | 通过（**变长数组**） | **失败**：`ISO C++ forbids variable length array` |

**共同点**：两门语言里 `const` 都只保证「你不改它」，
不保证「它的值在编译期已知」。

**不同点**：C++ 里带常量初值的 `const int` 本身就是常量表达式，
能当模板参数、能当枚举值、能当数组长度；
C 里 `const` 变量永远不是常量表达式，
能用它当数组长度只是因为 C 有变长数组。

> [!IMPORTANT]
> **`const` 只保证「你不改它」，不保证「它的值在编译期已知」。**
> 一个用函数返回值初始化的 `const` 变量，
> 它的值要到运行期才知道——**它仍然是只读的，但不是常量**。

## 2.2 `constexpr` 补上了这个保证

**`constexpr` 的意思是「这确实是一个编译期常量」。**

**它不是 C++ 独有的**：C++11 引入之后，**C23 也引入了 `constexpr`**，
但两门语言的能力不同——**C 里只能用于对象，而且必须有初值**，
`constexpr` 函数是 C++ 才有的（见第 3 节）。

`C++`

```cpp
constexpr int n = 5;        // C++11 起：编译器保证值在编译期已知
```

**C23 起 C 也能写同样的声明**，语法相同，限制更多：

`实测数据`

| 写法 | C23 | C++17 |
|---|---|---|
| `constexpr int n = 5;` | 通过 | 通过 |
| `constexpr int n;`（不带初值） | **失败**：`'constexpr' requires an initialized data declaration` | **失败**：`uninitialized 'const n'` |
| `constexpr int f(int x) { return x * x; }`（函数） | **失败**：同一个错 | 通过 |

**它的约束比 `const` 强**（下表是 C++ 的语义）：

| | `const` | `constexpr` |
|---|---|---|
| 不能改 | 是 | 是 |
| 值必须在编译期已知 | **不一定** | **是** |
| 能否当数组长度 | 看初始化方式 | **一定能** |
| 能否当模板参数 | 看初始化方式 | **一定能**（模板只有 C++ 有） |

> [!IMPORTANT]
> **`constexpr` 在两门语言里不是同一件事。**
> C++ 的 `constexpr` 既能修饰对象也能修饰函数（C++11 起）；
> **C23 的 `constexpr` 只能修饰对象，而且必须带初值**，
> 写成函数会被当成「缺少初值的数据声明」而报错。
> 完整的核对见附录 A.7。

> [!TIP]
> **C++ 里需要「编译期常量」时一律用 `constexpr`。**
> 它把「这是常量」这件事写进了类型系统，
> 编译器会替你检查，而不是等某个地方用不了才发现。
> **C 里对应的手段是 `#define` 与 `enum`**（见第 6 节）；
> C23 的 `constexpr` 对象也可以用，但它还太新。

## 2.3 强行改 `const` 会怎样

**可以用强制转换绕过 `const`，但结果往往不是你想的那样。**

`实测数据`
`C++`

```cpp
/* castaway.cpp    编译：g++ -std=c++17 castaway.cpp -o castaway */
#include <cstdio>

int main() {
    const int n = 5;
    int *p = (int *)&n;         // 强行去掉 const
    *p = 6;
    std::printf("n = %d, *p = %d\n", n, *p);
    return 0;
}
```

输出是 `n = 5, *p = 6`。

**同一块内存，两种读法得到不同的值。**

**原因**：编译器知道 `n` 是 `const`，
凡是读到 `n` 的地方**直接把 5 填了进去**（这叫常量折叠），
根本没去内存里读。

> [!CAUTION]
> **修改 `const` 对象是未定义行为，C 与 C++ 都这样规定。**
> 上例里 `n` 打印出 5 不是「没改成功」，而是
> **编译器压根没打算去读那块内存**。
> 这个程序在别的编译器上可能打印 6，也可能崩溃。

# 第 3 节 `constexpr` 函数（C++）

## 3.1 它是什么

**`constexpr` 函数是 C++ 才有的**（C++11 起）：
一个「既能编译期算、也能运行期算」的函数。
**C 没有这个特性**，C23 的 `constexpr` 只能修饰对象。

`实测数据`
`C++`

```cpp
/* constexpr_fn.cpp    编译：g++ -std=c++17 constexpr_fn.cpp -o constexpr_fn */
#include <cstdio>

constexpr int square(int x) { return x * x; }

int main() {
    constexpr int a = square(5);        // 编译期算
    int b = square(5);                  // 也可能在运行期算
    int arr[square(3)];                 // 数组长度必须是常量

    std::printf("a = %d, b = %d, sizeof(arr) = %zu\n", a, b, sizeof(arr));
    return 0;
}
```

输出是 `a = 25, b = 25, sizeof(arr) = 36`。

**`int arr[square(3)]` 能编过，说明 `square(3)` 在编译期就被算成了 9。**

**同一个函数放进 C23 会直接报错**：

`实测数据`
`Text`

```text
error: 'constexpr' requires an initialized data declaration
```

**C23 把 `constexpr` 限定在对象上**，函数声明被当成缺少初值的数据声明。

## 3.2 它真的省掉了运行期的计算

**看汇编最直接。**

`C++`

```cpp
/* fold.cpp    编译：g++ -std=c++17 -O0 -S fold.cpp -o fold.s */
int use_constexpr() {
    constexpr int n = 5;
    return n * n;
}
int use_variable() {
    int n = 5;
    return n * n;
}
```

**两个函数的汇编**

`实测数据`
`Assembly`

```asm
_Z13use_constexprv:              _Z12use_variablev:
    pushq   %rbp                     pushq   %rbp
    movq    %rsp, %rbp               movq    %rsp, %rbp
    subq    $16, %rsp                subq    $16, %rsp
    movl    $5, -4(%rbp)             movl    $5, -4(%rbp)
    movl    $25, %eax                movl    -4(%rbp), %eax
    addq    $16, %rsp                imull   %eax, %eax
    popq    %rbp                     addq    $16, %rsp
    ret                              popq    %rbp
                                     ret
```

**右边有一条 `imull`（乘法指令），左边没有。**

**左边直接把 25 填进了寄存器**——乘法在编译期就算完了。

> [!IMPORTANT]
> **`constexpr` 的计算不进入运行期。**
> 上例是在 `-O0`（不优化）下测的，
> 也就是说**这不是优化器的功劳，而是 `constexpr` 本身的效果**。

## 3.3 函数体里能写什么

**C++14 起放宽了很多**（C 没有 `constexpr` 函数，本小节只涉及 C++）。

`实测数据`

| 函数体里用了什么 | C++17 |
|---|---|
| 直接返回常量 | 通过 |
| 局部变量 | **通过** |
| `if` | **通过** |
| `for` / `while` | **通过** |
| `static` 局部变量 | **失败**：`'x' defined 'static' in 'constexpr' function only available with -std=c++23` |
| `goto` | 失败 |
| 调用非 `constexpr` 函数 | 失败（除非该分支不在编译期求值时执行） |

**下面这个函数用了局部变量、`for` 和 `if`**：

`实测数据`
`C++`

```cpp
/* constexpr_body.cpp    编译：g++ -std=c++17 constexpr_body.cpp -o constexpr_body */
#include <cstdio>

constexpr int sum_to(int n) {           // C++14 起可以写局部变量与循环
    int s = 0;
    for (int i = 1; i <= n; ++i) s += i;
    return s;
}

constexpr int pick(int n) {             // 也可以写 if
    if (n > 2) return sum_to(n);
    return n;
}

int main() {
    constexpr int a = pick(1);          // 编译期求值
    constexpr int b = pick(3);
    std::printf("%d %d %d\n", a, b, pick(3));
    return 0;
}
```

**输出是 `1 6 6`。**

> [!NOTE]
> **C++11 时 `constexpr` 函数体只能有一条 `return` 语句**，
> 所以那时的写法要写成递归。**C++14 起放宽成普通函数体**，
> 本教材的基准 C++17 因此可以直接写循环。

# 第 4 节 `static_assert`

## 4.1 编译期断言

**`static_assert` 从 C++11 起可用，C++17 起消息可以省略。**
**如果条件不成立，编译直接失败。**

`C++`

```cpp
/* static_assert.cpp    编译：g++ -std=c++17 static_assert.cpp -o static_assert */
#include <cstdio>

static_assert(sizeof(int) == 4, "int 不是 4 字节");

int main() {
    std::printf("int 是 %zu 字节\n", sizeof(int));
    return 0;
}
```

**条件成立时编译通过。把 `4` 改成 `8`，编译报错**：

`实测数据`
`Text`

```text
error: static assertion failed: int 不是 4 字节
```

**C++17 起消息可以省略**：

`C++`

```cpp
static_assert(sizeof(int) == 4);        // 不写消息也合法
```

**g++ 在 C++11 下默认也接受这种单参数写法**，
加上 `-pedantic-errors` 才会拒绝：

`实测数据`
`Text`

```text
error: 'static_assert' without a message only available with '-std=c++17' or '-std=gnu++17'
```

## 4.2 C 里也有

**C11 起有了 `static_assert`**，但需要包含 `<assert.h>`。
**C23 起它成了关键字，不需要包含任何头文件**。

`C`

```c
/* static_assert_c.c    编译：gcc -std=c11 static_assert_c.c -o static_assert_c */
#include <assert.h>         /* C11：static_assert 由 <assert.h> 提供 */
static_assert(sizeof(int) == 4, "int 不是 4 字节");
int main(void) { return 0; }
```

`实测数据`

| 写法 | C23 | C11 |
|---|---|---|
| 包含 `<assert.h>` 后用 `static_assert` | 通过 | 通过 |
| **不包含任何头文件**直接用 | **通过** | **失败**：`expected declaration specifiers or '...' before 'sizeof'` |

> [!TIP]
> **`static_assert` 是「把假设写进代码」的手段。**
> 比如「这个结构体必须是 8 字节」「这个类型必须是无符号的」——
> 写下来之后，换平台、换编译器时会立刻暴露，
> 而不是等到运行期发现数据不对。

## 4.3 它和 `assert` 的区别

**`assert` 与 `static_assert` 在 C 与 C++ 里的行为相同。**

| | `static_assert` | `assert` |
|---|---|---|
| 什么时候检查 | **编译期** | 运行期 |
| 失败会怎样 | **编译不过** | 程序中止 |
| 有没有运行期开销 | **没有** | 有（判断一次） |
| 能不能检查变量 | **不能**（只认常量表达式） | 能 |
| 发布版里还在吗 | 在 | 通常被 `NDEBUG` 去掉 |

> [!IMPORTANT]
> **凡是编译期能查的，就不要留到运行期。**
> `static_assert` 的检查是零成本的——它在生成的代码里
> 什么也不留。

# 第 5 节 `if constexpr`（C++17）

**C++17 起，`if` 的条件可以是编译期常量。**
**C 没有这个写法**：C 里 `if` 的条件一律是运行期求值的表达式。

`C++`

```cpp
/* if_constexpr.cpp    编译：g++ -std=c++17 if_constexpr.cpp -o if_constexpr */
#include <cstdio>

template <typename T>
void show(T v) {
    if constexpr (sizeof(T) <= 4) {
        std::printf("小类型，%zu 字节\n", sizeof(T));
    } else {
        std::printf("大类型，%zu 字节\n", sizeof(T));
    }
}

int main() {
    show(1);            // int，4 字节
    show(1.0);          // double，8 字节
    return 0;
}
```

`实测数据`
`Text`

```text
小类型，4 字节
大类型，8 字节
```

## 5.1 它与普通 `if` 的区别

**普通 `if` 两门语言都有，`if constexpr` 只有 C++ 有。**
**普通 `if` 的两个分支都要能编过；`if constexpr` 只编被选中的那个。**

| | `if` | `if constexpr` |
|---|---|---|
| 语言 | C 与 C++ | C++（C++17 起） |
| 条件 | 运行期值 | **编译期常量** |
| 两个分支 | **都要合法** | **只编选中的那个** |
| 没选中的分支 | 仍然生成代码 | **完全不生成** |
| 能不能写「只对某类型成立」的代码 | 不能 | **能** |

**这一点在模板里用途最广**：可以针对不同类型的参数写完全不同的实现，
而不要求所有实现都对所有类型成立。

**`if constexpr` 是 C++17 引入的模板编程工具**，
模板的完整讲解见《05-类与面向对象/11-模板.md》；`if constexpr` 属于模板的高阶用法，见《05-类与面向对象/12-模板的高阶使用.md》第 3 节。

# 第 6 节 C 里的编译期手段

**C 没有 `constexpr` 函数，也没有 `if constexpr`。**
**C23 起有了 `constexpr`，但它只能修饰对象，而且必须有初值**（见第 2.2 小节）。

**它能用的手段有限**：

| 手段 | 版本与语言归属 |
|---|---|
| `sizeof`、`offsetof` | 编译期常量，C 与 C++ 都有 |
| 枚举值 | 编译期常量，C 与 C++ 都有 |
| `static_assert` | **C11 起**，C23 起不必包含头文件；C++11 起也有 |
| `#define` | 文本替换，C 与 C++ 都有，见《04-语法/14-预处理器.md》第 2 节 |
| 数组长度 | 必须是常量表达式；**C99 起可以是变量，即变长数组（VLA），这是 C 专有的**，C++ 里只是编译器扩展 |
| `constexpr` | **C23 起**，只能用于对象，必须有初值；C 没有 `constexpr` 函数 |
| 模板、`if constexpr` | **C 没有**，属于 C++ |

**C 里想表达「编译期常量」，通常用宏或枚举**：

`C`

```c
/* c_compile_time.c    编译：gcc -std=c23 -c c_compile_time.c -o c_compile_time.o */
#define MAX_LEN 128                 /* 宏：文本替换，没有类型 */
enum { MAX_LEN_E = 128 };           /* 枚举：有类型，可以调试 */
constexpr int MAX_LEN_X = 128;      /* C23 起：constexpr 对象，必须有初值 */
static const int MAX_LEN_C = 128;   /* const：是变量，不是常量表达式 */
```

> [!WARNING]
> **C 里的 `static const int` 不能当数组长度**——
> 它是只读变量，不是常量表达式。
> **想要编译期常量，用 `#define` 或 `enum`**；C23 起也可以用 `constexpr` 对象。

**C23 的 `constexpr` 与 C++ 的差异见第 2.2 小节与附录 A.7**：
它只用于对象、必须有初值，没有 `constexpr` 函数。

> [!TIP]
> **C 与 C++ 在这一块的差距是两种语言设计取向的体现**：
> C++ 把「编译期计算」做进了语言（模板、`constexpr` 函数），
> C 则主要靠预处理器。
> **`consteval`、`constinit` 与 `std::is_constant_evaluated` 是 C++20 才有的**，
> 超出本教材的 C++17 基准，这里只点名，不展开。
> 这一区别的讨论见《04-语法/02-数据类型与类型系统.md》第 7 节。

# 术语表

| 术语 | 英文 | 含义 |
|---|---|---|
| 常量表达式 | Constant expression | 编译期就能求值的表达式；C 与 C++ 都有这个概念，判定规则不同 |
| 常量折叠 | Constant folding | 编译器把常量运算提前算好，C 与 C++ 都会做 |
| 编译期断言 | Static assertion | 编译时检查的条件；C11 起与 C++11 起都有 |
| `constexpr` | Constexpr | C++11 起的常量声明与函数；C23 起也引入了这个关键字，但只用于对象 |
| `if constexpr` | Constexpr if | C++17 起的编译期分支；C 没有 |
| `consteval` | Immediate function | C++20 起的「必须编译期求值」函数；超出本教材的 C++17 基准 |
| `constinit` | Constant initialization | C++20 起的「必须静态初始化」声明；超出本教材的 C++17 基准 |
| 变长数组 | VLA | 长度在运行期确定的数组，C99 起，**C 专有**；C++ 里只是编译器扩展 |
| 模板 | Template | 用类型作参数的代码生成机制，**C++ 专有** |

# 附录 A 复现本章节实测

**环境**：`gcc` / `g++` 15.2.0（MinGW-w64），Windows x64。
C 侧用 `-std=c23`，C++ 侧用 `-std=c++17`（另有标注的除外）。

## A.1 `sizeof` 是编译期常量（C 与 C++）

`C`

```c
/* compile_time.c    编译：gcc -std=c23 compile_time.c -o compile_time_c */
#include <stdio.h>
#include <stddef.h>
struct S { char c; int i; };
int main(void) {
    printf("%zu %zu\n", sizeof(struct S), offsetof(struct S, i));
    int arr[sizeof(struct S)];
    printf("%zu\n", sizeof(arr));
    return 0;
}
```

`C++`

```cpp
/* compile_time.cpp    编译：g++ -std=c++17 compile_time.cpp -o compile_time */
#include <cstdio>
#include <cstddef>
struct S { char c; int i; };
int main() {
    std::printf("%zu %zu\n", sizeof(S), offsetof(S, i));
    int arr[sizeof(S)];
    std::printf("%zu\n", sizeof(arr));
    return 0;
}
```

`Bash`

```bash
gcc -std=c23 compile_time.c -o c_c && ./c_c
# 8 4
# 32
g++ -std=c++17 compile_time.cpp -o c_cpp && ./c_cpp
# 8 4
# 32
```

## A.2 `const` 与 `constexpr` 的区别

`C++`

```cpp
/* const_vs_constexpr.cpp    编译：g++ -std=c++17 -pedantic-errors -c const_vs_constexpr.cpp -o const_vs_constexpr.o */
int get() { return 5; }
const int a = 5;
const int b = get();
int arr[a];                 // 通过
// int arr2[b];             // 失败：ISO C++ forbids variable length array
```

`Bash`

```bash
g++ -std=c++17 -pedantic-errors -c const_vs_constexpr.cpp -o const_vs_constexpr.o
```

**同一份逻辑在 C 里的结果不同**：

`C`

```c
/* const_not_constant.c    编译：gcc -std=c23 const_not_constant.c -o const_not_constant */
#include <stdio.h>
int get(void) { return 5; }
const int a = 5;            /* 有初值，仍然只是只读变量 */
int main(void) {
    const int b = get();
    int vla_a[a];           /* 变长数组：C99 起合法 */
    int vla_b[b];
    printf("%zu %zu\n", sizeof(vla_a), sizeof(vla_b));
    return 0;
}
```

`Bash`

```bash
gcc -std=c23 const_not_constant.c -o c && ./c
# 20 20
gcc -std=c23 -pedantic-errors const_not_constant.c -o c && ./c
# 20 20：C 里这不违反标准
```

**同一个 `const` 变量用在需要常量表达式的位置，两门语言的结论相反**：

`C`

```c
/* const_enum_err.c    编译：gcc -std=c23 -c const_enum_err.c -o const_enum_err.o （失败） */
const int a = 5;
enum { E = a };             /* 失败：enumerator value for 'E' is not an integer constant */
```

`C++`

```cpp
/* const_enum_ok.cpp    编译：g++ -std=c++17 -c const_enum_ok.cpp -o const_enum_ok.o */
const int a = 5;
enum { E = a };             // 通过
```

**C 里连文件作用域的运行期初始化都不允许**：

`C`

```c
/* const_file_err.c    编译：gcc -std=c23 -c const_file_err.c -o const_file_err.o （失败） */
int get(void) { return 5; }
const int b = get();        /* 失败：initializer element is not constant */
```

## A.3 `constexpr` 省掉运行期计算

`C++`

```cpp
/* fold.cpp    编译：g++ -std=c++17 -O0 -S fold.cpp -o fold.s */
int use_constexpr() { constexpr int n = 5; return n * n; }
int use_variable()  { int n = 5; return n * n; }
```

`Bash`

```bash
g++ -std=c++17 -O0 -S fold.cpp -o fold.s
```

**对照两个函数体**：`use_constexpr` 里是 `movl $25, %eax`，
`use_variable` 里是 `movl -4(%rbp), %eax` 加 `imull %eax, %eax`。

## A.4 `static_assert`

`C++`

```cpp

```


## A.7 语言归属核对

**同一批写法在两门语言、不同版本下的结果**：

`实测数据`

| 写法 | C23 | C++17 | C++20 |
|---|---|---|---|
| `constexpr int n = 5;`（对象带初值） | 通过 | 通过 | 通过 |
| `constexpr int n;`（对象不带初值） | **失败** | **失败** | **失败** |
| `constexpr int f(int x) { return x * x; }`（函数） | **失败** | 通过 | 通过 |
| `consteval int f() { return 1; }` | — | **失败** | 通过 |
| `constinit int g = 1;` | — | **失败** | 通过 |
| `std::is_constant_evaluated()` | — | **失败** | 通过 |
| `static_assert(...)`（不包含任何头文件） | 通过 | 通过 | 通过 |
| `static_assert`（含 `<assert.h>` / `<cassert>`） | 通过 | 通过 | 通过 |
| `if constexpr (...)` | **失败** | 通过 | 通过 |

**报错原文**：

`实测数据`
`Text`

```text
c23_func.c:2:1: error: 'constexpr' requires an initialized data declaration
   2 | constexpr int square(int x) { return x * x; }
     | ^~~~~~~~~
cpp17_noinit.cpp:1:15: error: uninitialized 'const n' [-fpermissive]
cpp17_consteval.cpp:2:1: error: 'consteval' does not name a type; did you mean 'constexpr'?
cpp17_constinit.cpp:2:1: error: 'constinit' does not name a type
cpp17_ice.cpp:2:25: error: 'is_constant_evaluated' is not a member of 'std'
```

**两个结论**：

- **C23 的 `constexpr` 只覆盖对象**：对象声明可以用，函数不行。
- **`consteval`、`constinit`、`std::is_constant_evaluated` 都是 C++20 的特性**，
  本教材的基准是 C++17，正文提到它们时只点名，不展开。

`Bash`

```bash
# C 侧
gcc -std=c23 -c c23_obj.c -o c23_obj.o            # 通过
gcc -std=c23 -c c23_func.c -o c23_func.o          # 失败
# C++ 侧
g++ -std=c++17 -c cpp17_func.cpp -o f.o           # 通过
g++ -std=c++17 -c cpp17_consteval.cpp -o f.o      # 失败
g++ -std=c++20 -c cpp17_consteval.cpp -o f.o      # 通过
```
